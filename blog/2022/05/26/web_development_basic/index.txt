11:Tf8d4,<p>The foundation of every website on the open web is three languages: <strong>HTML</strong> for structure, <strong>CSS</strong> for presentation, and <strong>JavaScript</strong> for behaviour. Modern frameworks (React, Vue, Svelte) all compile down to those three. This post covers the basics that the advanced post and any future framework work assume — semantic HTML, the modern CSS layout systems (Flexbox + Grid), responsive design, vanilla JS DOM manipulation, jQuery (still found in older codebases), forms, and the accessibility minimum.</p>

<h1 id="Learning-Outcome"><a href="#Learning-Outcome" class="headerlink" title="Learning Outcome"></a>Learning Outcome</h1>
<ul>
<li>Write semantic, valid HTML5.</li>
<li>Lay out pages with Flexbox and CSS Grid.</li>
<li>Make a site responsive with media queries.</li>
<li>Manipulate the DOM with vanilla JavaScript and jQuery.</li>
<li>Build accessible forms and handle their submission.</li>
<li>Set up a minimal local development environment.</li>

<h1 id="Chapter-1-—-How-the-web-works-one-paragraph"><a href="#Chapter-1-—-How-the-web-works-one-paragraph" class="headerlink" title="Chapter 1 — How the web works (one paragraph)"></a>Chapter 1 — How the web works (one paragraph)</h1>
<p>A <strong>browser</strong> sends an HTTP(S) request to a <strong>server</strong>; the server replies with an <strong>HTML document</strong>; the browser parses it, loads any linked <strong>CSS</strong> + <strong>JS</strong> + images, builds the <strong>DOM</strong> (the in-memory tree of elements) and <strong>CSSOM</strong> (the matched style tree), and renders pixels. JavaScript can later mutate the DOM and styles, triggering re-renders. Every &quot;fancy&quot; feature ultimately reduces to those moves.</p>
<h2 id="Terminology"><a href="#Terminology" class="headerlink" title="Terminology"></a>Terminology</h2>
<ul>
<li><strong>HTML</strong> — HyperText Markup Language; the structural language of web pages.</li>
<li><strong>CSS</strong> — Cascading Style Sheets; selectors + property declarations that style HTML.</li>
<li><strong>DOM</strong> — Document Object Model; the tree of nodes that the browser builds from HTML.</li>
<li><strong>JavaScript (ES) / ECMAScript</strong> — the language that runs in the browser and (via Node.js) on servers.</li>
<li><strong>Viewport</strong> — the visible area of the browser window.</li>
<li><strong>Selector</strong> — a CSS pattern that targets HTML elements.</li>
</ul>

<h2 id="The-cascade"><a href="#The-cascade" class="headerlink" title="The cascade"></a>The cascade</h2>
<p>When multiple rules match, the winner is decided by:</p>
<ol>
<li><strong>Origin + importance</strong> — <code>!important</code> user styles → <code>!important</code> author styles → author styles → user → browser default.</li>
<li><strong>Specificity</strong> — inline (1000) → id (100) → class/attr/pseudo (10) → element (1).</li>
<li><strong>Source order</strong> — later wins on ties.</li>
</ol>
<p>Avoid <code>!important</code> in normal code; it almost always means the cascade was lost. Refactor instead.</p>
<h2 id="Box-model"><a href="#Box-model" class="headerlink" title="Box model"></a>Box model</h2>

<h2 id="Exercise-3-—-Fetch-render"><a href="#Exercise-3-—-Fetch-render" class="headerlink" title="Exercise 3 — Fetch + render"></a>Exercise 3 — Fetch + render</h2>

<h2 id="Exercise-4-—-Responsive-gallery"><a href="#Exercise-4-—-Responsive-gallery" class="headerlink" title="Exercise 4 — Responsive gallery"></a>Exercise 4 — Responsive gallery</h2>
<p>A grid of 12 images. At &lt; 600px → 1 column. 600-900 → 2 cols. &gt; 900 → 3 cols. Use Grid + <code>minmax(...)</code>.</p>
<h2 id="Exercise-5-—-Form-validation"><a href="#Exercise-5-—-Form-validation" class="headerlink" title="Exercise 5 — Form validation"></a>Exercise 5 — Form validation</h2>
<p>A signup form (name, email, age, password). Use HTML5 attributes for native validation. Add a JS-side check that the password is ≥ 8 chars and contains a digit. Show errors below each input without losing focus.</p>
