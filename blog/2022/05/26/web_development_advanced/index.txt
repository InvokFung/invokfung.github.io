<li>The package manager (npm).</li>
<li>Many backend frameworks (Express, Fastify, NestJS, Next.js API routes).</li>

<h1 id="Chapter-3-—-Build-tools-Vite-ESM"><a href="#Chapter-3-—-Build-tools-Vite-ESM" class="headerlink" title="Chapter 3 — Build tools (Vite + ESM)"></a>Chapter 3 — Build tools (Vite + ESM)</h1>
<p>Old days: webpack + Babel + a 200-line config; cold start 30 sec, HMR 2-5 sec. Modern: <strong>Vite</strong> uses native ES modules in dev (zero bundling) and <strong>esbuild</strong> / <strong>Rollup</strong> for production builds. Cold start &lt; 500 ms, HMR &lt; 100 ms.</p>
<pre><code class="language-bash"><figure class="highlight bash"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span></pre></td><td class="code"><pre><code class="bash"><span class="line">npm create vite@latest my-app -- --template react-ts</span><br><span class="line"><span class="hljs-built_in">cd</span> my-app</span><br><span class="line">npm install</span><br><span class="line">npm run dev          <span class="hljs-comment"># opens http://localhost:5173</span></span><br><span class="line">npm run build        <span class="hljs-comment"># outputs to dist/</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Templates: <code>vanilla</code>, <code>vanilla-ts</code>, <code>react</code>, <code>react-ts</code>, <code>vue</code>, <code>vue-ts</code>, <code>svelte</code>, <code>svelte-ts</code>, <code>solid</code>, <code>lit</code>, <code>preact</code>, <code>qwik</code>. TypeScript is the default in modern teams.</p>
<h2 id="Why-ESM-matters"><a href="#Why-ESM-matters" class="headerlink" title="Why ESM matters"></a>Why ESM matters</h2>
<pre><code class="language-html"><figure class="highlight html"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span></pre></td><td class="code"><pre><code class="html"><span class="line"><span class="hljs-tag">&lt;<span class="hljs-name">script</span> <span class="hljs-attr">type</span>=<span class="hljs-string">&quot;module&quot;</span> <span class="hljs-attr">src</span>=<span class="hljs-string">&quot;/src/main.js&quot;</span>&gt;</span><span class="hljs-tag">&lt;/<span class="hljs-name">script</span>&gt;</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>The browser fetches each <code>import</code>-ed module separately. Dev servers serve them un-bundled — only re-process the file you changed. Production builds still bundle (fewer requests, tree-shaking).</p>

<h1 id="Chapter-12-—-Performance-baseline"><a href="#Chapter-12-—-Performance-baseline" class="headerlink" title="Chapter 12 — Performance baseline"></a>Chapter 12 — Performance baseline</h1>
<p>Hit these targets in Lighthouse for a polished site:</p>
<table>
<thead>
<tr>
<th>Metric</th>
<th>Target</th>
</tr>
</thead>
<tbody>
<tr>
<td>LCP (Largest Contentful Paint)</td>
<td>&lt; 2.5 s</td>
</tr>
<tr>
<td>INP (Interaction to Next Paint)</td>
<td>&lt; 200 ms</td>
</tr>
<tr>
<td>CLS (Cumulative Layout Shift)</td>
<td>&lt; 0.1</td>
</tr>
<tr>
<td>First-load JS (uncompressed)</td>
<td>&lt; 200 KB</td>
</tr>
<tr>
<td>Image format</td>
<td>AVIF / WebP, not PNG/JPG raw</td>
</tr>
<tr>
<td>Fonts</td>
<td><code>font-display: swap</code>, subset, self-host</td>
</tr>
</tbody>
</table>
<p>Tools: Lighthouse (in DevTools), <a href="https://pagespeed.web.dev/" target="_blank" rel="noopener external nofollow noreferrer">PageSpeed Insights</a>, <a href="https://www.webpagetest.org/" target="_blank" rel="noopener external nofollow noreferrer">WebPageTest</a>.</p>
<p>Common wins:</p>
<ol>
<li>Lazy-load below-the-fold images (<code>loading=&quot;lazy&quot;</code>).</li>
<li>Code-split routes (<code>React.lazy</code>, dynamic <code>import()</code>).</li>
<li>Compress images (use a build-time tool — <code>@astrojs/image</code>, <code>sharp</code>).</li>
<li>Preload the hero font.</li>
<li>Remove unused JS (the bundle analyzer flags it).</li>
</ol>
