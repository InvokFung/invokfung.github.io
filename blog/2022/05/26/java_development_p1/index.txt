<h1 id="Chapter-2-—-Objects-and-Classes"><a href="#Chapter-2-—-Objects-and-Classes" class="headerlink" title="Chapter 2 — Objects and Classes"></a>Chapter 2 — Objects and Classes</h1>
<h2 id="Terminology-1"><a href="#Terminology-1" class="headerlink" title="Terminology"></a>Terminology</h2>
<ul>
<li><strong>Field</strong> — class-level variable (state).</li>
<li><strong>Method</strong> — class-level function (behaviour).</li>
<li><strong>Constructor</strong> — special method called when <code>new</code> creates an instance.</li>
<li><strong><code>this</code></strong> — reference to the current instance inside a method.</li>
<li><strong><code>static</code></strong> — belongs to the class, not an instance.</li>

<li><strong>Record</strong> (Java 16+) — concise immutable data carrier.</li>
</ul>

<h2 id="Terminology-2"><a href="#Terminology-2" class="headerlink" title="Terminology"></a>Terminology</h2>
<ul>
<li><strong><code>extends</code></strong> — declares a subclass.</li>

<h2 id="Terminology-3"><a href="#Terminology-3" class="headerlink" title="Terminology"></a>Terminology</h2>
<ul>
<li><strong>Abstract class</strong> — declared with <code>abstract</code>; cannot be instantiated; may contain abstract methods.</li>

</ul>

<h2 id="Terminology-5"><a href="#Terminology-5" class="headerlink" title="Terminology"></a>Terminology</h2>
<ul>
<li><strong><code>Throwable</code></strong> — root.</li>
<li><strong><code>Error</code></strong> — JVM-level (<code>OutOfMemoryError</code>); usually don't catch.</li>

<p>Rules:</p>
<ul>
<li>Never use <code>assert</code> for argument validation in public APIs — use <code>if + throw new IllegalArgumentException(...)</code>.</li>

<li>Assertions are stripped at runtime by default — don't put side effects inside.</li>

<h1 id="Chapter-9-—-Multithreading"><a href="#Chapter-9-—-Multithreading" class="headerlink" title="Chapter 9 — Multithreading"></a>Chapter 9 — Multithreading</h1>
<h2 id="Terminology-6"><a href="#Terminology-6" class="headerlink" title="Terminology"></a>Terminology</h2>
<ul>
<li><strong>Thread</strong> — a unit of execution scheduled by the OS.</li>
<li><strong>Runnable</strong> — functional interface for a unit of work.</li>
<li><strong>Thread-safe</strong> — correct when accessed from multiple threads simultaneously.</li>
<li><strong>Race condition</strong> — outcome depends on thread interleaving.</li>
<li><strong><code>synchronized</code></strong> — mutual-exclusion keyword.</li>
<li><strong><code>volatile</code></strong> — guarantees visibility of writes across threads.</li>
<li><strong>Virtual thread</strong> (Java 21+) — lightweight, JVM-scheduled; millions can run concurrently.</li>
</ul>

<h2 id="Exercise-1-—-Class-basics"><a href="#Exercise-1-—-Class-basics" class="headerlink" title="Exercise 1 — Class basics"></a>Exercise 1 — Class basics</h2>
<p>Build a <code>BankAccount</code> class with <code>deposit</code>, <code>withdraw</code> (reject if overdraw), <code>balance()</code>. Override <code>toString()</code>. Add a <code>transferTo(BankAccount other, double amount)</code> method.</p>
<h2 id="Exercise-2-—-Inheritance"><a href="#Exercise-2-—-Inheritance" class="headerlink" title="Exercise 2 — Inheritance"></a>Exercise 2 — Inheritance</h2>
<p>Define <code>Shape</code> (abstract <code>double area()</code>), <code>Circle</code>, <code>Rectangle</code>, <code>Triangle</code>. Put them in an array; print the total area.</p>
<h2 id="Exercise-3-—-Generics"><a href="#Exercise-3-—-Generics" class="headerlink" title="Exercise 3 — Generics"></a>Exercise 3 — Generics</h2>
<p>Implement <code>Stack&lt;T&gt;</code> with <code>push</code>, <code>pop</code>, <code>peek</code>, <code>isEmpty</code>, <code>size</code>. Use an underlying <code>ArrayList&lt;T&gt;</code>.</p>
<h2 id="Exercise-4-—-Exception-flow"><a href="#Exercise-4-—-Exception-flow" class="headerlink" title="Exercise 4 — Exception flow"></a>Exercise 4 — Exception flow</h2>
<p>Read a file path from <code>args[0]</code>; print its content. Catch <code>NoSuchFileException</code> and <code>IOException</code> separately, exit with different exit codes (2 and 3 respectively).</p>

<p>Spawn 1000 virtual threads, each downloading <code>https://httpbin.org/uuid</code>. Collect the responses into a <code>List&lt;String&gt;</code> (thread-safe!) and print the count of unique values.</p>
