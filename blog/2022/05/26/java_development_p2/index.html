Java Development [Basic] Part 2 — GUI, Events, Functional, Collections, Streams

Created2022-05-26|Updated2026-05-21|Programming
|Post View:

Part 1 covered Java's language core through threads. Part 2 picks up with the application-level toolkit: a graphical user interface (JavaFX), event handling, the functional programming features added in Java 8 (lambdas, method references, functional interfaces), the Collections framework (the standard data structures), and the Stream API (declarative bulk operations). Together they cover most of what real Java apps build on top of the basics.

Learning Outcome

  • Build a basic JavaFX window with controls and a layout container.
  • Hook up event handlers (button clicks, key presses, observable property changes).
  • Write lambdas and method references; use the standard functional interfaces.
  • Choose between ArrayList, LinkedList, HashMap, TreeMap, HashSet, TreeSet, ArrayDeque, PriorityQueue.
  • Use the Stream API for map / filter / reduce, grouping, sorting, and parallel processing.
  • Combine functional + streams + collections into clean data pipelines.

Chapter 10 — Graphical User Interface (JavaFX)

Terminology

  • Stage — a top-level window.
  • Scene — the content of a stage; holds a scene graph.
  • Node — anything in the scene graph (controls, shapes, layouts).
  • Layout (Pane) — a Node that arranges children (VBox, HBox, GridPane, BorderPane, StackPane).
  • Control — interactive widget (Button, Label, TextField, TableView, etc.).

JavaFX is the modern Java GUI (since 2008); Swing is the older one but still around in some enterprise code. Pick JavaFX for new work.

Setup

JavaFX is no longer bundled with the JDK. Add it via:

  • Maven / Gradle dependency — org.openjfx:javafx-controls:21.
  • Or download the SDK from openjfx.io and run with --module-path <sdk>/lib --add-modules javafx.controls.

Chapter 11 — Events

Terminology

  • Event — an object describing something that happened (ActionEvent, MouseEvent, KeyEvent).
  • Event handler — a function (now usually a lambda) that runs in response.
  • Observable property — a value that fires notifications when it changes (ObservableValue<T>, Property<T>).
  • Binding — a derived observable computed from others.

Chapter 12 — Functional Programming (Java 8+)

Terminology

  • Lambda expression — short anonymous function: (a, b) -> a + b.
  • Method reference — shorthand for a lambda that just calls one method: String::toUpperCase.
  • Functional interface — an interface with exactly one abstract method (SAM).
  • Effectively final — a local variable that isn't reassigned — required to capture in a lambda.

Lambdas

Method references

Form Example Equivalent lambda
Static Integer::parseInt s -> Integer.parseInt(s)
Instance of a class String::toUpperCase s -> s.toUpperCase()
Instance of an object System.out::println x -> System.out.println(x)
Constructor ArrayList::new () -> new ArrayList<>()

Standard functional interfaces (java.util.function)

Interface Signature Use
Function<T, R> R apply(T t) transform
BiFunction<T, U, R> R apply(T t, U u) two args → result
Predicate<T> boolean test(T t) filter
Consumer<T> void accept(T t) side effect
Supplier<T> T get() factory
UnaryOperator<T> T apply(T t) same-type transform
BinaryOperator<T> T apply(T a, T b) reduce step

Specialised primitive versions exist (IntFunction, ToIntFunction, IntPredicate...) to avoid boxing in hot loops.

Optional<T>

Wraps a possibly-absent value — preferable to returning null.

Chapter 13 — Collections

Terminology

  • Collection<E> — root interface for groups of elements (List, Set, Queue).
  • Map<K, V> — key-value lookups (not a Collection).
  • Iterable<E> — anything iterable with for (... : x).

The interface hierarchy

Concrete classes

Interface Implementation When
List ArrayList default; O(1) index, O(n) middle insert
List LinkedList many insertions / deletions in middle (rarely the right choice in practice)
Set HashSet unordered, O(1) average ops
Set LinkedHashSet insertion-ordered
Set TreeSet sorted, O(log n)
Map HashMap unordered, O(1) average
Map LinkedHashMap insertion-ordered
Map TreeMap sorted by key, O(log n)
Map ConcurrentHashMap thread-safe
Queue / Deque ArrayDeque preferred over Stack and LinkedList
Queue PriorityQueue min-heap by natural / comparator order

Common operations

Factory + immutable collections (Java 9+)

Use immutable factories for shared constants — safer + slightly faster.

Iteration

Trick: for-each uses the iterator and so will throw ConcurrentModificationException if you mutate the collection inside the loop. Use Iterator.remove() or iterate over a copy if you need to modify.

Chapter 14 — Stream API

A Stream is a sequence of elements supporting bulk operations. Streams don't store data — they consume from a source (collection, array, generator) and produce a result.

Pattern

Operations:

  • Intermediate (return a new Stream): filter, map, flatMap, sorted, distinct, limit, skip, peek.
  • Terminal (consume the stream): collect, count, reduce, forEach, findFirst, findAny, anyMatch, allMatch, noneMatch, min, max, toArray, toList (Java 16+).

Parallel streams

Easy parallelism. Works well for CPU-bound, side-effect-free work over large data. Don't blindly add parallel() to small lists or IO-bound work — overhead can outweigh the benefit. Measure.

Trick: the modern terminal .toList() (Java 16+) replaces .collect(Collectors.toList()) for the common case. Less typing; returns an unmodifiable list.

Where to next

  • Build tools — Maven / Gradle (the toolchain for any non-trivial Java project).
  • Spring Boot — the dominant Java framework for web/services in 2026.
  • JDBC / JPA / Hibernate — database access.
  • Modules (JPMS) — Java 9+ module system.
  • Records + sealed types + pattern matching — modern data-modelling features.
  • Structured concurrency — Java 21+ preview for safer concurrent code.
  • Project Loom / virtual threads — covered briefly in Part 1; worth a deeper post.
