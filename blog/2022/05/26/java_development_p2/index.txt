Part 2 picks up with the application-level toolkit: a graphical user interface (<strong>JavaFX</strong>), event handling, the <strong>functional programming</strong> features added in Java 8 (lambdas, method references, functional interfaces), the <strong>Collections framework</strong> (the standard data structures), and the <strong>Stream API</strong> (declarative bulk operations). <h1 id="Learning-Outcome"><a href="#Learning-Outcome" class="headerlink" title="Learning Outcome"></a>Learning Outcome</h1>
<ul>
<li>Build a basic JavaFX window with controls and a layout container.</li>
<li>Hook up event handlers (button clicks, key presses, observable property changes).</li>
<li>Write lambdas and method references; use the standard functional interfaces.</li>
<li>Choose between <code>ArrayList</code>, <code>LinkedList</code>, <code>HashMap</code>, <code>TreeMap</code>, <code>HashSet</code>, <code>TreeSet</code>, <code>ArrayDeque</code>, <code>PriorityQueue</code>.</li>
<li>Use the Stream API for <code>map / filter / reduce</code>, grouping, sorting, and parallel processing.</li>
<li>Combine functional + streams + collections into clean data pipelines.</li>
</ul>

<h1 id="Chapter-10-—-Graphical-User-Interface-JavaFX"><a href="#Chapter-10-—-Graphical-User-Interface-JavaFX" class="headerlink" title="Chapter 10 — Graphical User Interface (JavaFX)"></a>Chapter 10 — Graphical User Interface (JavaFX)</h1>
<h2 id="Terminology"><a href="#Terminology" class="headerlink" title="Terminology"></a>Terminology</h2>
<ul>
<li><strong>Stage</strong> — a top-level window.</li>
<li><strong>Scene</strong> — the content of a stage; holds a scene graph.</li>
<li><strong>Node</strong> — anything in the scene graph (controls, shapes, layouts).</li>
<li><strong>Layout (Pane)</strong> — a Node that arranges children (<code>VBox</code>, <code>HBox</code>, <code>GridPane</code>, <code>BorderPane</code>, <code>StackPane</code>).</li>
<li><strong>Control</strong> — interactive widget (<code>Button</code>, <code>Label</code>, <code>TextField</code>, <code>TableView</code>, etc.).</li>
</ul>
<p>JavaFX is the <strong>modern</strong> Java GUI (since 2008); Swing is the older one but still around in some enterprise code. Pick JavaFX for new work.</p>
<h2 id="Setup"><a href="#Setup" class="headerlink" title="Setup"></a>Setup</h2>
<p>JavaFX is no longer bundled with the JDK. Add it via:</p>
<ul>
<li><strong>Maven / Gradle dependency</strong> — <code>org.openjfx:javafx-controls:21</code>.</li>
<li>Or download the SDK from <a href="https://openjfx.io/" target="_blank" rel="noopener external nofollow noreferrer">openjfx.io</a> and run with <code>--module-path &lt;sdk&gt;/lib --add-modules javafx.controls</code>.</li>
</ul>

<h2 id="Threading-rule"><a href="#Threading-rule" class="headerlink" title="Threading rule"></a>Threading rule</h2>
<p>All scene-graph changes must happen on the <strong>JavaFX Application Thread</strong>. From a background thread, use:</p>
<pre><code class="language-java"><figure class="highlight java"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span></pre></td><td class="code"><pre><code class="java"><span class="line">Platform.runLater(() -&gt; label.setText(<span class="hljs-string">&quot;done&quot;</span>));</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>For longer work, use a <code>Task&lt;T&gt;</code> which runs <code>call()</code> on a background thread and exposes <code>succeeded</code>/<code>failed</code> callbacks on the JavaFX thread.</p>

<h1 id="Chapter-14-—-Stream-API"><a href="#Chapter-14-—-Stream-API" class="headerlink" title="Chapter 14 — Stream API"></a>Chapter 14 — Stream API</h1>
<p>A <strong>Stream</strong> is a sequence of elements supporting bulk operations. Streams don't store data — they consume from a source (collection, array, generator) and produce a result.</p>
<h2 id="Pattern"><a href="#Pattern" class="headerlink" title="Pattern"></a>Pattern</h2>
<pre><code class="language-text"><figure class="highlight text"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span></pre></td><td class="code"><pre><code class="text"><span class="line">source → intermediate operations (lazy) → terminal operation</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Operations:</p>
<ul>
<li><strong>Intermediate</strong> (return a new Stream): <code>filter</code>, <code>map</code>, <code>flatMap</code>, <code>sorted</code>, <code>distinct</code>, <code>limit</code>, <code>skip</code>, <code>peek</code>.</li>
<li><strong>Terminal</strong> (consume the stream): <code>collect</code>, <code>count</code>, <code>reduce</code>, <code>forEach</code>, <code>findFirst</code>, <code>findAny</code>, <code>anyMatch</code>, <code>allMatch</code>, <code>noneMatch</code>, <code>min</code>, <code>max</code>, <code>toArray</code>, <code>toList</code> (Java 16+).</li>
</ul>
