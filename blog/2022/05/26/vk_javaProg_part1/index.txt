<p><strong>如何在不使用開發軟件的前提下,單獨運行 Java 檔案</strong></p>
<ol>
<li>首先你的裝置上必須安裝了 JDK</li>
<li>手上持有 Java 檔案,例: [檔案名稱].java</li>
<li>打開命令提示元 CMD 並輸入 <strong>cd [檔案位置]</strong> 將目標位置設定在檔案文件夾</li>
<li>輸入 <strong>javac [檔案名稱].java</strong> 以創建執行 Java 用的檔案 <strong>[檔案名稱].class</strong></li>
<li>最後在命令提示元中輸入 <strong>java [檔案名稱].java</strong> 即可</li>
</ol>

<p><strong>如何單獨運行 Java 檔案並附帶參數 Parameter</strong></p>

<li>在最後一步的指令後方添加任意Parameters<br>
<strong>java [檔案名稱].java &lt;parameter1&gt; &lt;parameter2&gt; &lt;...&gt;</strong><br>

</li>
</ol>

<h1 id="章節二-Objects-Oriented-Programming-OOP"><a href="#章節二-Objects-Oriented-Programming-OOP" class="headerlink" title="章節二 - Objects Oriented Programming (OOP)"></a>章節二 - Objects Oriented Programming (OOP)</h1>
<p>Java 開發的核心基本圍繞在 Object, 而 Object 的原型就是 Class</p>
<h2 id="甚麼是-Class"><a href="#甚麼是-Class" class="headerlink" title="甚麼是 Class"></a>甚麼是 Class</h2>

<h3 id="Class-type-種類"><a href="#Class-type-種類" class="headerlink" title="Class type 種類"></a>Class type 種類</h3>
<p>不同的種類會導致不同的存取權限<br>
分類不限於 Class ,更能用在 Variable 和 Method 上</p>
<ul>
<li>Public (最大權限)<br>
Project內任何檔案都能存取</li>
<li>Protected<br>
同一 Class, Package, 其他 Package 的 Subclass 能存取</li>
<li>Default<br>
僅限同一 Class, Package 能存取</li>
<li>Private (最小權限)<br>
僅限同一 Class 能存取</li>
</ul>
<p>例子</p>
