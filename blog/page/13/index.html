MongoDB Course — 23 · Migrating from SQL / Postgres to MongoDB
Created2025-07-11|Database MongoDB
You have a Postgres / MySQL / Oracle workload. You want to move it to MongoDB — perhaps because the access pattern is document-shaped, the schema is changing too fast for migrations, or scaling write throughput requires sharding. The migration is half schema redesign, half data movement, half cut-over choreography. This post is the playbook: schema-mapping principles, data-load tooling (mongoimport, AWS DMS, Striim, custom ETL), dual-write strategies, staged cut-over, rollback plan, and the common traps. > Series map: 20 Outbox → 21 CQRS+ES → 22 RAG → 23 SQL→Mongo migration (this post) → 24 Kafka + Debezium → … → 29 K8s + mongosync + cost. Learning Outcome - Decide whether the workload should move at all (and which parts).- Map relational schema to document model using Post 07's patterns.- Choose a data-movement strategy (full reload, dual-write, change-data-capture).- Implement the staged cut-over with rollback gates.- Avoid the 6 most common migration disasters. Chapter 1 — Should you migrate? Honest answer first: most SQL workloads should stay on SQL. Migration is expensive + risky. Strong reasons to move: - Schema flexibility required (per-tenant custom fields, fast product iteration, polymorphic items).- Write throughput beyond what Postgres can vertical-scale.- Hierarchical / document-shaped data (forms, content, configs, complex products) that's painful to join.- Horizontal scaling + multi-region + sharding required.- Operational simplicity at low ops headcount (Atlas managed > self-hosted Postgres cluster). Weak reasons: - "NoSQL is modern."- "We want to avoid joins" (you'll write joins as either way).- "We need higher performance" (often a Postgres index would have fixed it). Often the right answer is migrate a subset — the parts where the document model genuinely fits — and keep the rest in Postgres. The two coexist via outbox / CDC / app-side composition. Chapter 2 — Schema mapping principles Re-read Post 07 (Schema Design). Strategy A — Full reload (hours of downtime) 1. Freeze writes to source.2. Extract source → transform → load into Mongo.3. Cut DNS / connection string over.4. Resume writes against Mongo. OK for: < 100 GB and you can take a maintenance window. Strategy B — Dual-write at app layer (low downtime) 1. App writes to both Postgres + Mongo for new operations.2. Backfill historical data via ETL.3. Read-shadow: in parallel with reads from Postgres, fetch from Mongo + log differences.4. Switch reads to Mongo when shadow shows parity.5. Stop writes to Postgres. OK for: medium-size apps where you control the write path. Strategy C — CDC-driven (best for large, can't-downtime) 1. Tail Postgres WAL via Debezium (or AWS DMS, Striim, Estuary, Airbyte).2. Transform + write to Mongo continuously.3. After sync catches up + remains in sync for a while, cut reads over.4. After cut-over, drain Postgres writes; flip back-flow off. OK for: large databases, strict uptime requirements, polyglot teams. Strategy D — Strangler fig - New features write to Mongo only.- Old features stay on Postgres.- Migrate one feature at a time over months. OK for: legacy systems where a big-bang move is too risky. MongoDB Course — 21 · CQRS + Event Sourcing on MongoDB
Created2025-07-08|Database MongoDB
CQRS (Command Query Responsibility Segregation) separates write models from read models. Event Sourcing treats the immutable event log as the source of truth — current state is a projection of replayed events. Both are architectural patterns, not Mongo features — but MongoDB fits them especially well: change streams as the projection bus (Post 12), for materialised views (Post 06), aggregation for replaying events, transactions for atomic event-store appends (Post 09). This post covers when each pays off, the canonical models, the trade-offs vs CRUD, and a worked order-management example end-to-end. > Series map: 19 Beanie+FastAPI → 20 Outbox → 21 CQRS + Event Sourcing (this post) → 22 RAG → ... → 29 K8s + mongosync + cost. Learning Outcome - Define CQRS and recognise when it earns its complexity.- Define Event Sourcing and the event-store schema in MongoDB.- Project events into read models via change streams.- Replay history for new projections + bug fixes.- Handle snapshots + projection rebuilds.- Combine outbox + CQRS + ES into a clean architecture. Chapter 1 — CQRS in one paragraph A normal CRUD app uses one model for reads and writes — same schema, same indexes, same database. CQRS splits them: command side handles writes (often normalised, validated, transactional), query side holds one or more read models optimised per use case (denormalised, fast). The read models are updated by events the command side publishes — usually asynchronously. Benefit: - Read models match exactly the queries they serve → simple + fast.- Read + write scale independently.- Multiple read models per command model (one for search, one for analytics, one for a mobile API). Cost: - More moving parts.- Read-after-write delay (eventual consistency).- Operational complexity. Use CQRS when one of: read volume >> write volume; queries diverge wildly from write shape; you already need an outbox + projections. Chapter 2 — Event Sourcing in one paragraph Instead of storing current state, store every change as an immutable event. Current state is computed by replaying events. Events are append-only — the most reliable storage primitive in databases. Benefits: - Full audit trail for free.- New projections retroactively built from history.- Bug fixes can replay events through corrected code.- Time-travel debugging. Costs: - Reads must aggregate events (use snapshots + projections).- Schema evolution of events is forever — versioning matters.- Higher mental + ops load than CRUD. Linear Algebra — 03 · Linear Maps, Change of Basis and Determinants
Created2025-07-04|Mathematics Linear Algebra
Up to now a matrix has been a table of numbers that you multiply and row-reduce. This post changes the point of view: a matrix is only a description of a linear map, written in one particular pair of bases. Change the bases and the same map gets a different matrix. That idea explains why rank, trace and determinant are "real" properties of a map while individual entries are not, and it is the doorway to eigenvalues in the next post. The second half of the post builds the determinant from three simple rules, proves the key facts (product rule, invertibility test, Cramer's rule), and shows what the number means geometrically: the factor by which a map scales area or volume, with a sign for orientation. > Series map: 00 Vectors & Linear Systems → 01 Matrix Algebra, Inverses & LU → 02 Vector Spaces, Basis & Dimension → 03 Linear Maps, Change of Basis & Determinants (this post) → 04 Eigenvalues & Diagonalization → 05 Inner Products, Spectral Theorem & SVD. Learning Outcome - Decide whether a given function between vector spaces is linear, and find its kernel and image.- State and prove the rank–nullity theorem for linear maps, and use it to relate injective, surjective and invertible.- Write the matrix of a linear map relative to any bases, and explain why composition of maps is the matrix product.- Convert coordinates between bases, and compute the matrix of a map in a new basis with $P^{-1}AP$.- Recognise rotations, reflections, shears, projections and scalings in $\mathbb{R}^2$ from their matrices.- Define the determinant by its three axioms, compute it by cofactor expansion and by elimination, and prove $\det(AB) = \det A \det B$.- Interpret $\lvert\det A\rvert$ as a volume scaling factor and the sign of $\det A$ as orientation.- Solve small systems with Cramer's rule, and explain why it is not used for large ones. Chapter 1 — Linear maps Terminology - Vector space $V$ over $\mathbb{R}$ — as in Linear Algebra 02: a set with addition and scalar multiplication obeying the eight axioms. Everything in this post also works over $\mathbb{C}$ or any field.- Linear map (linear transformation) $T: V \to W$ — a function that respects addition and scalar multiplication (definition below). When $V = W$ it is also called a linear operator on $V$.- Domain $V$ and codomain $W$ — where inputs live and where outputs are allowed to land.- Kernel (null space) $\ker T = \{v \in V : T(v) = 0\}$.- Image (range) $\operatorname{im} T = \{T(v) : v \in V\}$.- Rank of $T$ — $\dim \operatorname{im} T$. Nullity of $T$ — $\dim \ker T$.- Injective (one-to-one) — $T(u) = T(v)$ implies $u = v$. Surjective (onto) — $\operatorname{im} T = W$. Bijective — both.- Isomorphism — a bijective linear map. $V$ and $W$ are isomorphic, written $V \cong W$, if an isomorphism exists.- $Pn$ — polynomials of degree at most $n$ with real coefficients; $\dim Pn = n + 1$. Definition A function $T: V \to W$ is linear if for all $u, v \in V$ and all scalars $c$: $$T(u + v) = T(u) + T(v), \qquad T(cv) = c\,T(v).$$ The two conditions combine into one: $T(c1 v1 + c2 v2) = c1 T(v1) + c2 T(v2)$. By induction, a linear map sends every linear combination to the same combination of the images. Taking $c = 0$ gives $T(0) = 0$: a linear map always sends zero to zero. Examples: 1. Matrix maps. For an $m \times n$ matrix $A$, the map $TA: \mathbb{R}^n \to \mathbb{R}^m$, $TA(x) = Ax$, is linear because $A(u+v) = Au + Av$ and $A(cv) = cAv$ (Linear Algebra 01).2. Differentiation. $D: P3 \to P2$, $D(p) = p'$. The sum rule and the constant-multiple rule of calculus are exactly the two linearity conditions.3. Integration. $I: C[0,1] \to \mathbb{R}$, $I(f) = \int0^1 f(x)\,dx$, where $C[0,1]$ is the space of continuous functions on $[0,1]$.4. Evaluation. $E: P2 \to \mathbb{R}^2$, $E(p) = (p(0), p(1))$.5. Transpose. $M \mapsto M^T$ from $m \times n$ matrices to $n \times m$ matrices. Non-examples: - Translation $T(x) = x + b$ with $b \neq 0$: $T(0) = b \neq 0$, so it is not linear. (It is called affine.)- $T(x, y) = (x + y, xy)$: $T(2 \cdot (1,1)) = (4, 4)$ but $2\,T(1,1) = (4, 2)$.- $T(x) = \lvert x\rvert$ on $\mathbb{R}$: $T(-1) = 1 \neq -T(1)$. > Trick: To show a map is not linear, one counterexample is enough — and checking $T(0) = 0$ first catches many cases in one line. To show a map is linear, you must check both conditions for arbitrary inputs. A linear map is fixed by what it does to a basis Theorem 1. Let $b1, \dots, bn$ be a basis of $V$ and let $w1, \dots, wn$ be any vectors in $W$. There is exactly one linear map $T: V \to W$ with $T(bi) = wi$ for every $i$. Proof. Every $v \in V$ has unique coordinates: $v = c1 b1 + \dots + cn bn$ (Linear Algebra 02). Define $T(v) = c1 w1 + \dots + cn wn$. This is well defined because the coordinates are unique. It is linear: if $v$ has coordinates $ci$ and $u$ has coordinates $di$, then $u + v$ has coordinates $ci + di$ and $kv$ has coordinates $kci$, and the formula is linear in the coordinates. It sends $bi$ to $wi$. For uniqueness, any linear $S$ with $S(bi) = wi$ satisfies $S(v) = \sum ci S(bi) = \sum ci wi = T(v)$. ∎ This theorem is the reason matrices work at all: to store a linear map you only need to store $n$ vectors, the images of the basis vectors. Chapter 2 — Kernel, image and rank–nullity Kernel and image are subspaces Proposition 2. For linear $T: V \to W$, $\ker T$ is a subspace of $V$ and $\operatorname{im} T$ is a subspace of $W$. Proof. $T(0) = 0$, so $0$ is in both. If $T(u) = T(v) = 0$ then $T(u + cv) = 0 + c \cdot 0 = 0$, so the kernel is closed under addition and scaling. If $w1 = T(v1)$ and $w2 = T(v2)$ then $w1 + c w2 = T(v1 + c v2)$ is also in the image. ∎ For a matrix map $TA$, the kernel is the null space $N(A)$ and the image is the column space $C(A)$ from Linear Algebra 02. Proposition 3. $T$ is injective if and only if $\ker T = \{0\}$. Proof. If $T$ is injective and $T(v) = 0 = T(0)$, then $v = 0$. Conversely, if $\ker T = \{0\}$ and $T(u) = T(v)$, then $T(u - v) = 0$, so $u - v = 0$. ∎ > Watch out: "The only solution of $T(v) = 0$ is $v = 0$" is a statement about one equation, but it controls every equation $T(v) = w$: each one then has at most one solution. This is the map version of "no free variables" from Linear Algebra 00. Rank–nullity for linear maps Linear Algebra 02 proved $\operatorname{rank} A + \dim N(A) = n$ for an $m \times n$ matrix by counting pivot and free columns. Here is the version for maps, with a proof that uses no matrices at all. Theorem 4 (rank–nullity). Let $V$ be finite-dimensional and $T: V \to W$ linear. Then $\operatorname{im} T$ is finite-dimensional and $$\dim V = \dim \ker T + \dim \operatorname{im} T.$$ Proof. $\ker T$ is a subspace of the finite-dimensional space $V$, so it has a basis $u1, \dots, uk$ (possibly $k = 0$). By the basis-extension theorem of Linear Algebra 02, extend it to a basis $u1, \dots, uk, w1, \dots, wr$ of $V$, so $\dim V = k + r$. We show that $T(w1), \dots, T(wr)$ is a basis of $\operatorname{im} T$; then $\dim \operatorname{im} T = r$ and we are done. Spanning. Any vector in the image is $T(v)$ for some $v = \sum ai ui + \sum bj wj$. Since $T(ui) = 0$, we get $T(v) = \sum bj T(wj)$. Independence. Suppose $\sum cj T(wj) = 0$. Then $T\left(\sum cj wj\right) = 0$, so $\sum cj wj \in \ker T$ and can be written as $\sum di ui$. Then $\sum cj wj - \sum di ui = 0$ is a linear relation among the basis vectors of $V$, so every $cj$ (and every $di$) is zero. ∎ Worked example. $T: \mathbb{R}^3 \to \mathbb{R}^2$, $T(x, y, z) = (x + 2y - z,\ 2x + 4y + z)$. Its matrix is $$A = \begin{pmatrix} 1 & 2 & -1 \\ 2 & 4 & 1 \end{pmatrix}.$$ Solving $T(v) = 0$: adding the two equations gives $3x + 6y = 0$, so $x = -2y$, and then $z = x + 2y = 0$. The kernel is the line spanned by $(-2, 1, 0)$, so the nullity is 1. Rank–nullity forces $\dim \operatorname{im} T = 3 - 1 = 2$, so the image is all of $\mathbb{R}^2$: $T$ is surjective but not injective. Worked example (no matrix in sight). $D: P3 \to P2$, $D(p) = p'$. The kernel is the constant polynomials (dimension 1). Every $q \in P2$ is the derivative of some cubic, so the image is $P2$ (dimension 3). Check: $4 = 1 + 3$. Consequences Corollary 5. Let $T: V \to W$ be linear with $V, W$ finite-dimensional. 1. If $\dim V > \dim W$, then $T$ is not injective (the kernel has dimension at least $\dim V - \dim W > 0$).2. If $\dim V < \dim W$, then $T$ is not surjective (the image has dimension at most $\dim V$).3. If $\dim V = \dim W$, then $T$ injective $\iff$ $T$ surjective $\iff$ $T$ is an isomorphism. Proof of 3. Injective means $\dim \ker T = 0$, which by rank–nullity means $\dim \operatorname{im} T = \dim V = \dim W$, which means $\operatorname{im} T = W$ (a subspace of full dimension is the whole space). ∎ Part 3 is the abstract form of the invertible matrix theorem from Linear Algebra 01: for a square matrix, "only the trivial solution" and "a solution for every right-hand side" are the same condition. Theorem 6 (classification by dimension). Two finite-dimensional spaces are isomorphic if and only if they have the same dimension. In particular every $n$-dimensional real space is isomorphic to $\mathbb{R}^n$. Proof. An isomorphism sends a basis to a basis (it is injective, so independence is kept, and surjective, so the images span), so dimensions agree. Conversely, if $\dim V = n$ with basis $b1, \dots, bn$, the coordinate map $v \mapsto (c1, \dots, cn)$ is linear, injective and surjective. Composing two such maps gives $V \cong \mathbb{R}^n \cong W$. ∎ The inverse of an isomorphism is automatically linear: if $T(u') = u$ and $T(v') = v$, then $T(u' + cv') = u + cv$, so $T^{-1}(u + cv) = T^{-1}(u) + cT^{-1}(v)$. > Common pitfall: Isomorphic does not mean equal. $P2$ and $\mathbb{R}^3$ are isomorphic, but the isomorphism depends on a choice of basis. There is no single "correct" identification — which is exactly why the next chapter keeps track of bases. Chapter 3 — The matrix of a linear map Coordinates Fix an ordered basis $\mathcal{B} = (b1, \dots, bn)$ of $V$. The coordinate vector of $v$ is the column $[v]{\mathcal{B}} = (c1, \dots, cn)^T$ with $v = \sum ci bi$. The map $v \mapsto [v]{\mathcal{B}}$ is the isomorphism $V \to \mathbb{R}^n$ of Theorem 6. Order matters: swapping $b1$ and $b2$ swaps the first two coordinates. The matrix relative to two bases Let $T: V \to W$ be linear, with basis $\mathcal{B} = (b1, \dots, bn)$ of $V$ and $\mathcal{C} = (c1, \dots, cm)$ of $W$. The matrix of $T$ relative to $\mathcal{B}$ and $\mathcal{C}$ is the $m \times n$ matrix $$[T]{\mathcal{C} \leftarrow \mathcal{B}} = \Big( [T(b1)]{\mathcal{C}} \ \ [T(b2)]{\mathcal{C}} \ \ \cdots \ \ [T(bn)]{\mathcal{C}} \Big).$$ Column $j$ = the $\mathcal{C}$-coordinates of the image of the $j$-th basis vector. With it, applying $T$ becomes matrix multiplication on coordinates: $$[T(v)]{\mathcal{C}} = [T]{\mathcal{C} \leftarrow \mathcal{B}}\, [v]{\mathcal{B}}.$$ Why: if $v = \sum xj bj$ then $T(v) = \sum xj T(bj)$, and taking $\mathcal{C}$-coordinates (a linear operation) gives $\sum xj [T(bj)]{\mathcal{C}}$, which is the matrix times the column $x$. The arrow notation $\mathcal{C} \leftarrow \mathcal{B}$ reads right to left: coordinates in $\mathcal{B}$ go in, coordinates in $\mathcal{C}$ come out. When $V = W$ and the same basis is used on both sides, write $[T]{\mathcal{B}}$. Worked example. $D: P3 \to P2$ with bases $(1, x, x^2, x^3)$ and $(1, x, x^2)$. The images of the basis vectors are $0,\ 1,\ 2x,\ 3x^2$, whose coordinates are the columns: $$[D] = \begin{pmatrix} 0 & 1 & 0 & 0 \\ 0 & 0 & 2 & 0 \\ 0 & 0 & 0 & 3 \end{pmatrix}.$$ Check with $p = 1 + 2x - x^2 + 4x^3$: $[D]\,(1, 2, -1, 4)^T = (2, -2, 12)^T$, and indeed $p' = 2 - 2x + 12x^2$. The matrix has rank 3 and a one-dimensional null space spanned by $(1,0,0,0)^T$ — the constant polynomial 1 — matching the rank–nullity count above. Composition is the matrix product Theorem 7. Let $T: U \to V$ and $S: V \to W$ be linear, with bases $\mathcal{B}, \mathcal{C}, \mathcal{D}$ of $U, V, W$. Then $$[S \circ T]{\mathcal{D} \leftarrow \mathcal{B}} = [S]{\mathcal{D} \leftarrow \mathcal{C}}\ [T]{\mathcal{C} \leftarrow \mathcal{B}}.$$ Proof. For every $u \in U$: $[S(T(u))]{\mathcal{D}} = [S]\,[T(u)]{\mathcal{C}} = [S]\,[T]\,[u]{\mathcal{B}}$. Taking $u = bj$ (so $[u]{\mathcal{B}}$ is the $j$-th standard column) shows that column $j$ of $[S \circ T]$ equals column $j$ of $[S][T]$. ∎ This is why matrix multiplication is defined the strange row-times-column way: it is the only definition that makes "do $T$, then do $S$" correspond to a product. It also explains why the product is associative (composition of functions is) and generally not commutative (doing things in a different order usually gives a different result). The order is right to left: in $ST$, $T$ acts first. Two consequences follow at once. $T$ is an isomorphism if and only if its matrix (in any bases) is invertible, and then $[T^{-1}]{\mathcal{B} \leftarrow \mathcal{C}} = \left([T]{\mathcal{C} \leftarrow \mathcal{B}}\right)^{-1}$. And the rank of $T$ equals the rank of any matrix that represents it. Chapter 4 — Change of basis and similarity The change-of-basis matrix Let $\mathcal{E}$ be the standard basis of $\mathbb{R}^n$ and $\mathcal{B} = (b1, \dots, bn)$ another basis. Put the new basis vectors, written in standard coordinates, into the columns of $$P = P{\mathcal{E} \leftarrow \mathcal{B}} = \big( b1 \ \ b2 \ \ \cdots \ \ bn \big).$$ Then $v = \sum ci bi = P\,[v]{\mathcal{B}}$, that is $$[v]{\mathcal{E}} = P\,[v]{\mathcal{B}}, \qquad [v]{\mathcal{B}} = P^{-1}[v]{\mathcal{E}}.$$ $P$ is invertible because its columns are a basis. $P$ is simply the matrix of the identity map, $[\mathrm{id}]{\mathcal{E} \leftarrow \mathcal{B}}$: it takes $\mathcal{B}$-coordinates in and gives $\mathcal{E}$-coordinates out. > Common pitfall: The matrix whose columns are the new basis vectors converts new coordinates to old, not old to new. To get new coordinates you must solve $P c = v$ (or apply $P^{-1}$). Writing the arrow $\mathcal{E} \leftarrow \mathcal{B}$ on every change-of-basis matrix prevents this mistake. The same map in a new basis Let $T: \mathbb{R}^n \to \mathbb{R}^n$ have standard matrix $A = [T]{\mathcal{E}}$. Its matrix in the basis $\mathcal{B}$ is found by composing: convert $\mathcal{B}$-coordinates to standard ($P$), apply $T$ ($A$), convert back ($P^{-1}$): $$[T]{\mathcal{B}} = P^{-1} A P.$$ This is Theorem 7 applied to $T = \mathrm{id} \circ T \circ \mathrm{id}$. For a map between different spaces, with change-of-basis matrices $P$ on the domain and $Q$ on the codomain, the rule is $[T]{\mathcal{C}' \leftarrow \mathcal{B}'} = Q^{-1}\,[T]{\mathcal{C} \leftarrow \mathcal{B}}\,P$. Worked example. Let $A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$ and take the basis $b1 = (1, 1)$, $b2 = (1, -1)$. Then $$P = \begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}, \quad P^{-1} = \frac{1}{2}\begin{pmatrix} 1 & 1 \\ 1 & -1 \end{pmatrix}, \quad P^{-1}AP = \begin{pmatrix} 3 & 0 \\ 0 & 1 \end{pmatrix}.$$ You can see the diagonal answer directly: $Ab1 = (3, 3) = 3b1$ and $Ab2 = (1, -1) = b2$. In the new basis the map just stretches the $b1$ direction by 3 and leaves the $b2$ direction alone. Now track one vector. $v = (5, 1)$ has $[v]{\mathcal{B}} = P^{-1}v = (3, 2)$, because $3(1,1) + 2(1,-1) = (5, 1)$. In new coordinates the map gives $\operatorname{diag}(3,1)\,(3,2)^T = (9, 2)^T$, and $9(1,1) + 2(1,-1) = (11, 7) = Av$. The two routes agree. Choosing a basis that makes the matrix diagonal is the whole subject of Linear Algebra 04: $b1$ and $b2$ here are eigenvectors. Similarity Square matrices $A$ and $B$ are similar if $B = P^{-1}AP$ for some invertible $P$. Similar matrices are the same linear operator written in two bases. Similarity is an equivalence relation (reflexive with $P = I$, symmetric with $P^{-1}$, transitive with $PQ$). Anything defined for the operator rather than the table of numbers must be the same for similar matrices. Such quantities are called similarity invariants: | Invariant | Why it survives $A \mapsto P^{-1}AP$ ||-----------|--------------------------------------|| Rank | rank of the map, which does not depend on coordinates || Trace | $\operatorname{tr}(XY) = \operatorname{tr}(YX)$, so $\operatorname{tr}(P^{-1}(AP)) = \operatorname{tr}((AP)P^{-1})$ || Determinant | product rule (Chapter 6): $\det P^{-1} \det A \det P = \det A$ || Characteristic polynomial, eigenvalues | Linear Algebra 04 | The trace identity is a one-line calculation: $\operatorname{tr}(XY) = \sumi \sumj x{ij} y{ji} = \sumj \sumi y{ji} x{ij} = \operatorname{tr}(YX)$. Check the example: $\operatorname{tr}A = 4 = 3 + 1$. > Watch out: Equal invariants do not prove similarity. $I = \begin{pmatrix} 1 & 0 \\ 0 & 1\end{pmatrix}$ and $\begin{pmatrix} 1 & 1 \\ 0 & 1\end{pmatrix}$ have the same rank, trace and determinant, but only $I$ is similar to $I$ (because $P^{-1}IP = I$ for every $P$). Chapter 6 — The determinant Terminology - Multilinear (in the rows) — linear in each row separately when the other rows are held fixed.- Alternating — the value is $0$ whenever two rows are equal.- Permutation of $\{1, \dots, n\}$ — a bijection $\sigma$ of the set to itself; $Sn$ is the set of all $n!$ of them.- Sign $\operatorname{sgn}(\sigma)$ — $+1$ if $\sigma$ is a product of an even number of swaps, $-1$ if odd. Equivalently $(-1)^{\text{number of inversions}}$, where an inversion is a pair $i < j$ with $\sigma(i) > \sigma(j)$.- Minor $M{ij}$ — the determinant of the $(n-1) \times (n-1)$ matrix left after deleting row $i$ and column $j$. Cofactor $C{ij} = (-1)^{i+j} M{ij}$. The three axioms For $2 \times 2$ matrices you know $\det \begin{pmatrix} a & b \\ c & d \end{pmatrix} = ad - bc$. The clean way to generalise is not to guess a formula but to list the properties we want and prove that exactly one function has them. A function $D$ from $n \times n$ matrices to $\mathbb{R}$ is a determinant function if: 1. (Multilinear) $D$ is linear in each row: $D(\dots, u + cv, \dots) = D(\dots, u, \dots) + c\,D(\dots, v, \dots)$, other rows fixed.2. (Alternating) $D(A) = 0$ if two rows of $A$ are equal.3. (Normalised) $D(I) = 1$. Theorem 8 (existence and uniqueness). There is exactly one determinant function, written $\det$. Moreover, any function $D$ satisfying axioms 1 and 2 (but not necessarily 3) equals $D(I) \cdot \det$. Existence is shown by checking that the Leibniz formula below satisfies the three axioms; uniqueness follows because the axioms alone determine the value on every matrix, as the row-operation rules show. A full proof is in Axler (Chapter 9) or Hoffman and Kunze (Chapter 5); here we state it and use it. What the axioms force: row operations From the axioms alone: - Swapping two rows changes the sign. Put $u + v$ in both rows $i$ and $j$. By axiom 2 the value is 0; expanding with axiom 1 gives $D(u,u) + D(u,v) + D(v,u) + D(v,v) = 0$ (other rows omitted), and the first and last terms are 0, so $D(u,v) = -D(v,u)$.- Scaling one row by $c$ multiplies the determinant by $c$ (axiom 1).- Adding a multiple of one row to another leaves the determinant unchanged: $D(\dots, u + cv, \dots, v, \dots) = D(\dots, u, \dots, v, \dots) + c\,D(\dots, v, \dots, v, \dots)$, and the last term is 0.- A zero row gives determinant 0 (scale that row by 0).- A triangular matrix has determinant = product of its diagonal entries. If all diagonal entries are nonzero, row replacements clear the off-diagonal entries without changing $D$, leaving a diagonal matrix, and axiom 1 plus axiom 3 give the product. If a diagonal entry is zero, elimination produces a zero row, so both sides are 0. These rules are also the fastest way to compute: row-reduce to triangular form, keeping track of swaps and scalings. Leibniz formula and cofactor expansion Leibniz formula. $$\det A = \sum{\sigma \in Sn} \operatorname{sgn}(\sigma)\, a{1\sigma(1)}\, a{2\sigma(2)} \cdots a{n\sigma(n)}.$$ Each term picks one entry from every row and every column. For $n = 2$ there are two terms, $a{11}a{22} - a{12}a{21}$. For $n = 3$ there are six: $$\det A = a{11}a{22}a{33} + a{12}a{23}a{31} + a{13}a{21}a{32} - a{13}a{22}a{31} - a{11}a{23}a{32} - a{12}a{21}a{33}.$$ Cofactor (Laplace) expansion along row $i$ or column $j$: $$\det A = \sum{j=1}^{n} a{ij} C{ij} \quad \text{(row } i\text{)}, \qquad \det A = \sum{i=1}^{n} a{ij} C{ij} \quad \text{(column } j\text{)}.$$ The signs $(-1)^{i+j}$ follow a checkerboard starting with $+$ in the top-left corner. Expand along the row or column with the most zeros. Worked example — three ways. Let $$M = \begin{pmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \\ 7 & 8 & 10 \end{pmatrix}.$$ Cofactor expansion along row 1: $$\det M = 1(5 \cdot 10 - 6 \cdot 8) - 2(4 \cdot 10 - 6 \cdot 7) + 3(4 \cdot 8 - 5 \cdot 7) = 1(2) - 2(-2) + 3(-3) = -3.$$ Leibniz, six terms: $50 + 84 + 96 - 105 - 48 - 80 = 230 - 233 = -3$. Elimination: $R2 - 4R1$ and $R3 - 7R1$ give rows $(0, -3, -6)$ and $(0, -6, -11)$; then $R3 - 2R2$ gives $(0, 0, 1)$. Only row replacements were used, so the determinant is unchanged: $\det M = 1 \cdot (-3) \cdot 1 = -3$. > Watch out: The "diagonals" trick (rule of Sarrus) works for $3 \times 3$ matrices only. For $4 \times 4$ it gives 8 terms, but the determinant has $4! = 24$. The product rule and other properties Theorem 9. $\det(AB) = \det A \cdot \det B$ for all $n \times n$ matrices $A, B$. Proof. Fix $B$ and define $D(A) = \det(AB)$. Row $i$ of $AB$ is (row $i$ of $A$) $\times B$, which is linear in row $i$ of $A$, so $D$ is multilinear in the rows of $A$. If $A$ has two equal rows, so does $AB$, so $D(A) = 0$. By the second part of Theorem 8, $D(A) = D(I)\det A = \det(B)\det(A)$. ∎ Theorem 10. $\det A^T = \det A$. Reason. In the Leibniz formula, the term for $\sigma$ in $\det A^T$ is the term for $\sigma^{-1}$ in $\det A$, and $\operatorname{sgn}(\sigma^{-1}) = \operatorname{sgn}(\sigma)$. As $\sigma$ runs over $Sn$ so does $\sigma^{-1}$. ∎ So every statement about rows also holds for columns: column swaps flip the sign, and so on. Theorem 11 (the invertibility test). A square matrix $A$ is invertible if and only if $\det A \neq 0$. In that case $\det(A^{-1}) = 1/\det A$. Proof. Row-reduce: $Ek \cdots E1 A = R$ with $R$ in reduced row echelon form. Each elementary operation multiplies the determinant by a nonzero number ($-1$, $c \neq 0$, or $1$), so $\det A \neq 0 \iff \det R \neq 0$. A square RREF is either $I$ (determinant 1) or has a zero row (determinant 0), and $R = I$ exactly when $A$ is invertible (Linear Algebra 01). For the formula, $\det A \det A^{-1} = \det I = 1$. ∎ Further consequences: - $\det(cA) = c^n \det A$ for an $n \times n$ matrix (each of the $n$ rows is scaled). For the matrix $M$ above, $\det(2M) = 8 \cdot (-3) = -24$.- Similar matrices have equal determinants, so $\det T$ is well defined for a linear operator $T$: use its matrix in any basis.- For block upper triangular matrices, $\det \begin{pmatrix} A & B \\ 0 & D \end{pmatrix} = \det A \det D$ (with $A$, $D$ square). > Common pitfall: $\det(A + B) \neq \det A + \det B$ in general. Try $A = B = I2$: the left side is $\det(2I) = 4$, the right side is 2. The determinant is multiplicative, not additive. Determinant as signed volume For $n \times n$ $A$ with columns $a1, \dots, an$, the number $\lvert\det A\rvert$ is the volume (area when $n = 2$) of the parallelepiped $\{t1 a1 + \dots + tn an : 0 \le ti \le 1\}$. Why this is plausible: signed volume, as a function of the edge vectors, satisfies the axioms. Scaling one edge by $c$ scales the volume by $c$. Sliding one edge along another (a shear) does not change the volume — Cavalieri's principle, the same reason a slanted stack of coins has the same volume as a straight one. Two equal edges give a flat box of volume 0. The unit cube has volume 1. By uniqueness, signed volume is the determinant. Since $A$ sends the unit cube (volume 1) to this parallelepiped, and the map is linear, $A$ multiplies the volume of every region by $\lvert\det A\rvert$. This is the factor $\lvert\det J\rvert$ in the change-of-variables formula for multiple integrals. The sign records orientation: $\det A > 0$ keeps the order of the edges (counter-clockwise stays counter-clockwise in the plane), $\det A < 0$ reverses it, as a mirror does. $\det A = 0$ means the space is flattened into a lower dimension — and that information cannot be undone, which is Theorem 11 seen geometrically. Example in $\mathbb{R}^3$: the columns $(1,0,0)$, $(1,2,0)$, $(1,1,3)$ form an upper triangular matrix with determinant $1 \cdot 2 \cdot 3 = 6$, so the box they span has volume 6. The figure uses $A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$ ($\det = 3$), the same matrix with its columns swapped, $B = \begin{pmatrix} 1 & 2 \\ 2 & 1 \end{pmatrix}$ ($\det = -3$), and $C = \begin{pmatrix} 2 & 1 \\ 2 & 1 \end{pmatrix}$ ($\det = 0$). $A$ and $B$ produce the same parallelogram, but in $B$ the image of $e1$ has moved to the other side of the image of $e2$: the turn from the first column to the second is clockwise, so the orientation is reversed. That is the column-swap rule, drawn. Chapter 7 — Cramer's rule and the adjugate Theorem 12 (Cramer's rule). If $\det A \neq 0$, the unique solution of $Ax = b$ is $$xi = \frac{\det Ai(b)}{\det A}, \qquad i = 1, \dots, n,$$ where $Ai(b)$ is $A$ with column $i$ replaced by $b$. Proof. Let $Ii(x)$ be the identity matrix with column $i$ replaced by $x$. Then $A\,Ii(x) = Ai(b)$: its columns are $Ae1, \dots, Ax, \dots, Aen$, which are the columns of $A$ with $b = Ax$ in position $i$. Expanding $\det Ii(x)$ along row $i$ gives $xi$. The product rule then gives $\det A \cdot xi = \det Ai(b)$. ∎ Worked example. $2x + y = 5$, $x + 3y = 10$. Here $\det A = 6 - 1 = 5$, and $$x = \frac{\det\begin{pmatrix} 5 & 1 \\ 10 & 3 \end{pmatrix}}{5} = \frac{5}{5} = 1, \qquad y = \frac{\det\begin{pmatrix} 2 & 5 \\ 1 & 10 \end{pmatrix}}{5} = \frac{15}{5} = 3.$$ Check: $2 + 3 = 5$ and $1 + 9 = 10$. The adjugate. Applying Cramer's rule to each column of $AX = I$ gives an explicit inverse: $$A^{-1} = \frac{1}{\det A}\operatorname{adj}(A), \qquad \operatorname{adj}(A){ij} = C{ji}.$$ Note the transpose: entry $(i,j)$ of the adjugate is the cofactor at $(j,i)$. For $2 \times 2$ this is the familiar $\begin{pmatrix} a & b \\ c & d \end{pmatrix}^{-1} = \frac{1}{ad - bc}\begin{pmatrix} d & -b \\ -c & a \end{pmatrix}$. For $M$ above, $$\operatorname{adj}(M) = \begin{pmatrix} 2 & 4 & -3 \\ 2 & -11 & 6 \\ -3 & 6 & -3 \end{pmatrix}, \qquad M^{-1} = -\frac{1}{3}\operatorname{adj}(M) = \begin{pmatrix} -2/3 & -4/3 & 1 \\ -2/3 & 11/3 & -2 \\ 1 & -2 & 1 \end{pmatrix}.$$ Why not Cramer for large systems Cramer's rule is valuable for theory: it shows that each $xi$ is a rational function of the entries of $A$ and $b$, so the solution depends continuously (indeed smoothly) on the data wherever $\det A \neq 0$. As an algorithm it is a bad choice: - The Leibniz formula has $n!$ terms. For $n = 20$ that is $20! = 2\,432\,902\,008\,176\,640\,000 \approx 2.4 \times 10^{18}$ products for a single determinant.- Even computing each determinant by elimination, Cramer needs $n + 1$ determinants, each costing about as much as one full LU factorisation ($\approx \tfrac{2}{3}n^3$ flops). Gaussian elimination solves the system with one factorisation.- Determinants are poor measures of numerical trouble. $\det(0.1\,I{100}) = 10^{-100}$, yet $0.1\,I$ is perfectly well-behaved. Closeness to singularity is measured by the condition number (Linear Algebra 05 and the planned numerical post), not by the size of $\det A$. > Trick: In practice, a determinant is computed from an LU factorisation with partial pivoting, $PA = LU$: $\det A = \pm \prod u{ii}$, the sign coming from the number of row swaps.
