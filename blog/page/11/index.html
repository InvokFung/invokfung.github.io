Chapter 2 — Minor Scales: Three Flavours A minor key has one key signature (the natural minor) but musicians use three common scale shapes built from that signature. In a major key > Trick: in a major key, the primary triads (I, IV, V) are all major chords. Roman numerals are uppercase to show this. The supportive triads (ii, iii, vi) are minor — lowercase. Newer = more features. C++ vs Python (one paragraph) Python is interpreted, dynamically typed, garbage-collected, and slow. C++ is compiled, statically typed, manually memory-managed (with smart-pointer helpers), and fast. Python code reads cleanly with little ceremony; C++ code can be more verbose but exposes what's happening at the machine level. Use C++ when you need raw speed, low memory footprint, hardware access, or you're building infrastructure that other languages will call into. > Trick: don't pick a language; pick a problem. Most real engineers use both — Python for orchestration and analysis, C++ (or Rust) for the hot inner loop.
