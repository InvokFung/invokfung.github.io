PostgreSQL's planner is a cost-based optimizer — it enumerates plan shapes, prices each one using a handful of tunable constants plus the statistics collected by , and executes the cheapest. Almost every "why is this query slow" investigation ends at one of two answers: the cost constants do not describe your hardware, or the row estimates are wrong. Chapter 9 — Materialized views

A materialized view stores the query result on disk. It is the right tool when an expensive aggregate is read far more often than the underlying data changes, and slightly stale results are acceptable.

computes the new contents into a temporary relation and applies the difference, so readers are never blocked. Its requirements: a unique index covering all rows, and a view that has already been populated once. It is slower in wall-clock terms than a plain refresh — it trades throughput for availability.

PostgreSQL has no built-in incremental view maintenance; if refresh cost becomes the bottleneck, the usual answer is a summary table updated by triggers or by a scheduled job that only recomputes recent partitions.

Structure

A PostgreSQL B-tree is a Lehman–Yao B-link tree, built from 8 KB pages:

Numbers worth internalising:

- Each page holds on the order of a few hundred entries for typical key widths, so fanout is a few hundred.- Three levels therefore index roughly a hundred million rows; four levels index far more. Depth grows logarithmically and stays small.- A single-row lookup costs about depth + 1 page reads: one per level down, plus one heap page fetch — and the upper levels are almost always cached.- The maximum index entry is about one third of a page (roughly 2704 bytes at the default 8 KB ). Indexing a long  column fails at insert time when a value exceeds it; index a hash or a truncation instead.- Leaf pages are doubly linked, which is why a range scan (, , ) is cheap once positioned, and why a B-tree can also satisfy  without a sort — in either direction, since it can be walked backwards.

Two modern optimisations that matter operationally:

- Deduplication (PostgreSQL 13+): repeated keys are stored once with a posting list of TIDs. Indexes on low-cardinality columns became dramatically smaller.- Bottom-up index deletion (PostgreSQL 14+): before splitting a page, the index opportunistically removes entries pointing at dead tuples. This substantially slows bloat growth on tables with heavy non- updates.

Chapter 2 — The six index types

B-tree

The default and the right answer for perhaps 90% of indexes: any type with a total order, equality and range predicates, sorting, uniqueness.

Hash

Equality only. WAL-logged and crash-safe since PostgreSQL 10 (before that they were not replicated and had to be rebuilt after a crash, which is why old advice says "never use hash indexes").

Narrower than a B-tree for long keys, since it stores a 32-bit hash rather than the value. In exchange it cannot do ranges, cannot sort, cannot be unique, and cannot be multicolumn. The niche is genuinely narrow: very long keys, equality-only access, no ordering requirement. Benchmark against a B-tree on your own data before committing.

GIN — Generalized Inverted Index

For values that contain multiple searchable items: array elements,  keys and values, full-text lexemes, trigrams.

GIN reads fast and writes slowly, because one row update can touch many index entries. The  mechanism buffers changes in a pending list and flushes them in batches — good for write throughput, but it means a query may have to scan the unflushed pending list, producing occasional latency spikes. Tune with  or set  for read-latency-sensitive workloads.

GiST — Generalized Search Tree

A framework for indexing things without a natural total order: geometry, ranges, nearest-neighbour search, and the exclusion constraints from Post 01.

GiST is lossy: it returns candidate rows that the executor must recheck. That is why a GiST plan shows a .

SP-GiST — Space-Partitioned GiST

For naturally hierarchical, non-balanced partitionings: quadtrees, k-d trees, radix trees. In practice: / containment, points, and text prefix search where a radix tree beats a B-tree on space.

BRIN — Block Range INdex

Stores a summary (by default min/max) for each range of heap pages — 128 pages by default. Consequently it is minuscule: an index over a billion-row table can be a few megabytes.

BRIN only works when the physical row order correlates with the indexed value — append-only time-series data, log tables, tables loaded in key order. If rows are scattered, every block range spans the whole value domain and the index eliminates nothing. Check before building:

Ordering the columns

The rule PostgreSQL practitioners use is the same shape as MongoDB's:

> Equality columns first, then the column you sort by, then the range column last.

That is exactly the ESR rule — Equality, Sort, Range — from the MongoDB indexes post. The reasoning is identical in both engines: a B-tree can only continue using subsequent columns while preceding ones are pinned to single values. Once a range predicate opens up a span of the tree, everything after it in the index is no longer in useful order.

When a sequential scan is correct

This bears stating plainly, because a great deal of wasted tuning effort comes from trying to force an index scan that would be slower.

A sequential scan is the right plan when:

1. The predicate matches a large fraction of the table — beyond roughly 5–10%, random heap fetches through an index exceed the cost of reading everything sequentially. The exact crossover depends on  and physical correlation.2. The table is small. Under a few hundred pages, one sequential read beats index descent plus heap fetch. The planner knows this and is right.3. No index covers the predicate, and creating one is not justified by the query's frequency.4. The query is an aggregate over most of the table —  genuinely must look at everything (or at least at the whole visibility map, via a parallel index-only scan).5. Parallelism applies. A parallel sequential scan across four workers can beat a single-threaded index scan outright.

To diagnose — never to fix in production code:

If the forced index plan is slower, the planner was right and the investigation is over. If it is much faster, you have found a cost-model or statistics problem — which is Post 04's subject.

Chapter 7 — Building and maintaining indexes in production

A plain  takes a lock that blocks all writes to the table for the entire build. On a large busy table that is an outage.

What it costs you:

- Two table scans instead of one, plus a wait for all transactions that could see the table to finish. Substantially slower in wall-clock terms.- It cannot run inside a transaction block — which means migration frameworks that wrap each migration in a transaction need an explicit escape (Rails: ; Django: ; plain SQL: run it as its own statement).- If it fails — a deadlock, a unique violation discovered during the second pass, a cancelled session — it leaves behind an invalid index that is maintained on writes but never used by queries.

(PostgreSQL 12+) rebuilds an existing index without blocking writes, and  removes one the same way. On a replicated setup, build indexes on standbys first only if you are using logical replication — with physical streaming replication the index arrives automatically through WAL.

Index bloat

MVCC leaves dead entries behind;  reclaims space for reuse but does not return it to the operating system, and a B-tree that has churned heavily can end up substantially larger than a freshly built equivalent. Bottom-up index deletion (PG 14+) reduced this markedly, but it did not eliminate it.

The fix is . Do not schedule blanket reindexing "just in case" — it is expensive I/O, and a healthy index does not need it.

Basic CTEs

CTEs make a long query readable by naming its stages, and they can be referenced multiple times. Data-modifying CTEs are a PostgreSQL strength:

The PostgreSQL 12 fencing change

Before PostgreSQL 12, every  clause was an optimisation fence: it was always materialised into a temporary result, and predicates from the outer query could never be pushed into it. That made CTEs a manual planner hint — sometimes helpful, often a performance trap.

Chapter 1 — Inner products and norms

Terminology

- Inner product on a real vector space $V$ — a function $\langle u, v\rangle \in \mathbb{R}$ that is symmetric, linear in each argument, and positive definite (axioms below).- Inner product space — a vector space together with an inner product.- Norm $\lVert v\rVert = \sqrt{\langle v, v\rangle}$ — the length of $v$. A unit vector has norm 1.- Orthogonal — $\langle u, v\rangle = 0$, written $u \perp v$.- Orthonormal list — pairwise orthogonal unit vectors.- Orthogonal complement $W^\perp = \{v : \langle v, w\rangle = 0 \text{ for all } w \in W\}$.- Orthogonal matrix — a square real matrix $Q$ with $Q^TQ = I$.

Axioms and examples

An inner product on a real vector space satisfies, for all $u, v, w$ and scalars $c$:

1. Symmetry: $\langle u, v\rangle = \langle v, u\rangle$.2. Linearity: $\langle u + cv, w\rangle = \langle u, w\rangle + c\langle v, w\rangle$ (and so, by symmetry, linear in the second slot too).3. Positive definiteness: $\langle v, v\rangle \ge 0$, with equality only for $v = 0$.

Examples:

- Dot product on $\mathbb{R}^n$: $\langle x, y\rangle = x^Ty = \sum xi yi$. This is the default in this post.- Weighted dot product: $\langle x, y\rangle = \sum wi xi yi$ with all $wi > 0$. More generally $\langle x, y\rangle = x^TMy$ for any symmetric positive definite $M$ (Chapter 6).- Functions: on $C[0,1]$, $\langle f, g\rangle = \int0^1 f(t)g(t)\,dt$. For example $\langle 1, t - \tfrac12\rangle = \int0^1 (t - \tfrac12)\,dt = 0$: the constant 1 and $t - \frac12$ are orthogonal, and $\lVert t - \tfrac12\rVert^2 = \frac{1}{12}$.- Matrices: $\langle A, B\rangle = \operatorname{tr}(A^TB) = \sum{i,j} a{ij}b{ij}$ (the Frobenius inner product).

Over $\mathbb{C}$ the symmetry axiom becomes $\langle u, v\rangle = \overline{\langle v, u\rangle}$ and the standard product is $\sum xi \overline{yi}$; everything below has a complex version with $A^T$ replaced by the conjugate transpose $A^$.

Cauchy–Schwarz and the triangle inequality

Theorem 1 (Cauchy–Schwarz). $\lvert\langle u, v\rangle\rvert \le \lVert u\rVert\,\lVert v\rVert$, with equality if and only if $u$ and $v$ are linearly dependent.

Proof. If $v = 0$ both sides are 0. Otherwise, for every real $t$,

$$0 \le \lVert u - tv\rVert^2 = \lVert u\rVert^2 - 2t\langle u, v\rangle + t^2\lVert v\rVert^2.$$

A quadratic in $t$ with positive leading coefficient that is never negative has at most one real root, so its discriminant is $\le 0$: $4\langle u, v\rangle^2 - 4\lVert u\rVert^2\lVert v\rVert^2 \le 0$. Equality means the discriminant is 0, so for some $t$ the quadratic is 0, that is $u = tv$; conversely $u = tv$ gives equality directly. ∎

Cauchy–Schwarz makes angles possible: define $\theta \in [0, \pi]$ by $\cos\theta = \frac{\langle u, v\rangle}{\lVert u\rVert\lVert v\rVert}$, a number in $[-1, 1]$. Example: $u = (1, 2, 2)$, $v = (3, 0, 4)$ have $u \cdot v = 11$, $\lVert u\rVert = 3$, $\lVert v\rVert = 5$, so $\cos\theta = 11/15$ and $\theta \approx 42.8°$.

Theorem 2 (triangle inequality). $\lVert u + v\rVert \le \lVert u\rVert + \lVert v\rVert$.

Proof. $\lVert u + v\rVert^2 = \lVert u\rVert^2 + 2\langle u, v\rangle + \lVert v\rVert^2 \le \lVert u\rVert^2 + 2\lVert u\rVert\lVert v\rVert + \lVert v\rVert^2 = (\lVert u\rVert + \lVert v\rVert)^2$, using Cauchy–Schwarz in the middle. Take square roots. ∎

The same expansion gives Pythagoras: if $u \perp v$ then $\lVert u + v\rVert^2 = \lVert u\rVert^2 + \lVert v\rVert^2$.

Chapter 2 — Orthogonality and projection

Orthonormal bases

Proposition 3. An orthogonal list of nonzero vectors is linearly independent.

Proof. If $\sum ci vi = 0$, take the inner product with $vj$: every term except $cj\langle vj, vj\rangle$ vanishes, so $cj\lVert vj\rVert^2 = 0$ and $cj = 0$. ∎

The same computation shows why orthonormal bases are so convenient. If $q1, \dots, qn$ is an orthonormal basis, then for every $v$:

$$v = \sum{i=1}^n \langle v, qi\rangle\, qi, \qquad \lVert v\rVert^2 = \sum{i=1}^n \langle v, qi\rangle^2.$$

Coordinates are just inner products — no linear system to solve. The second formula is Parseval's identity.

Orthogonal projection onto a subspace

Let $W$ be a subspace with orthonormal basis $q1, \dots, qk$. The orthogonal projection of $v$ onto $W$ is

$$PW v = \sum{i=1}^{k} \langle v, qi\rangle\, qi.$$

The residual $v - PW v$ is orthogonal to every $qj$ (take the inner product and use orthonormality), hence to all of $W$. So every $v$ splits uniquely as $v = PW v + (v - PW v)$ with the first part in $W$ and the second in $W^\perp$, and $\dim W + \dim W^\perp = \dim V$.

Theorem 4 (best approximation). $PW v$ is the unique closest point of $W$ to $v$: for every $w \in W$ with $w \neq PW v$,

$$\lVert v - w\rVert > \lVert v - PW v\rVert.$$

Proof. Write $v - w = (v - PW v) + (PW v - w)$. The first part is in $W^\perp$, the second in $W$, so by Pythagoras $\lVert v - w\rVert^2 = \lVert v - PW v\rVert^2 + \lVert PW v - w\rVert^2$, and the last term is positive when $w \neq PW v$. ∎

In matrix form. If $Q$ is the $n \times k$ matrix with orthonormal columns $qi$, then $Q^TQ = Ik$ and the projection matrix is $P = QQ^T$. If the columns of $A$ are any basis of $W$ (not orthonormal), then

$$P = A(A^TA)^{-1}A^T.$$

Every projection matrix satisfies $P^2 = P$ and $P^T = P$. Projection onto a single line through $a$ is $\frac{aa^T}{a^Ta}$; for example the projection of $b = (3, 0, 3)$ onto the line through $a = (1, 2, 2)$ is $\frac{a \cdot b}{a \cdot a}a = \frac{9}{9}a = (1, 2, 2)$, with residual $(2, -2, 1) \perp a$.

> Common pitfall: $\sum \langle v, qi\rangle qi$ is the projection only when the $qi$ are orthonormal. With a non-orthogonal basis, adding up the one-dimensional projections double-counts, and the result is not the closest point. Use $A(A^TA)^{-1}A^T$, or orthonormalise first.

Chapter 3 — Gram–Schmidt and QR

The algorithm

Given independent vectors $v1, \dots, vn$, Gram–Schmidt produces an orthonormal list $q1, \dots, qn$ with the same span at every stage: $\operatorname{span}(q1, \dots, qj) = \operatorname{span}(v1, \dots, vj)$ for each $j$. At step $j$, subtract from $vj$ its projection onto the span of the earlier $q$'s, then normalise:

$$wj = vj - \sum{i < j} \langle vj, qi\rangle\, qi, \qquad qj = \frac{wj}{\lVert wj\rVert}.$$

$wj \neq 0$ because $vj$ is not in the span of $v1, \dots, v{j-1}$. So every finite-dimensional inner product space has an orthonormal basis.

Worked example. $v1 = (1, 1, 0)$, $v2 = (1, 0, 1)$, $v3 = (0, 1, 1)$.

- $q1 = \frac{1}{\sqrt2}(1, 1, 0)$.- $\langle v2, q1\rangle = \frac{1}{\sqrt2}$, so $w2 = (1, 0, 1) - \frac12(1, 1, 0) = (\frac12, -\frac12, 1)$, with $\lVert w2\rVert = \sqrt{3/2}$. Then $q2 = \frac{1}{\sqrt6}(1, -1, 2)$.- $\langle v3, q1\rangle = \frac{1}{\sqrt2}$ and $\langle v3, q2\rangle = \frac{1}{\sqrt6}$, so $w3 = (0, 1, 1) - \frac12(1, 1, 0) - \frac16(1, -1, 2) = (-\frac23, \frac23, \frac23)$, and $q3 = \frac{1}{\sqrt3}(-1, 1, 1)$.

Check: $q1 \cdot q2 = \frac{1 - 1 + 0}{\sqrt{12}} = 0$, $q1 \cdot q3 = \frac{-1 + 1 + 0}{\sqrt6} = 0$, $q2 \cdot q3 = \frac{-1 - 1 + 2}{\sqrt{18}} = 0$.

QR factorisation

Gram–Schmidt, written as matrices, is a factorisation. Each $vj$ is a combination of $q1, \dots, qj$ only, with coefficients $r{ij} = \langle vj, qi\rangle$ ($i < j$) and $r{jj} = \lVert wj\rVert$. So

$$A = QR,$$

with $Q$ having orthonormal columns and $R$ upper triangular with positive diagonal. For the example, $R = Q^TA$:

$$R = \begin{pmatrix} \sqrt2 & 1/\sqrt2 & 1/\sqrt2 \\ 0 & \sqrt{3/2} & 1/\sqrt6 \\ 0 & 0 & 2/\sqrt3 \end{pmatrix} \approx \begin{pmatrix} 1.4142 & 0.7071 & 0.7071 \\ 0 & 1.2247 & 0.4082 \\ 0 & 0 & 1.1547 \end{pmatrix}.$$

> Watch out: Classical Gram–Schmidt loses orthogonality in floating point when the columns are nearly dependent. Libraries compute QR with Householder reflections (or use modified Gram–Schmidt, which subtracts each projection from the updated vector). The factorisation is the same; the arithmetic is more stable.

Chapter 4 — Least squares

The problem

An overdetermined system $Ax = b$ ($A$ is $m \times n$ with $m > n$) usually has no solution: $b$ is not in the column space $C(A)$. The least-squares solution $\hat x$ minimises $\lVert b - Ax\rVert$. By Theorem 4, $A\hat x$ must be the projection of $b$ onto $C(A)$, so the residual $e = b - A\hat x$ is orthogonal to every column of $A$: $A^Te = 0$. That gives the normal equations

$$A^TA\,\hat x = A^Tb.$$

If the columns of $A$ are independent, $A^TA$ is invertible (if $A^TAx = 0$ then $x^TA^TAx = \lVert Ax\rVert^2 = 0$, so $Ax = 0$, so $x = 0$), and $\hat x = (A^TA)^{-1}A^Tb$ is unique.

Worked example — fitting a line

Fit $y = c0 + c1 x$ to the points $(1, 1), (2, 2), (3, 2), (4, 5)$. Each point gives one equation $c0 + c1 xi = yi$:

$$A = \begin{pmatrix} 1 & 1 \\ 1 & 2 \\ 1 & 3 \\ 1 & 4 \end{pmatrix}, \quad b = \begin{pmatrix} 1 \\ 2 \\ 2 \\ 5 \end{pmatrix}, \quad A^TA = \begin{pmatrix} 4 & 10 \\ 10 & 30 \end{pmatrix}, \quad A^Tb = \begin{pmatrix} 10 \\ 31 \end{pmatrix}.$$

$\det(A^TA) = 120 - 100 = 20$, so

$$\hat c = \frac{1}{20}\begin{pmatrix} 30 & -10 \\ -10 & 4 \end{pmatrix}\begin{pmatrix} 10 \\ 31 \end{pmatrix} = \frac{1}{20}\begin{pmatrix} -10 \\ 24 \end{pmatrix} = \begin{pmatrix} -0.5 \\ 1.2 \end{pmatrix}.$$

The best line is $y = -0.5 + 1.2x$. The fitted values are $(0.7, 1.9, 3.1, 4.3)$ and the residuals $e = (0.3, 0.1, -1.1, 0.7)$. Checks: $A^Te = 0$, that is, the residuals sum to 0 and $\sum xi ei = 0.3 + 0.2 - 3.3 + 2.8 = 0$. The minimum sum of squared errors is $0.09 + 0.01 + 1.21 + 0.49 = 1.8$; no other line does better.

Least squares with QR

If $A = QR$ (reduced: $Q$ is $m \times n$), the normal equations $R^TQ^TQR\hat x = R^TQ^Tb$ simplify to

$$R\hat x = Q^Tb,$$

solved by back substitution. This is the method used in practice. Forming $A^TA$ squares the condition number (Chapter 7), which can destroy half the significant digits; QR avoids it.

Chapter 5 — Orthogonal matrices and the spectral theorem

Orthogonal matrices

A square $Q$ with $Q^TQ = I$ has orthonormal columns and $Q^{-1} = Q^T$. It preserves inner products, lengths and angles: $(Qx)\cdot(Qy) = x^TQ^TQy = x \cdot y$. Taking determinants, $\det(Q)^2 = 1$, so $\det Q = \pm 1$. In $\mathbb{R}^2$ the orthogonal matrices are exactly the rotations ($\det = 1$) and the reflections ($\det = -1$) of Linear Algebra 03. Products and inverses of orthogonal matrices are orthogonal.

A change of basis to an orthonormal basis uses an orthogonal $P$, so $P^{-1}AP = P^TAP$: no inverse to compute.

The spectral theorem

Theorem 5 (spectral theorem, real symmetric case). If $A$ is a real symmetric $n \times n$ matrix ($A^T = A$), then:

1. all eigenvalues of $A$ are real;2. eigenvectors for distinct eigenvalues are orthogonal;3. $A$ has an orthonormal basis of eigenvectors, so $A = Q\Lambda Q^T$ with $Q$ orthogonal and $\Lambda$ real diagonal.

Conversely, any $Q\Lambda Q^T$ is symmetric, so a real matrix is orthogonally diagonalizable if and only if it is symmetric.

Proof sketch. The key identity is $\langle Ax, y\rangle = x^TA^Ty = x^TAy = \langle x, Ay\rangle$.

(1) Let $Av = \lambda v$ with $v \in \mathbb{C}^n$ nonzero. The number $\bar v^TAv$ equals its own complex conjugate (conjugate it, use that $A$ is real, then transpose the $1 \times 1$ result and use $A^T = A$), so it is real. It also equals $\lambda\,\bar v^Tv = \lambda\sum\lvert vi\rvert^2$, and $\sum\lvert vi\rvert^2 > 0$ is real. So $\lambda$ is real.

(2) If $Av1 = \lambda1 v1$ and $Av2 = \lambda2 v2$, then $\lambda1\langle v1, v2\rangle = \langle Av1, v2\rangle = \langle v1, Av2\rangle = \lambda2\langle v1, v2\rangle$, so $(\lambda1 - \lambda2)\langle v1, v2\rangle = 0$.

(3) Induction on $n$. By (1) there is a real eigenvalue $\lambda1$ with a unit eigenvector $q1$. The complement $W = q1^\perp$ is mapped into itself: if $w \perp q1$ then $\langle Aw, q1\rangle = \langle w, Aq1\rangle = \lambda1\langle w, q1\rangle = 0$. On the $(n-1)$-dimensional space $W$, $A$ still satisfies $\langle Ax, y\rangle = \langle x, Ay\rangle$, so by induction $W$ has an orthonormal basis of eigenvectors $q2, \dots, qn$. Together with $q1$ this is an orthonormal eigenbasis of $\mathbb{R}^n$. ∎

Worked example. $B = \begin{pmatrix} 2 & 1 & 1 \\ 1 & 2 & 1 \\ 1 & 1 & 2 \end{pmatrix}$ from Linear Algebra 04 has eigenvalues $4, 1, 1$. The eigenvector $(1,1,1)$ for 4 is automatically orthogonal to the eigenplane $x + y + z = 0$ for 1. Inside that plane, Linear Algebra 04 used $(-1, 1, 0)$ and $(-1, 0, 1)$, which are not orthogonal to each other — Gram–Schmidt fixes that. An orthonormal choice is

$$q1 = \tfrac{1}{\sqrt3}(1, 1, 1), \quad q2 = \tfrac{1}{\sqrt2}(1, -1, 0), \quad q3 = \tfrac{1}{\sqrt6}(1, 1, -2), \qquad Q^TBQ = \operatorname{diag}(4, 1, 1).$$

The spectral decomposition writes $A$ as a sum of rank-one projections:

$$A = \lambda1 q1q1^T + \lambda2 q2q2^T + \dots + \lambdan qnqn^T.$$

For $B$: $B = 4q1q1^T + q2q2^T + q3q3^T$. Since $q2q2^T + q3q3^T = I - q1q1^T$, this is $B = I + 3q1q1^T$.

> Trick: For symmetric matrices, eigenvectors from different eigenvalues are orthogonal for free. You only need Gram–Schmidt inside an eigenspace of dimension 2 or more.

Chapter 6 — Positive definite matrices and quadratic forms

Four equivalent tests

A symmetric matrix $A$ is positive definite if $x^TAx > 0$ for every $x \neq 0$, and positive semidefinite if $x^TAx \ge 0$ for every $x$.

Theorem 6. For a real symmetric $n \times n$ matrix $A$, the following are equivalent:

1. $A$ is positive definite;2. every eigenvalue of $A$ is positive;3. every leading principal minor (the determinant of the top-left $k \times k$ block, $k = 1, \dots, n$) is positive (Sylvester's criterion);4. elimination without row swaps succeeds with every pivot positive;5. $A = R^TR$ for some invertible $R$ — for example the Cholesky factor, upper triangular with positive diagonal.

Proof of 1 ⇔ 2. Write $A = Q\Lambda Q^T$ and put $y = Q^Tx$ (a change to the eigenvector basis; $y \neq 0$ exactly when $x \neq 0$). Then

$$x^TAx = y^T\Lambda y = \lambda1 y1^2 + \dots + \lambdan yn^2,$$

which is positive for all $y \neq 0$ exactly when every $\lambdai > 0$. For 5 ⇒ 1: $x^TR^TRx = \lVert Rx\rVert^2 > 0$ when $x \neq 0$ because $R$ is invertible. The links to 3 and 4 go through the LU factorisation of Linear Algebra 01: the $k$-th pivot equals the ratio of the $k$-th and $(k-1)$-th leading minors. ∎

Worked example.

$$K = \begin{pmatrix} 2 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 2 \end{pmatrix}.$$

- Leading minors: $2$, $4 - 1 = 3$, $\det K = 4$. All positive.- Pivots: $2$, $\frac32$, $\frac43$ — the ratios $\frac21, \frac32, \frac43$ of consecutive minors.- Eigenvalues: $2 - \sqrt2 \approx 0.586$, $2$, $2 + \sqrt2 \approx 3.414$.- The quadratic form is a sum of squares: $x^TKx = 2x^2 - 2xy + 2y^2 - 2yz + 2z^2 = x^2 + (x - y)^2 + (y - z)^2 + z^2$, which is $0$ only when $x = y = z = 0$.

All four tests agree: $K$ is positive definite. (This matrix is the second-difference matrix that appears when a differential equation $-u'' = f$ is discretised.)

> Common pitfall: Positive entries do not make a matrix positive definite, and negative entries do not prevent it. $\begin{pmatrix} 1 & 2 \\ 2 & 3\end{pmatrix}$ has all entries positive but determinant $-1$, so its eigenvalues are $2 \pm \sqrt5$, one of them negative; $K$ above has negative entries and is positive definite.

Quadratic forms and principal axes

A quadratic form is $q(x) = x^TAx$ with $A$ symmetric (any cross term $bxy$ is split evenly between the two off-diagonal entries). The spectral theorem rotates the axes so the cross terms disappear.

Worked example. $q(x, y) = 5x^2 + 4xy + 2y^2$ has $A = \begin{pmatrix} 5 & 2 \\ 2 & 2 \end{pmatrix}$, with trace 7 and determinant 6, so eigenvalues $6$ and $1$. Unit eigenvectors: $\frac{1}{\sqrt5}(2, 1)$ for 6 and $\frac{1}{\sqrt5}(-1, 2)$ for 1. In the rotated coordinates $u = \frac{2x + y}{\sqrt5}$, $v = \frac{-x + 2y}{\sqrt5}$,

$$q = 6u^2 + v^2.$$

(Check at $(x, y) = (1, 0)$: $u = 2/\sqrt5$, $v = -1/\sqrt5$, and $6 \cdot \frac45 + \frac15 = 5 = q(1, 0)$.) The level curve $q = 6$ is the ellipse $u^2 + v^2/6 = 1$: semi-axis $1$ along $(2, 1)$ and $\sqrt6$ along $(-1, 2)$. The principal axes are the eigenvectors, and the semi-axes are $\sqrt{c/\lambdai}$ for the level $q = c$. In calculus the same idea classifies critical points: a positive definite Hessian means a local minimum.

Chapter 7 — The singular value decomposition

The theorem

Diagonalization needs a square matrix, and even then it can fail or need complex numbers. The SVD always works.

Theorem 7 (SVD). Every real $m \times n$ matrix $A$ of rank $r$ can be written as

$$A = U\Sigma V^T,$$

where $U$ ($m \times m$) and $V$ ($n \times n$) are orthogonal and $\Sigma$ is $m \times n$ with diagonal entries $\sigma1 \ge \sigma2 \ge \dots \ge \sigmar > 0$ and zeros elsewhere. The $\sigmai$ are the singular values (uniquely determined by $A$); the columns $vi$ of $V$ and $ui$ of $U$ are the right and left singular vectors, and $Avi = \sigmai ui$.

Proof. $A^TA$ is symmetric and positive semidefinite ($x^TA^TAx = \lVert Ax\rVert^2 \ge 0$), so by the spectral theorem it has an orthonormal eigenbasis $v1, \dots, vn$ with eigenvalues $\lambda1 \ge \dots \ge \lambdan \ge 0$. Exactly $r$ of them are positive, because $A^TA$ has the same null space as $A$ (shown in Chapter 4), hence rank $r$. Put $\sigmai = \sqrt{\lambdai}$ and, for $i \le r$, $ui = Avi/\sigmai$. These are orthonormal:

$$ui \cdot uj = \frac{vi^TA^TAvj}{\sigmai\sigmaj} = \frac{\lambdaj\, vi \cdot vj}{\sigmai\sigmaj} = \begin{cases} 1 & i = j \\ 0 & i \neq j. \end{cases}$$

Extend $u1, \dots, ur$ to an orthonormal basis of $\mathbb{R}^m$. Then $Avi = \sigmai ui$ for $i \le r$ and $Avi = 0$ for $i > r$, which is $AV = U\Sigma$, that is $A = U\Sigma V^T$. ∎

Dropping the zero parts gives the compact form $A = \sum{i=1}^{r}\sigmai ui vi^T$, a sum of $r$ rank-one matrices. The SVD also hands you orthonormal bases for all four fundamental subspaces of Linear Algebra 02: $v1, \dots, vr$ for the row space, $v{r+1}, \dots, vn$ for the null space, $u1, \dots, ur$ for the column space, and $u{r+1}, \dots, um$ for the left null space.

Worked example

$$A = \begin{pmatrix} 3 & 0 \\ 4 & 5 \end{pmatrix}, \qquad A^TA = \begin{pmatrix} 25 & 20 \\ 20 & 25 \end{pmatrix}.$$

$A^TA$ has trace 50 and determinant $625 - 400 = 225$, so eigenvalues $45$ and $5$, with unit eigenvectors $v1 = \frac{1}{\sqrt2}(1, 1)$ and $v2 = \frac{1}{\sqrt2}(-1, 1)$. The singular values are $\sigma1 = \sqrt{45} = 3\sqrt5 \approx 6.708$ and $\sigma2 = \sqrt5 \approx 2.236$. Then

$$u1 = \frac{Av1}{\sigma1} = \frac{(3, 9)/\sqrt2}{3\sqrt5} = \frac{1}{\sqrt{10}}(1, 3), \qquad u2 = \frac{Av2}{\sigma2} = \frac{(-3, 1)/\sqrt2}{\sqrt5} = \frac{1}{\sqrt{10}}(-3, 1),$$

$$A = \underbrace{\frac{1}{\sqrt{10}}\begin{pmatrix} 1 & -3 \\ 3 & 1 \end{pmatrix}}{U} \underbrace{\begin{pmatrix} 3\sqrt5 & 0 \\ 0 & \sqrt5 \end{pmatrix}}{\Sigma} \underbrace{\frac{1}{\sqrt2}\begin{pmatrix} 1 & 1 \\ -1 & 1 \end{pmatrix}}{V^T}.$$

Checks: $\sigma1\sigma2 = 15 = \det A$ (here $\det U = \det V = 1$), and $\sigma1^2 + \sigma2^2 = 50 = 9 + 0 + 16 + 25$, the sum of the squared entries.

> Watch out: The singular values of $A$ are not its eigenvalues. This $A$ is triangular with eigenvalues 3 and 5, but singular values $6.708$ and $2.236$. For a symmetric matrix the singular values are the absolute values of the eigenvalues (more generally this holds for normal matrices, those with $A^TA = AA^T$), and for a positive semidefinite matrix they are exactly the eigenvalues.

Geometry: rotate, stretch, rotate

Read $A = U\Sigma V^T$ from right to left as three steps applied to the unit circle:

1. $V^T$ is orthogonal: it rotates (or reflects) the plane, carrying $v1, v2$ to $e1, e2$. Here $V^T$ is rotation by $-45°$. The circle stays a circle.2. $\Sigma$ stretches along the axes by $\sigma1$ and $\sigma2$. The circle becomes an axis-aligned ellipse with semi-axes $6.708$ and $2.236$.3. $U$ rotates again, carrying $e1, e2$ to $u1, u2$. Here $U$ is rotation by about $71.6°$ (the angle of $(1, 3)$).

![The SVD of A = [[3,0],[4,5]] as three steps applied to the unit circle: V transpose rotates by -45 degrees taking v1 and v2 to e1 and e2, Sigma stretches by 3 root 5 and root 5 into an axis-aligned ellipse, and U rotates by about 71.6 degrees; the result is the image of the unit circle under A, an ellipse with semi-axes along u1 and u2.](/assets/linalg/diagram05svdgeometry.svg)

So every linear map of $\mathbb{R}^n$ sends the unit sphere to an ellipsoid (flattened when $A$ is singular); the singular values are its semi-axes, the $ui$ their directions, and the $vi$ the unit vectors that land on them. In general $U$ and $V$ may include a reflection; both can be chosen as rotations exactly when $\det A \ge 0$ (for square $A$).

Norms and conditioning

- Spectral norm: $\lVert A\rVert2 = \max{\lVert x\rVert = 1}\lVert Ax\rVert = \sigma1$ — the longest semi-axis.- Frobenius norm: $\lVert A\rVertF = \sqrt{\sum a{ij}^2} = \sqrt{\sigma1^2 + \dots + \sigmar^2}$ (orthogonal matrices do not change it).- Condition number of an invertible $A$: $\kappa(A) = \sigma1/\sigman$, the ratio of the longest to the shortest semi-axis. For the example $\kappa = 3\sqrt5/\sqrt5 = 3$. Solving $Ax = b$ can amplify relative errors in $b$ by up to $\kappa$; since $\sigmai(A^TA) = \sigmai^2$, forming the normal equations squares it. This, and not the size of $\det A$, measures closeness to singularity (Linear Algebra 03, Chapter 7).

Chapter 8 — Using the SVD

Low-rank approximation

Theorem 8 (Eckart–Young, statement). Let $A = \sum{i=1}^r \sigmai ui vi^T$ and, for $k < r$, $Ak = \sum{i=1}^k \sigmai ui vi^T$. Among all matrices $B$ of rank at most $k$,

$$\min{\operatorname{rank} B \le k}\lVert A - B\rVert2 = \lVert A - Ak\rVert2 = \sigma{k+1}, \qquad \min{\operatorname{rank} B \le k}\lVert A - B\rVertF = \lVert A - Ak\rVertF = \sqrt{\sigma{k+1}^2 + \dots + \sigmar^2}.$$

Keep the $k$ largest singular triples and drop the rest; nothing of rank $k$ does better. For the example,

$$A1 = 3\sqrt5\, u1v1^T = \frac{3}{2}\begin{pmatrix} 1 & 1 \\ 3 & 3 \end{pmatrix} = \begin{pmatrix} 1.5 & 1.5 \\ 4.5 & 4.5 \end{pmatrix}, \qquad A - A1 = \begin{pmatrix} 1.5 & -1.5 \\ -0.5 & 0.5 \end{pmatrix},$$

and $\lVert A - A1\rVertF^2 = 2.25 + 2.25 + 0.25 + 0.25 = 5 = \sigma2^2$, as the theorem says.

Storage: a rank-$k$ approximation of an $m \times n$ matrix needs $k(m + n + 1)$ numbers instead of $mn$. For a $1000 \times 1000$ greyscale image and $k = 50$, that is $100\,050$ numbers instead of $1\,000\,000$, about 10%. Whether the result looks acceptable depends on how fast the singular values decay.

The pseudoinverse

The Moore–Penrose pseudoinverse of $A = U\Sigma V^T$ is

$$A^+ = V\Sigma^+U^T,$$

where $\Sigma^+$ is $n \times m$ with $1/\sigmai$ in place of each nonzero $\sigmai$. It inverts $A$ on the row space and sends the left null space to 0. $x^+ = A^+b$ is the least-squares solution of $Ax = b$ with the smallest norm — well defined even when $A$ is rank-deficient and the normal equations have infinitely many solutions. If $A$ has independent columns, $A^+ = (A^TA)^{-1}A^T$ and $A^+b$ is the $\hat x$ of Chapter 4; for the line fit, $A^+b = (-0.5, 1.2)$. If $A$ is invertible, $A^+ = A^{-1}$.

Example. $A = \begin{pmatrix} 1 & 1 \\ 1 & 1 \end{pmatrix} = 2\,uu^T$ with $u = \frac{1}{\sqrt2}(1, 1)$, so $A^+ = \frac12 uu^T = \frac14\begin{pmatrix} 1 & 1 \\ 1 & 1\end{pmatrix}$. For $b = (1, 3)$ (not in the column space), $x^+ = A^+b = (1, 1)$. Every $x$ with $x1 + x2 = 2$ gives the same smallest residual (because $Ax = (2, 2)$, the projection of $b$), and $(1, 1)$ is the shortest of them.

Principal component analysis

Put $N$ data points in $\mathbb{R}^p$ as the rows of a matrix and subtract the mean of each column, giving a centred $N \times p$ matrix $X$. The sample covariance matrix is $C = \frac{1}{N - 1}X^TX$. If $X = U\Sigma V^T$ then $C = V\frac{\Sigma^T\Sigma}{N - 1}V^T$, so:

- the principal directions are the right singular vectors $vi$ (eigenvectors of $C$);- the variance along $vi$ is $\sigmai^2/(N - 1)$;- projecting the data onto $v1, \dots, vk$ is the best $k$-dimensional summary in the least-squares sense (Eckart–Young applied to $X$).

Worked example. The four points $(3, 3), (-3, -3), (1, -1), (-1, 1)$ already have mean zero. $X^TX = \begin{pmatrix} 20 & 16 \\ 16 & 20\end{pmatrix}$ has eigenvalues 36 and 4 with eigenvectors $(1, 1)$ and $(1, -1)$, so the singular values of $X$ are 6 and 2. The first principal direction is $\frac{1}{\sqrt2}(1, 1)$ with variance $36/3 = 12$; the second has variance $4/3$. The first component explains $36/(36 + 4) = 90\%$ of the total variance.

> Common pitfall: Forgetting to centre the data. Without subtracting the mean, the first "principal component" mostly points at the mean itself. Also scale the columns first when they are in different units, or the largest-unit variable dominates.

Practice Exercises

1. Show that $\langle f, g\rangle = \int0^1 f(t)g(t)\,dt$ satisfies the positive-definiteness axiom on $C[0,1]$. Then find the projection of $f(t) = t$ onto the constants.

<details><summary>Solution</summary>

$\langle f, f\rangle = \int0^1 f^2 \ge 0$. If $f$ is continuous and $f(t0) \neq 0$, then $f^2 > \frac12 f(t0)^2$ on some interval around $t0$, so the integral is positive; hence $\langle f, f\rangle = 0$ forces $f = 0$. (Continuity matters here.) Projection onto $\operatorname{span}(1)$: $\frac{\langle t, 1\rangle}{\langle 1, 1\rangle}\cdot 1 = \frac{1/2}{1} = \frac12$. The residual $t - \frac12$ is orthogonal to 1, as computed in Chapter 1.

</details>

2. Apply Gram–Schmidt to $a1 = (1, 1, 1, 1)$, $a2 = (0, 1, 2, 3)$.

<details><summary>Solution</summary>

$q1 = \frac12(1, 1, 1, 1)$. $\langle a2, a1\rangle / \langle a1, a1\rangle = 6/4 = \frac32$, so $w2 = (0, 1, 2, 3) - \frac32(1, 1, 1, 1) = (-\frac32, -\frac12, \frac12, \frac32)$ with $\lVert w2\rVert = \sqrt{\frac94 + \frac14 + \frac14 + \frac94} = \sqrt5$. So $q2 = \frac{1}{2\sqrt5}(-3, -1, 1, 3)$. (This is the "centred $x$" that makes line fitting at $x = 0, 1, 2, 3$ decouple.)

</details>

3. For the line fit in Chapter 4, compute the projection matrix $P = A(A^TA)^{-1}A^T$ and check $Pb$.

<details><summary>Solution</summary>

$(A^TA)^{-1} = \frac{1}{20}\begin{pmatrix} 30 & -10 \\ -10 & 4\end{pmatrix}$, and

$$P = \frac{1}{10}\begin{pmatrix} 7 & 4 & 1 & -2 \\ 4 & 3 & 2 & 1 \\ 1 & 2 & 3 & 4 \\ -2 & 1 & 4 & 7 \end{pmatrix}.$$

$Pb = \frac{1}{10}(7 + 8 + 2 - 10,\ 4 + 6 + 4 + 5,\ 1 + 4 + 6 + 20,\ -2 + 2 + 8 + 35) = (0.7, 1.9, 3.1, 4.3)$, the fitted values. Also $P^2 = P$ and $P^T = P$.

</details>

4. Is $\begin{pmatrix} 4 & 2 \\ 2 & 3\end{pmatrix}$ positive definite? Use two different tests.

<details><summary>Solution</summary>

Leading minors: $4 > 0$ and $12 - 4 = 8 > 0$: yes. Eigenvalues: trace 7, determinant 8, so $\lambda = \frac{7 \pm \sqrt{49 - 32}}{2} = \frac{7 \pm \sqrt{17}}{2}$, both positive because $\sqrt{17} < 7$. Or complete the square: $4x^2 + 4xy + 3y^2 = (2x + y)^2 + 2y^2$.

</details>

5. Find the singular values of $E = \begin{pmatrix} 2 & 2 \\ 1 & -1\end{pmatrix}$ and its condition number.

<details><summary>Solution</summary>

$E^TE = \begin{pmatrix} 5 & 3 \\ 3 & 5\end{pmatrix}$ has eigenvalues 8 and 2, so $\sigma1 = 2\sqrt2$, $\sigma2 = \sqrt2$, and $\kappa = 2$. Check: $\sigma1\sigma2 = 4 = \lvert\det E\rvert = \lvert -2 - 2\rvert$.

</details>

6. Prove that if $Q$ is orthogonal then every real eigenvalue of $Q$ is $\pm1$, and every singular value of $Q$ is 1.

<details><summary>Solution</summary>

If $Qv = \lambda v$ with $v \neq 0$, then $\lVert v\rVert = \lVert Qv\rVert = \lvert\lambda\rvert\,\lVert v\rVert$, so $\lvert\lambda\rvert = 1$. Singular values are square roots of the eigenvalues of $Q^TQ = I$, all equal to 1: an orthogonal map sends the unit sphere to itself.

</details>

7. Show that for a symmetric positive semidefinite matrix the SVD and the spectral decomposition coincide, and give a $2 \times 2$ symmetric matrix where they differ.

<details><summary>Solution</summary>

If $A = Q\Lambda Q^T$ with all $\lambdai \ge 0$ (sorted in decreasing order), then $U = V = Q$ and $\Sigma = \Lambda$ is a valid SVD. For a symmetric matrix with a negative eigenvalue, such as $\begin{pmatrix} 1 & 2 \\ 2 & 1\end{pmatrix}$ (eigenvalues $3, -1$), the singular values are $3$ and $1$: the sign moves into $U$ (take $u2 = -v2$).

</details>

Chapter 1 — How Mongo time-series collections work

You create a TS collection with a , optional , and :

Under the hood:

- Documents you insert are invisibly bucketed by  + time window. The visible API is one-doc-per-event, but on disk it's many events per bucket document.- Buckets use columnar compression — much smaller than 1-doc-per-event.- Queries by time range + metaField are fast because they touch only matching buckets.

Trade-offs vs hand-rolled bucket pattern (Post 07 Ch 5):

- No manual schema to maintain.- Better compression than naive.- TTL works out of the box.

Limits to be aware of:

- No update / delete of individual events (you can re-create the doc or delete the bucket; old events were immutable).- Indexing limited (mostly  + ; partial multi-key support).- Aggregations work but cardinality-heavy  is still RAM-bound.

For most telemetry use cases this is fine. Workloads where Mongo TS starts to crack: 100k+ writes/sec sustained on a single node, deep aggregations over years of data, sub-100 ms query latency on billions of rows.

Chapter 2 — Where Mongo TS shines

| Workload | Why Mongo TS fits ||----------|--------------------|| Mid-volume IoT (thousands of devices, 1-10 Hz each) | one collection; no extra infra || Observability for one product | metrics + tags fit Mongo doc model; index by host + time || Financial ticks for handful of symbols | bucket per symbol + minute || Audit / event log with TTL | TS +  purges automatically || Workloads that mix transactional + analytics | one DB; no ETL |

Chapter 3 — Where Mongo TS struggles

- Very high write throughput — single primary saturates around 50-100k writes/sec on a strong shard. Beyond that, sharding helps but costs grow.- Very deep aggregations — averaging across billions of rows with cardinality-heavy  is slower than columnar engines built for it.- Sub-50ms p99 on huge ranges — columnar formats with vectorised execution win.- Compression at extreme scale — ClickHouse / Parquet typically achieves 5-20× the compression ratio of Mongo TS for time-series-shape data.- Cost per TB of cold data — Atlas hot storage isn't cheap; archive helps but specialist engines compress more aggressively.

When the workload hits any of these, look at alternatives below.

Chapter 5 — ClickHouse — when + how

ClickHouse is a columnar OLAP database. Strengths for time-series:

- Sub-second aggregation over billions of rows.- 10-50× compression vs row-store.- Materialized views update incrementally.- Native S3 + Parquet integration for cold storage.

Inserts: millions of rows / second per node.Queries: tens of milliseconds over millions of rows.

Trade-offs:

- Append-mostly; updates + deletes are expensive (mutations queue).- Schema is rigid (vs Mongo's flexibility).- Operational complexity higher than managed Mongo.

Use ClickHouse when: pure analytical queries dominate; workload exceeds Mongo TS ceiling; you can devote eng time to running it or pay for managed.

Chapter 6 — Hybrid — Mongo for OLTP, ClickHouse for OLAP

The common 2026 pattern for serious scale:

Mongo handles user-facing reads + writes with rich queries on recent data. Events flow to ClickHouse via Kafka (Post 24) or a periodic batch ( + S3 → ClickHouse). Dashboards / BI hit ClickHouse for big analytics.

Each tool does what it's best at; you pay the cost of running two systems but neither is asked to do the other's job poorly.

Chapter 7 — When TimescaleDB fits better

If your team is already deep on Postgres + your analytical queries are still SQL-shape (joins, complex predicates, transactions over recent slices), TimescaleDB keeps you on one engine.

Strengths:

- Full Postgres feature set + PostGIS + extensions.- Multi-tier storage (recent on SSD, old compressed to columnar).- Familiar to SQL teams.

Weaknesses:

- Not as fast as pure columnar for huge analytics.- Scaling horizontally still harder than Atlas + Mongo or ClickHouse.

Pick when: SQL-first team, mixed transactional + analytical SQL workload, < 1 TB per dataset.

Chapter 8 — InfluxDB v3 — metrics-focused

InfluxDB v3 (formerly IOx) is rebuilt on Apache Arrow + Parquet. Strengths for metrics:

- Native to monitoring workflows (Prometheus-compat ingest, Grafana plugin).- Fast on time-series math (rates, moving averages, derivatives).- Self-managed or cloud.

Weaknesses:

- Less general-purpose than ClickHouse.- Schema evolution gotchas inherited from earlier versions.

Pick when: pure monitoring workload + you want a metrics-first DB rather than a general analytical engine.

Chapter 9 — QuestDB — fast + small

QuestDB is a young, fast columnar TS database. Strengths:

- Tiny footprint; runs on a laptop and on a server.- Very fast ingest + SQL queries.- Compatible with Postgres wire protocol.

Weaknesses:

- Smaller community + ecosystem than ClickHouse.- Fewer enterprise features.

Pick when: greenfield project, dev-friendliness > ecosystem.

Chapter 10 — Druid / Pinot — sub-second dashboards over huge data

For ad-tech, real-time analytics, leaderboard-style dashboards over billions of rows with millisecond response:

- Apache Druid — operational complexity high; sub-second analytical queries shine.- Apache Pinot — similar story; LinkedIn / Uber heritage.

Not the first choice for general workloads; reserve for when you genuinely need that latency at that scale.

Chapter 11 — Decision matrix

The right answer is rarely "one engine for everything" past a certain scale.

Mongo TS → ClickHouse

Chapter 3 — Bodies and colliders

A rigid body is the physical object (with mass, velocity, position). A collider is its shape for collision detection. Bodies can have one or more colliders.

Body types:

- Dynamic — moves with physics.- Fixed (static) — never moves, infinite mass; for floors, walls.- Kinematic position-based — moves by setting position; collides with dynamics; doesn't react to forces. For characters/platforms.- Kinematic velocity-based — moves by setting velocity; same idea as above.

| Shape | Constructor ||-------|-------------|| Box |  || Sphere |  || Capsule |  || Cylinder |  || Cone |  || Trimesh (any 3D mesh) |  || Heightfield (terrain) |  || Convex hull |  |
