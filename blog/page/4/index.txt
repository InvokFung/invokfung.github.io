Chapter 1 — What the cloud is

Terminology

- Cloud computing — renting compute, storage, network, and services from a provider on-demand, billed by usage rather than capital purchase.- Region — a geographic area (e.g.,  in Northern Virginia,  in Hong Kong). Each region is fully independent.- Availability Zone (AZ) — one or more isolated data centres inside a region, connected by low-latency links. Each region has ≥ 3 AZs.- Edge location — smaller PoPs (point of presence) used by CloudFront (CDN) and Route 53 (DNS). Hundreds worldwide.- Service — a single AWS product. EC2, S3, Lambda are services.- API — every AWS service is driven by an HTTPS API. Console, CLI, SDKs, and IaC tools all call the same APIs underneath.

Service-model layers

| Layer | What the provider runs | What you run | Example AWS ||-------|------------------------|--------------|-------------|| IaaS (Infrastructure) | hardware, virtualisation, network | OS + everything above | EC2, EBS, VPC || PaaS (Platform) | OS + runtime | your app code | Elastic Beanstalk, App Runner || FaaS (Functions) | runtime + scheduling | a single function | Lambda || SaaS (Software) | everything | only data + config | WorkMail, Connect |

Trick: when picking a service, ask "how much do I want to manage?". The deeper you go (IaaS → SaaS), the less control and the less ops work. There is no universal best — pick the layer that matches your team's appetite.

Chapter 3 — Account, billing, and the root user

When you sign up at aws.amazon.com, you create the root user — an account-wide super-admin tied to your email + credit card.

The rules everyone learns the hard way

1. Never use the root user for daily work. Log in once, set up MFA, create an IAM admin user, then log out.2. Enable MFA on the root user immediately — preferably a hardware key or a TOTP app.3. Set a billing alert before deploying anything. AWS has no built-in spending cap; you can rack up $5,000 in a misconfigured stack overnight.4. Tag every resource with at least an owner and environment tag — for cost allocation later.

Billing alert (5-minute setup)

1. Console → Billing → Billing preferences → enable "Receive Billing Alerts".2. CloudWatch → Alarms → create a billing alarm at, say, USD 10 / month.3. Subscribe your email to the SNS topic.

The alarm needs to be created in  (billing metrics live there).

Chapter 4 — IAM (Identity and Access Management)

IAM is how AWS knows who you are and what you're allowed to do. Five concepts:

| Concept | What ||---------|------|| User | A human (or app key pair). Has a password and/or access keys. || Group | A bag of users sharing permissions (e.g., , ). || Role | An identity that a service (EC2, Lambda, etc.) or a federated user assumes temporarily. The modern way. || Policy | A JSON document listing allowed/denied actions. Attached to users, groups, or roles. || Permission boundary | A meta-policy that caps what a user/role can be granted, regardless of inline policies. |

Roles vs users — modern guidance

Use roles for code (EC2, Lambda, ECS tasks). The service automatically gets short-lived credentials via the EC2 instance metadata service or the Lambda runtime; you never store access keys on disk.

Use users only for humans, and prefer federation (SSO, Okta, Azure AD) over local IAM users in serious accounts.

Common pitfall: committing long-lived AWS access keys to a public repo. Bots scan GitHub for keys constantly; expect crypto-mining within minutes. Never commit  strings. If exposed, rotate immediately and audit.

Chapter 6 — The Free Tier and how to avoid surprise bills

AWS gives a 12-month free tier on many services for new accounts, plus "always free" tiers for some.

| Resource | Free tier (per month) ||----------|------------------------|| EC2 (t2.micro / t3.micro) | 750 hours || S3 | 5 GB storage + 20k GET + 2k PUT || Lambda | 1M requests + 400k GB-seconds || DynamoDB | 25 GB + 200M requests || CloudWatch | 10 metrics + 5 GB logs |

Surprise-bill traps to avoid:

1. NAT Gateway — runs 24/7 at ≈ USD 32 / month, charges for data through it. Easy to leave running.2. Elastic IPs not attached — costs while idle.3. EBS volumes not deleted with their instances — keep paying for storage.4. CloudWatch Logs without retention — defaults to forever. Set retention to 7 or 30 days.5. Cross-region data transfer — between regions costs around USD 0.02 / GB. Adds up.6. Public S3 traffic — if your bucket goes viral, you pay for the egress.

> Trick: create a separate AWS account for learning — nothing else lives there. When done with a tutorial, run  or use AWS Nuke to wipe everything.

Chapter 1 — Three More Keys: A, E♭, and Their Minors

| Major | Sharps/Flats | Relative minor ||-------|--------------|----------------|| C | none | A m || G | F♯ | E m || D | F♯ C♯ | B m || A | F♯ C♯ G♯ | F♯ m || F | B♭ | D m || B♭ | B♭ E♭ | G m || E♭ | B♭ E♭ A♭ | C m |

A major (3 sharps) and E♭ major (3 flats) extend the symmetric pair around C.

> Trick: visualise the circle of fifths as a clock. C is at 12. Each step clockwise adds a sharp (G, D, A, E, B…). Each step counter-clockwise adds a flat (F, B♭, E♭, A♭, D♭…). Grade 3 covers ±3 steps from C: clockwise to A, counter-clockwise to E♭.

Reading a fast key signature

When you see three sharps in the order F♯ C♯ G♯, the last is G♯ → up one semitone → A major (or its relative F♯ minor).

When you see three flats in the order B♭ E♭ A♭, the second-to-last is E♭ → E♭ major (or its relative C minor).

Chapter 2 — Minor Scales: Three Flavours

A minor key has one key signature (the natural minor) but musicians use three common scale shapes built from that signature.

Natural minor (自然小調)

Use the relative-minor key signature, start from the minor tonic. Pattern in semitones:

$$\textnormal{W H W W H W W} \quad = \quad 2,1,2,2,1,2,2$$

Harmonic minor (和聲小調)

Raise the 7th degree of the natural minor. The interval between 6 and 7 becomes an augmented 2nd (3 semitones) — gives the unmistakable "exotic" sound.

Melodic minor (旋律小調)

Ascending: raise the 6th and 7th. Descending: revert to natural minor.

> Where I got stuck: I kept mixing harmonic and melodic.> - Harmonic minor exists to fix harmony — it gives the V chord its major-3rd leading tone (G♯ in A minor) so the V → i cadence sounds strong. Raise the 7 only.> - Melodic minor exists to smooth melody — the harmonic minor's augmented 2nd (F → G♯) is awkward to sing, so going up you also raise the 6 (F → F♯) to "smooth" the gap. Coming down you don't need the lift, so revert.>> Framing them by purpose (harmony-fixing vs melody-smoothing) made them stop blurring.

Chapter 3 — Triplets

A triplet is three notes played in the time of two of the same value. Notated with a "3" above or below a group:

In 4/4, a beat that would normally hold two quavers (♪♪) is squeezed to fit three (♪♪♪). The three notes are equal, faster than quavers, slower than triplet semiquavers.

Counting triplets

Subdivide each affected beat into three syllables: "tri-pa-let" or "1-trip-let, 2-trip-let". Pick one and stick with it.

> Trick: when first practising triplets, tap the beat with your foot while saying "1-trip-let, 2-trip-let, 3-trip-let, 4-trip-let" out loud. Foot is the beat (4 taps per bar), voice is the subdivision (12 syllables per bar). Once you can do this without the piano, the piano part is mechanical.

Duplet — the inverse

In compound time (where each beat naturally divides into 3), a duplet is two notes played in the time of three. Marked "2". Less common at Grade 3 but worth knowing.

Chapter 4 — 9/8 and 12/8 (More Compound Time)

| Metre | Beats per bar | Beat unit | Feel ||-------|---------------|-----------|------|| 6/8 | 2 | dotted crotchet | Gallop || 9/8 | 3 | dotted crotchet | Slow waltz, lilting || 12/8 | 4 | dotted crotchet | Blues shuffle, slow ballad |

In 9/8, count three macro-beats per bar, each dotted-crotchet long, each subdividing into 3 quavers. "1-and-a, 2-and-a, 3-and-a."

In 12/8, count four macro-beats: "1-and-a, 2-and-a, 3-and-a, 4-and-a."

> Analogy: if 6/8 is a gallop, 9/8 is a canter in three (less symmetric), and 12/8 is a rolling blues shuffle — most "12-bar blues" songs are written in 12/8 even when the notation says 4/4 swung.

Chapter 5 — Augmented and Diminished Intervals (just the tritone)

Grade 3 expands the interval qualities to include augmented and diminished — but only for the augmented 4th (A4) and diminished 5th (d5), which are the same six-semitone gap (the tritone, 三全音).

These two are enharmonic: same sound, different spelling. Whether you call it A4 or d5 depends on note names — count the staff positions:

- C → F♯: positions = 4 (C–D–E–F) → 4th → "augmented" (one semitone larger than P4).- C → G♭: positions = 5 (C–D–E–F–G) → 5th → "diminished" (one semitone smaller than P5).

> Trick: a tritone divides the octave exactly in half ($12 / 2 = 6$ semitones). It's the most dissonant interval in tonal music — historically called diabolus in musica ("the devil in music") because medieval theorists found it so unstable they avoided writing it. Today it's the engine of jazz and blues. Knowing the history hooks the memory.

Chapter 6 — Primary Triads (I, IV, V)

A triad (三和弦) = three notes stacked in thirds. Root, third, fifth.

The primary triads of any key are built on degrees 1, 4, 5 — the tonic, subdominant, dominant. They handle the bulk of harmonic motion in tonal music.

In a major key

> Trick: in a major key, the primary triads (I, IV, V) are all major chords. Roman numerals are uppercase to show this. The supportive triads (ii, iii, vi) are minor — lowercase. The vii° is diminished — lowercase + degree mark.

In a minor key (harmonic)

Because harmonic minor raises the 7th, the V chord becomes major (it has the raised leading tone) — even though the key is minor.

> Where I got stuck: V in minor is major. This seems like a contradiction — until you realise it's deliberate: the major V supplies the leading tone that pulls back to the tonic. Without that, the V → i cadence would sound weak. Once you internalise this purpose, the rule is obvious.

Writing triads — Grade 3 expectations

Root position only. Bass note = root. Stack a 3rd and 5th above. No inversions yet (Grade 4-5 territory).

In 4-part writing (Grade 5+) you also need to know how to double notes, but Grade 3 only asks for the three-note triad spelled out.

Chapter 7 — Roman Numeral Analysis (gentle introduction)

Grade 3 starts using Roman numerals to label chords. They tell you the function without specifying the key — a Roman-numeral analysis transposes for free.

| Numeral | Function | Quality in major | Quality in minor (natural) ||---------|----------|-------------------|-----------------------------|| I | Tonic | Major | minor || ii | Supertonic | minor | diminished || iii | Mediant | minor | Major || IV | Subdominant | Major | minor || V | Dominant | Major | minor (or Major if harmonic) || vi | Submediant | minor | Major || vii° | Leading tone | diminished | Major (subtonic, ♭VII) |

> Trick: in major, the qualities pattern is M m m M M m d° ("Major, minor, minor, Major, Major, minor, diminished"). Memorise this once; apply to any major scale. The pattern never changes — only the starting key.

Tempo

Dynamics + expression

| Term | Meaning ||------|---------|| Crescendo / diminuendo | Already known; reinforced || Sotto voce | In a whispered voice || Con brio | With brilliance, fire || Con moto | With motion || Grazioso | Gracefully || Maestoso | Majestically || Tranquillo | Calmly |

Choosing repertoire intelligently

By Grade 3 you should be playing three pieces simultaneously at different stages:

1. Mastery piece — old favourite, polished, played at performance tempo. Maintains confidence.2. Working piece — current focus, hands-together at slow tempo, gets the most minutes.3. Sight-read piece — new, untouched, played once per week as a "see how far I get".

The mix prevents staleness on any one and reinforces transferable skills.

> Trick: keep a small notebook of "pieces I never want to forget" — the mastery list. Every two weeks, revisit one of them for ten minutes. Without this, the pieces you spent six weeks learning will quietly evaporate from memory.

Chapter 10 — Practice Patterns: Voice Independence

Grade 3 introduces real two-voice writing (Bach inventions). The hands aren't just playing chords against melody — both hands have independent musical lines.

How to practise two voices

1. Sing one line while playing the other. Sing the RH; play only the LH. Then swap. This forces your brain to "hear" each part separately.2. Practise the LH at twice the volume, RH softly. Then reverse. Trains dynamic independence.3. Slow loops on the join points. Two-voice writing has constant "overlapping" moments where one hand crosses or sustains while the other moves. Mark those bars and isolate them.

> Where I got stuck: in Bach's first invention I could play either hand alone — but together my brain treated it as one stream and the LH always reverted to chord accompaniment. Fix: I spent a week singing the LH while playing the RH. The shift in mental model is exactly what's required — both lines are melodies, not "melody + accompaniment". Once the brain reframes it, the fingers follow.

Chapter 11 — Aural at Grade 3

ABRSM Grade 3 aural adds:

- Identify whether a piece is in major or minor key.- Identify whether a cadence is perfect (V → I) or imperfect (?? → V).- Sing back a slightly longer phrase (5–6 notes).- Identify two features of a played excerpt: dynamics, articulation, tempo change, tonality.

Practising major-vs-minor by ear

- Listen to one octave of a major scale (just C D E F G A B C). Hum it.- Now one octave of A minor (A B C D E F G A). Hum it.- The third note is the give-away. Major sounds "open / bright". Minor sounds "narrow / sad".

> Trick: the first three notes — do-re-mi vs la-ti-do — are the cleanest test. If the third note is a major third above the first, the key is major. If it's a minor third (one semitone less), the key is minor. Sing the test phrase silently in your head while listening; it'll often beat conscious analysis.

Chapter 1 — Two more keys

Grade 2 adds D major (2 sharps: F♯, C♯) and B♭ major (2 flats: B♭, E♭).

| Key | Sharps/Flats | Notes ascending ||-----|--------------|-----------------|| C major | none | C D E F G A B C || G major | F♯ | G A B C D E F♯ G || F major | B♭ | F G A B♭ C D E F || D major | F♯ C♯ | D E F♯ G A B C♯ D || B♭ major | B♭ E♭ | B♭ C D E♭ F G A B♭ |

> Trick: the order of sharps you encounter is fixed: F♯ → C♯ → G♯ → D♯ → A♯ → E♯ → B♯. Order of flats reversed: B♭ → E♭ → A♭ → D♭ → G♭ → C♭ → F♭. Same letters, opposite ends. Mnemonics: sharps = "Father Charles Goes Down And Ends Battle"; flats = the same backwards, "Battle Ends And Down Goes Charles' Father".

Finding the key from the signature

- Sharps: the last sharp is the leading tone — go up one semitone to find the tonic.- One sharp (F♯) → up to G → G major.- Two sharps (F♯, C♯) → last is C♯ → up to D → D major.- Flats: the second-to-last flat is the tonic.- Two flats (B♭, E♭) → second-to-last is B♭ → B♭ major.- (Special case: one flat alone = F major.)

> Where I got stuck: the flat-rule asks for the second-to-last, not the last. I missed this constantly. I wrote it on the cover of my notebook. After two weeks it became automatic.

Chapter 2 — Semiquavers (Sixteenth Notes)

A semiquaver / 十六分音符 = half a quaver = quarter of a crotchet. In 4/4, four semiquavers fit in one crotchet's time.

Beaming groups

Semiquavers are usually beamed in groups of 4 (one full crotchet beat). Mixed quaver + semiquaver groupings appear too:

Counting semiquavers out loud

Standard system: "1 e and a, 2 e and a, 3 e and a, 4 e and a" — four syllables per crotchet beat. Each crotchet contains 4 sixteenths; each syllable maps to one sixteenth-note position.

> Trick: try saying "ta-ka-di-mi" instead — many drummers use it, it's faster on the tongue than "1 e and a". As long as you commit to one consistent vocabulary, the brain locks onto the subdivision.

Dotted quaver + semiquaver pattern

The most common Grade 2 rhythm:

In count words: "1 . . a, 2 . . a" — the dotted quaver takes 3 sixteenths, the semiquaver takes the last 1.

Chapter 3 — Compound Time (6/8)

In 6/8 there are two beats per bar, and each beat is a dotted crotchet (= 3 quavers). Don't be fooled by the "6" — you do not count "1-2-3-4-5-6" evenly; you feel two macro-beats, each subdivided into three.

| | 6/8 | 3/4 ||---|-----|-----|| Beats per bar | 2 | 3 || Beat unit | dotted crotchet (3 quavers) | crotchet (2 quavers) || Each beat divides into | 3 | 2 || Feel | Gallop / lilt | Waltz |

The strong beats are the 1 and the 4. The other digits are subdivisions.

> Analogy: simple time is walking — left-right-left-right, two equal steps per beat. Compound time is galloping — DA-da-da, DA-da-da. The "DA" is the macro-beat (dotted crotchet); the "da-da" are the eighth-note subdivisions.

Other compound metres

Grade 2 only requires 6/8, but for context:

| Metre | Beats per bar | Each beat ||-------|---------------|-----------|| 6/8 | 2 | dotted crotchet || 9/8 | 3 | dotted crotchet || 12/8 | 4 | dotted crotchet |

You'll meet 9/8 and 12/8 at Grade 4.

Chapter 4 — Intervals by Quality

Grade 2 upgrades intervals from number-only to quality + number.

The quality lexicon

| Quality | Applies to numbers | Example (above C) ||---------|--------------------|--------------------|| Perfect | 1st, 4th, 5th, 8th | C–C unison, C–F, C–G, C–C octave || Major | 2nd, 3rd, 6th, 7th | C–D, C–E, C–A, C–B || Minor | 2nd, 3rd, 6th, 7th | C–D♭, C–E♭, C–A♭, C–B♭ (one semitone smaller than major) |

> Trick: the perfect intervals (P1, P4, P5, P8) are called "perfect" because both they and their inversions (P5 ↔ P4, P8 ↔ P1) are perfect — symmetric. The major / minor pairs (2nd, 3rd, 6th, 7th) flip into each other when inverted: major 3rd ↔ minor 6th, major 2nd ↔ minor 7th, etc. The 9 - x rule: a major-3rd inverted is a minor-(9-3) = minor-6th.

Counting semitones to find quality

| Interval | Semitones ||----------|-----------|| Perfect unison | 0 || Minor 2nd | 1 || Major 2nd | 2 || Minor 3rd | 3 || Major 3rd | 4 || Perfect 4th | 5 || Tritone (Aug 4 / Dim 5) | 6 || Perfect 5th | 7 || Minor 6th | 8 || Major 6th | 9 || Minor 7th | 10 || Major 7th | 11 || Perfect octave | 12 |

Method:1. Count the staff positions (line + space jumps) including both ends → gives you the number (2nd, 3rd, …).2. Count the semitones on the keyboard → cross-check against the table → gives you the quality.

Working in a key signature

Within a major scale, the intervals from the tonic to each scale degree are always:

| From tonic to | Interval ||---------------|----------|| 2nd | Major 2nd || 3rd | Major 3rd || 4th | Perfect 4th || 5th | Perfect 5th || 6th | Major 6th || 7th | Major 7th || 8th | Perfect octave |

> Trick: in a major key, all intervals built upward from the tonic are major or perfect. There are no naturally-occurring minor intervals from the tonic of a major key — they only appear when you alter notes with accidentals or use a different starting note.

Chapter 5 — Relative Minor

Every major key has a relative minor that shares its key signature. The relative minor's tonic sits a minor 3rd below the major tonic (or equivalently, the 6th degree of the major scale).

| Major | Relative minor | Shared sharps/flats ||-------|----------------|----------------------|| C major | A minor | none || G major | E minor | F♯ || F major | D minor | B♭ || D major | B minor | F♯ C♯ || B♭ major | G minor | B♭ E♭ |

The natural minor scale uses only those shared sharps/flats. (Harmonic and melodic minors add accidentals — Grade 3 material.)

> Where I got stuck: I kept confusing relative minor with parallel minor.> - Relative: same key signature, different tonic (C major ↔ A minor).> - Parallel: same tonic, different key signature (C major ↔ C minor).>> The fix that stuck: "Relative" = the related key with the same parents (signature). "Parallel" = the parallel universe with the same name (tonic). Two distinct concepts; pin them down separately.

Chapter 6 — Articulation

Grade 2 starts to care about how you play, not just what.

| Marking | Meaning ||---------|---------|| Legato | Connected, smooth (often shown with a slur) || Staccato (dot above/below note) | Short, detached — roughly half the written value || Tenuto (line above/below) | Held to full value, slight emphasis || Accent (>) | Played louder than surrounding notes || Slur (curved line over multiple notes) | Phrase boundary; play legato within || Fermata (eye-shaped pause) | Hold longer than written |

> Trick: the staccato dot means "half the value, the rest is silence". So a staccato crotchet = a quaver of sound + a quaver of silence. Don't clip the note artificially short; just lift the finger earlier and let the air do the rest.

Touch types — the three you'll use most

- Legato — finger weight transfers from key to key without lifting. The previous finger releases as the next presses, like walking.- Staccato — the finger bounces off the key. Wrist relaxed; energy from the fingertip, not the arm.- Portato — between legato and staccato, marked with dots under a slur. Each note slightly separated but still "singing" through.

How to choose

Pick one piece that excites you (whatever the level) and one that's slightly easier than your current ability. The exciting piece pulls you forward; the easy piece is where you actually drill technique without frustration. Rotate every 4–6 weeks.

> Trick: finish every learning session by playing the easiest piece you know at performance tempo, all the way through. It costs 90 seconds and reinforces what "finished" feels like. The pieces you struggle with don't get this treatment — only the ones you've already mastered.

Chapter 8 — Practice Templates

"Difficult bar" loop (10 minutes)

Pick the worst 4-bar passage in your current piece. Set metronome to half your target tempo. Play those 4 bars 10 times in a row without stopping. If you fail, slow the metronome by 10 BPM and start the count again. After 10 clean reps, raise BPM by 5. Repeat until you hit target.

This is the single highest-leverage practice technique. Twenty minutes of this beats two hours of "playing the whole piece from the top".

"Pulse robot" warm-up (5 minutes)

Set the metronome to quarter = 60. Play any scale you know, one note per click, both hands separate. Then both hands together. Then two notes per click. Then four. The point isn't the scale — it's getting your hands locked to an external clock.

"Mock exam" run (20 minutes, once a week)

Treat one full practice session per week as the exam itself. Set up your music, your phone-recorder, your metronome. Play your three current pieces back-to-back with no restarts. Then listen to the recording. Mistakes you didn't notice in the moment will jump out on playback. That's your homework for the next six days.

Chapter 9 — Aural Skills at Grade 2

ABRSM Grade 2 aural adds:

- Identify whether a phrase is in 2/4, 3/4, or now 6/8.- Sing back a slightly longer phrase (4 notes).- Clap back a 4-bar rhythm.- Identify a feature: "loud", "soft", "smooth", "detached", "ending on a different note than it started" — broader description.

> Trick: to tell 6/8 from 3/4, listen for the gallop. 3/4 walks evenly in threes — ONE-two-three, ONE-two-three. 6/8 lopes — DA-da-da DA-da-da. Tap your foot. If the foot lands twice per bar, it's 6/8. If three times, it's 3/4. The foot doesn't lie.

Chapter 1 — Pitch Notation Recap

Terminology

- Pitch (音高) — how high or low a note sounds, measured in frequency.- Accidental — sharp ♯ / flat ♭ / natural ♮ applied to a single note.- Sharp (♯) — raise the pitch by one semitone.- Flat (♭) — lower the pitch by one semitone.- Natural (♮) — cancel a previous sharp or flat.

An accidental affects every occurrence of that note in the same octave for the rest of the bar — then the barline resets it. A key signature is the only "global" accidental.

Ledger lines (加線)

Grade 1 requires one ledger above and one below in each clef.

- Treble: one line above the staff = A5, one line below the staff = Middle C (C4).- Bass: one line above the staff = Middle C (C4) as well (the same note), one line below the staff = E2.

> Trick: Middle C is the connector. It sits one ledger below the treble staff AND one ledger above the bass staff. Same key on the piano, two ways to write it. Drill this until it's automatic — Grade 2 and beyond use it constantly.

Chapter 2 — Note Values (音符的時值)

English / 中文 / symbol table

| EN | 中文 | UK name | Beats in 4/4 ||----|------|---------|--------------|| Whole note | 全音符 | Semibreve | 4 || Half note | 二分音符 | Minim | 2 || Quarter note | 四分音符 | Crotchet | 1 || Eighth note | 八分音符 | Quaver | ½ |

ABRSM uses the UK terms (semibreve, minim, crotchet, quaver). American sheet music uses whole/half/quarter/eighth. Same notes, different names. Get used to both.

Rests

Every note value has a matching rest. The same beat counts apply — a crotchet rest is 1 beat of silence in 4/4.

> Trick: I confused the whole-note rest (hangs down from a line) and the half-note rest (sits on top of a line). Memory aid: "the whole rest is a hole — it falls down. The half is half full — it sits up." Silly, never forgot it again.

Dots and ties

- A dot after a note adds half its value. Dotted minim = 2 + 1 = 3 beats.- A tie joins two notes of the same pitch — sum their durations.- A slur joins two notes of different pitches — phrasing, not duration.

Chapter 3 — Time Signatures (拍號)

Grade 1 covers 2/4, 3/4, 4/4 only.

The top number = beats per bar. The bottom number = which note value gets one beat (4 = crotchet).

| Time signature | Beats per bar | Feel ||----------------|---------------|------|| 2/4 | 2 | March (left-right-left-right) || 3/4 | 3 | Waltz (ONE-two-three) || 4/4 | 4 | Pop, hymn, default (ONE-two-three-four) |

The first beat of every bar is the strongest. Place natural emphasis there; the bar lines exist precisely to tell you where to push slightly.

Chapter 4 — Keys and Key Signatures

Grade 1 syllabus: C major, G major, F major.

| Key | Sharps/Flats | Memory anchor ||-----|--------------|---------------|| C major | none | Easy default || G major | 1 sharp: F♯ | "Goes up" → sharp || F major | 1 flat: B♭ | "Falls down" → flat |

Scale construction reminder

Major scale pattern in semitones: W W H W W W H (whole, whole, half, whole, whole, whole, half).

Apply from any tonic and you get a major scale. From C: all whites. From G: hits F♯ as the 7th. From F: hits B♭ as the 4th.

> Trick: the major-scale pattern doesn't change — only the starting note does. If you can derive C major from scratch, you can derive every major scale by counting W W H W W W H with your finger on the keyboard. Don't memorise 12 scales; memorise one pattern and 12 starting points.

Tonic, Dominant, Subdominant

For any major scale:

- Tonic (I) — the 1st degree. Home note. C in C major.- Subdominant (IV) — the 4th degree. F in C major.- Dominant (V) — the 5th degree. G in C major.

These three notes form the primary triads of the key, the most important chords in any major piece. Half of pop and folk music is built from just I, IV, V.

> Where I got stuck: I assumed "dominant" meant "loudest" or "main". It actually means the 5th, always. The label is positional, not musical. Once I stopped overthinking it, every scale fell into place.

Chapter 5 — Intervals (Number Only)

At Grade 1 you only need to identify the number of an interval (2nd, 3rd, etc.), not its quality (major / minor / perfect). Quality starts at Grade 2.

Counting

Count the lower note as 1, then count up the staff lines and spaces to the upper note. The count includes both notes.

| Interval | Staff positions ||----------|-----------------|| Unison | Same line/space || 2nd | Adjacent line + space || 3rd | Line to next line, or space to next space || 4th | Line to space-after-the-next-line || 5th | Line to second line above || 6th | Space to third space above || 7th | Line to fourth line above (one short of an octave) || Octave (8th) | Same letter, one position up |

> Trick: 3rds and 5ths "jump white" — they go line-to-line or space-to-space, looking visually stacked. 2nds and 4ths "step black" — they touch a line and the adjacent space. Once your eye reads these shapes, you stop counting notes one-by-one.

Chapter 6 — Hands-Together Coordination

You played hands together in Post 00 already with "Twinkle". Grade 1 expands this. The technique:

1. Each hand alone, played until boring. Genuinely boring — no mistakes, no thinking.2. Hands together at half speed. Eyes on the page, not the hands.3. Pulse first, accuracy second. If one hand stumbles, don't stop the pulse. Drop the wrong-hand note rather than break the beat.4. Slow with metronome. Crotchet = 60. Once smooth, raise by 5 BPM increments.

> Where I got stuck: my left hand was 6 weeks behind my right. The fix: I practised only the left hand for one full week. No right hand at all. Result: by the next week my left could play its own line cleanly, and hands-together suddenly worked.

Chapter 8 — Aural / Listening Skills

Grade 1 ABRSM practical includes an aural test. The skills:

> Trick: whistling is sneaky-good for aural training. If you can whistle the tune you've been practising, you've internalised the pitch shape. If you can only "sort of" whistle it, you haven't. The whistle is a free pitch test.

12:T3212,The first post in a self-study piano series. Goal: by the end of this one you can sit at any keyboard, find any note in under five seconds, and play three short pieces from memory. Skip the marketing fluff and go straight to the muscle memory.

> Series map: 00 Beginner (this post) → 01 Grade 1 → 02 Grade 2 → 03 Grade 3 → 04 Grade 4. Grades 5–8 will follow.

Learning Outcome

- Sit comfortably at the keyboard with healthy posture.- Name every white key on sight — both directions, both clefs.- Find Middle C on any size piano without thinking.- Play three short pieces with both hands.- Recognise the difference between a piano, an upright, a digital, and a synth — and pick the right one for practice.

Chapter 1 — Why piano is a good first instrument

The keyboard is the clearest visual map of Western music. Every other instrument hides pitch behind a fingering chart; the piano lays the entire pitch space out in front of you, left-to-right, low-to-high. If you understand "how a scale looks" on the piano, you understand it on a guitar, a violin, or in a software synth — you just don't see it as plainly.

A second practical reason: the piano is monophonically simple but polyphonically rich. Beginners can produce a clean tone from day one (press → sound), while advanced players spend a lifetime on the same instrument. Few instruments span that range.

> Where I started: I wasted my first two weeks googling "best digital piano under $500" instead of practising. The truth is any 88-key weighted keyboard from a major brand (Yamaha, Roland, Casio, Kawai) is fine for the first year. The piano you have and play every day beats the piano you research and never own.

Chapter 2 — Picking an instrument

Acoustic (real) piano

- Upright (直立式) — most homes. Footprint 150 cm wide, depth 60 cm. Tone is good but action is lighter than a grand.- Grand (平台式) — long horizontal action, more responsive. Babies (150 cm) to concert (275 cm). Expensive, needs tuning twice a year.

Digital piano

- Weighted action (重錘鍵盤) is non-negotiable for serious practice. "Semi-weighted" and "synth action" feel different and will delay your finger development.- 88 full keys preferred over 76 or 61 — exam pieces will eventually need the full range.- Built-in speakers are a "nice to have"; quality varies. Headphones bypass the problem and are quieter for housemates.

What you actually need (the honest list)

| Item | Necessity | Why ||------|-----------|-----|| 88-key fully-weighted digital, or any acoustic upright | Essential | Your hands form habits around action weight || Bench at correct height | Essential | Wrong height = wrist strain in 4 weeks || Metronome (app fine) | Essential | The most-skipped tool that fixes the most-common problem || Music stand with light | Highly recommended | You'll be reading every session || Headphones (digital) | Recommended | Practise at any hour without conflict || Pedal (sustain) | Eventually | Not for week 1; needed by week 8 |

> Trick: the right bench height = your forearms parallel to the floor when fingers rest on the keys, wrists neither dropping nor arching. Sit too high → you push the keys down with extra force and tense the wrist. Sit too low → you reach up and the fingers fight gravity. Adjust this on day one. Re-check it monthly.

Chapter 3 — The keyboard map

Black-key landmarks

The black keys come in groups of 2 and 3. The 2-group anchors C-D-E; the 3-group anchors F-G-A-B.

- The white key immediately left of a 2-group is always C.- The white key immediately left of a 3-group is always F.

These two anchors are the only ones you ever need to memorise. The other letters (D, E, G, A, B) are derived by counting in alphabetical order from C or F.

> Trick: the 2-group is C-D-E; 3-group is F-G-A-B. Stack the consonants in your head: Car Drives East, Fish Goes Around Back. Cheesy works.

Middle C

The C closest to the centre of the keyboard. On an 88-key piano this is the fourth C from the bottom — C4 in scientific pitch notation. On a 61-key it's the third C. Either way, find the centre, find the 2-group nearest it, drop your right thumb on the white key to the left of that pair.

Octaves

Same letter, doubled frequency: $f{n+12} = 2 \cdot fn$. The keyboard pattern repeats every 12 keys (7 white + 5 black). Once you memorise the 7-white-key span (C D E F G A B), the entire 88-key keyboard is mapped.

Chapter 4 — Posture and hand mechanics

Sitting

- Bench centred on Middle C.- Sit on the front third of the bench, not slumped back.- Feet flat on the floor. (Smaller players: get a footstool; dangling feet cause back tension.)- Elbows roughly at keyboard height.- Shoulders down and relaxed. No shrugging up to the ears.

Hands

- Curved fingers, as if holding a tennis ball.- Strike with the fingertip, not the pad.- Wrist is level with the back of the hand — flat, not collapsed, not arched.- Thumb plays with its side, slightly tucked under.

Finger numbering

| Hand | 1 | 2 | 3 | 4 | 5 ||------|---|---|---|---|---|| Right | Thumb | Index | Middle | Ring | Little || Left | Thumb | Index | Middle | Ring | Little |

Both hands use the same scheme — the thumb is always 1 for its own hand. Sheet music writes RH finger numbers above the staff, LH below.

> Where I got stuck: I kept dropping my wrist when playing softly. Fix: I propped a coin on the back of my hand during slow practice. If it stayed put for eight bars, my wrist was level. Sounds gimmicky, fixes it in three days.

Chapter 5 — Reading the staff (just enough for now)

Only what you need for the three first songs is covered here. Full staff theory is in Post 01.

Treble (right hand)

Lines bottom to top: E G B D F — "Every Good Boy Does Fine".Spaces bottom to top: F A C E — already spells FACE.

Bass (left hand)

Lines: G B D F A — "Good Boys Do Fine Always".Spaces: A C E G — "All Cows Eat Grass".

Middle C bridges both

Middle C sits on the first ledger line below the treble staff and the first ledger line above the bass staff. The same note, written two ways. The grand staff joins the two clefs with a brace — right hand on top, left hand on bottom.

> Analogy: the grand staff is two ladders bolted together at Middle C. Right hand climbs the top ladder (higher pitches), left hand climbs the bottom ladder (lower pitches). Middle C is the rung they share.

Chapter 6 — Three first pieces

These are the canonical first songs. I picked them because (1) the right-hand melody fits inside one hand position, (2) the left hand uses only two or three notes, and (3) you've heard them since you were five — your ear corrects you before your brain does.

Piece 1 — "Ode to Joy" (Beethoven, Symphony No. 9)

Hand position: RH thumb on Middle C.

Repeat. Then play:

Why this piece: the melody never leaves the five-finger span of one hand. You don't move your wrist. The whole song is your introduction to "fingers stay put, brain reads."

> Trick: count "1 2 3 4" steadily through it — every note is one beat except the last D of each line, which is two beats. If you can clap it without playing, you can play it.

Piece 2 — "Mary Had a Little Lamb"

Hand position: RH thumb on Middle C.

Why this piece: introduces a longer arc with repetition. You'll notice the same three-note shape repeats — once you spot the pattern your eye stops reading note-by-note.

Piece 3 — "Twinkle Twinkle Little Star" — both hands

RH: thumb on Middle C.

For your first attempt, just play the C3 long-held for each bar — one note per bar. Hold it under the right hand.

> Where I got stuck: hands together on day three felt impossible. Fix: don't try hands together until each hand is boring on its own. "Boring" is the right level — if you have to think, you're not ready. Each hand should run on autopilot, and only then do you stack them.

Chapter 7 — How to practise (the meta-skill)

If you take one thing from this post, take this: slow practice with full attention beats fast practice with split attention by an order of magnitude. The brain encodes accuracy, not speed. Speed comes free once accuracy is locked in.

Daily routine, 25–30 minutes

| Block | Time | What ||-------|------|------|| Warm-up | 3 min | 5-finger pattern, C major position, RH then LH then both || Note-naming | 2 min | Pick a random key, name it out loud || Today's piece | 15 min | One section at a time, slow, no mistakes || Sight-read | 5 min | Brand-new short piece, no repeats — see how far you get || Cool-down | 2 min | Replay your most-mastered piece for fun |

Slow practice rules

1. Start at a tempo where you make zero mistakes. Mistakes at speed become mistakes at all speeds.2. Loop the section that's hard, not the whole piece. Four bars. Ten times. Then move on.3. Hands separate before hands together. Always.4. Watch your hand for one minute, then watch the page for one minute. Alternate. Eyes-on-page-only forces you to internalise the keyboard map.5. End on a success. The last attempt before you stop is the one your brain rehearses overnight.

> Trick I steal from sports coaches: finish every practice session by playing the easiest passage of the day one more time, slowly and perfectly. Going to bed on a clean run reinforces the right pattern in sleep. Going to bed frustrated reinforces the wrong one.

13:T3d0e,Prompting is the practice of writing inputs that steer a Large Language Model (LLM) toward useful outputs. It is part interface design, part rhetoric, and part empirical science. This note covers the foundations and the techniques that have been validated by published research, with worked examples you can copy.

Learning Outcome

- Explain what a prompt is and why model behaviour is sensitive to its phrasing.- Decompose a prompt into its functional parts (instruction, context, examples, format spec).- Apply core techniques: zero-shot, few-shot, chain-of-thought, role conditioning, decomposition, and self-consistency.- Recognise common anti-patterns and explain why they fail.- Design an evaluation harness with a golden set + rubric + A/B framework.- Read a research paper on prompting and judge whether its claims will transfer to your task.

Chapter 1 - Foundations

Terminology

- Prompt — the full token sequence the model conditions on before generating the next token.- Completion — the model's generated response.- Token — sub-word unit (4 characters of English on average). All limits (context window, throughput, billing) are measured in tokens.- Context window — maximum prompt+completion length the model can attend to.- In-context learning (ICL) — model adapts its behaviour from examples in the prompt without weight updates. Reported in Language Models are Few-Shot Learners, Brown et al. (2020).- Temperature — sampling parameter; $0$ is greedy, higher values increase diversity.- Top-p / Top-k — nucleus / top-k sampling, alternatives to temperature.- System / developer message — privileged prompt segment used to set persistent behaviour. Mechanism formalised by The Instruction Hierarchy, Wallace et al. (2024).

Why prompts matter

An LLM is a next-token predictor over a learned distribution $P(tn \mid t1, \dots, t{n-1})$. The prompt is the conditional sequence $t1, \dots, t{n-1}$. Two prompts that read as semantically equivalent to a human can produce very different distributions because the model is sensitive to token-level cues it has learned to associate with answer quality (formality, code-block fences, "Let's think step by step", etc.).

This sensitivity has been measured empirically. Lu et al. (2022) showed that simply reordering few-shot examples can swing accuracy on classification benchmarks by tens of percentage points. Sclar et al. (2024) showed that benign formatting changes (newline vs. colon as separator) shift task accuracy by a comparable margin.

The practical consequence: prompts are programs. They deserve version control, testing, and review.

How the model "reads" a prompt

A typical chat-tuned model receives a structured sequence — for instance OpenAI's ChatML or Anthropic's / turn markers — where each turn is tagged with a role. The model has been fine-tuned (instruction-tuned + RLHF or DPO) to:

1. Treat the system / developer message as a high-priority constraint.2. Treat user messages as questions or requests.3. Treat its own prior responses as commitments to maintain consistency with.

The training procedure was first detailed in InstructGPT, Ouyang et al. (2022) and the Anthropic RLHF paper, Bai et al. (2022). The hierarchy of trust between roles was later sharpened in The Instruction Hierarchy, Wallace et al. (2024).

Chapter 3 - Core Techniques

Zero-shot

Ask the question directly with no examples. Works when the task is well-represented in the training distribution (translation, summarisation, common QA).

Few-shot (in-context learning)

Provide $k$ input/output pairs, then the new input. Brown et al. (2020) showed few-shot prompting closes a large fraction of the gap to fine-tuning on many tasks without any gradient updates.

Tips:

- Order examples easy → hard (Lu et al., 2022).- Make examples cover the failure modes you observe in zero-shot, not the easy cases.- Keep formatting identical across shots; a stray newline can degrade accuracy (Sclar et al., 2024).

Chain-of-Thought (CoT) prompting

Ask the model to show its work before committing to an answer. Reported in Chain-of-Thought Prompting Elicits Reasoning in Large Language Models, Wei et al. (2022). Improves arithmetic, symbolic, and commonsense reasoning on large models.

Two variants worth knowing:

- Zero-shot CoT: append "Let's think step by step." Kojima et al. (2022). Cheap and surprisingly effective.- Self-consistency: sample $n$ chains at temperature $>0$, take the majority vote on the final answer. Wang et al. (2022). Improves arithmetic accuracy further at $n \times$ cost.

Role / persona conditioning

Setting an expert persona biases vocabulary, depth, and inferred audience. The effect is real but smaller than CoT or few-shot; treat it as fine-tuning of style, not capability.

Decomposition

Break a hard problem into ordered sub-problems and prompt each separately, chaining outputs. Equivalent to Khot et al. (2023) "Decomposed Prompting" or least-to-most prompting by Zhou et al. (2023).

The chain is easier to debug than a single monolithic prompt; you can swap or rerun any step.

ReAct (Reasoning + Acting)

Interleave reasoning steps with tool calls. Yao et al. (2023). The model alternates between  (a reasoning step),  (a tool call), and  (tool result), until ready to emit an .

ReAct is the foundation pattern under most "agent" frameworks (LangChain, LlamaIndex, modern function-calling SDKs).

Three escalating strengths:

| Strength | Mechanism | Reliability || --- | --- | --- || Soft | Natural-language description ("return JSON") | 60-80% || Schema | Provide explicit schema (TypeScript / JSON Schema / Pydantic) | 90% || Hard | Use the provider's structured-output / JSON-mode API | 100% (provider-enforced) |

If you need a guaranteed shape, use the provider's structured output. Soft format is convenient but will fail on tail cases.

Chapter 5 - Reasoning Boosters

Self-consistency

Already mentioned. Formally: sample $n$ chains $c1, \dots, cn$ at $T > 0$, extract the final answer $ai$ from each, return $\arg\maxa \sumi \mathbb{1}[ai = a]$. The probability that the majority answer is correct converges to the per-sample accuracy raised to a Condorcet-style power as $n$ grows, when individual samples are conditionally independent given the question.

Tree of Thoughts (ToT)

Yao et al. (2023). Generalises CoT from a chain to a search tree. The model proposes multiple next-thoughts at each step, a value model scores each, and a search algorithm (BFS/DFS) explores. Helps on combinatorial problems (Game of 24, crosswords) where a single chain commits too early.

Reflexion

Shinn et al. (2023). After a wrong attempt, the model writes a critique of its own trace; that critique is appended to context for the next attempt. The agent improves across attempts within a single session.

Step-Back prompting

Zheng et al. (2024). Before answering a specific question, ask the model to first derive the general principle that governs the question. The principle then conditions the specific answer. Improves abstract / multi-step reasoning.

Chapter 7 - Evaluation

A prompt is a piece of software, so evaluate it like software.

Golden set

A small, curated set of representative inputs with hand-graded expected outputs. 30–100 items is enough to detect a 5pp accuracy shift.

Rubric

Decompose "is the output good?" into yes/no axes. For a summarisation task you might score:

- Factual (no hallucinated entities)- Complete (all named main points present)- Concise (within length limit)- Format (parses as JSON)- Refusal (correctly refused when no claim present)

Each axis scored 0/1 by a human grader or a separate "judge" model.

LLM-as-judge

Zheng et al. (2023). A stronger model grades a weaker model's output against a rubric. Cheap, scales, but biased toward outputs that look like the judge's style. Use a different family of model as the judge where possible, and spot-check 10% with a human.

A/B framework

Track $\Delta$ per axis, not just overall. A change that improves factuality but hurts conciseness is still a regression on the conciseness axis.

Statistical sanity

With $n=100$ binary outcomes, the 95% confidence interval on accuracy is roughly $\pm 10$pp around the observed rate. Differences smaller than that are noise. Increase $n$ or repeat the run to tighten.

Chapter 8 - Tool Use and Structured Output

Modern model providers expose two APIs that should replace most prompt-engineering hacks:

Function calling / tool use

You declare a JSON schema for one or more tools; the model picks one and emits arguments matching the schema. The runtime executes the tool and returns the result, which you append to the conversation and prompt again.

The model is fine-tuned to know when to call a tool versus answer directly. This is more reliable than ReAct in raw text because the model emits parsed JSON via the API.

Structured output (JSON / Pydantic mode)

You supply the full output schema; the provider's decoder constrains generation so the response is guaranteed valid against the schema. Eliminates "the model added a friendly preamble that broke my parser" failures.

When NOT to use tools

If the task is pure transformation of text the model already has the knowledge for (summarise, translate, classify), tools add latency and cost. Use tools when you need fresh data, deterministic computation, or side effects.
