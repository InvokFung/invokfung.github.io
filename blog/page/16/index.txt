e:T264f,An index is a B-tree (or specialised structure) on one or more fields that lets MongoDB find documents without scanning the whole collection. Indexes turn a 60-second query into a 5-millisecond one — and turn an undertuned cluster into a poorly-running mess if used wrong (too many, too wide, wrong order). This post covers every index type, the ESR rule (Equality, Sort, Range) for compound-index ordering, partial / sparse / TTL / wildcard / hashed variants, index intersection, covered queries, and the build options (, , ).

Chapter 1 — Index basics

Every MongoDB collection has at least one index — on  (unique, auto-created, can't drop). All others are user-created.

Naming: auto-generated as  joined by . Use  option for custom.

Cost trade-off

- Indexes speed reads that filter / sort / project on indexed fields.- Indexes slow writes — every insert / update / delete must update every relevant index.- Indexes use RAM — frequently accessed parts of indexes must fit in the WiredTiger cache for speed (Post 15).- Indexes use disk — typically 10-30% of collection data size each.

Rule: index for the queries you actually run, drop indexes never used (Post 04 covers  to find unused).

A query is covered when:

Chapter 14 — Index intersection (use sparingly)

MongoDB can intersect two single-field indexes to satisfy a multi-field query, but it's usually slower than a single compound index that matches the query.

Rule: design compound indexes for the queries you run, not single-field per-column indexes.

Chapter 5 — Copy semantics

The compiler generates a copy constructor and copy assignment operator by default. They do member-wise copy. For most classes this is fine. For classes that own raw memory, you must define them.

The default member-wise copy would have copied the pointer — both objects would point to the same memory, and the second destructor would double-free. Classic bug.

Chapter 6 — Move semantics (C++11+)

Moving = transferring ownership of resources without copying. Crucial for performance when you want a new object to take over what an old one had.

When does move happen?- Returning a local from a function.-  cast.- Passing a temporary (rvalue) to a constructor.

> Trick: if you implement copy + dtor by hand, also implement move. Otherwise the compiler won't generate move automatically, and your class falls back to copies in performance-critical places.

The Rule of Five

If you write any of: destructor, copy ctor, copy assign, move ctor, move assign — you should write (or  / ) all five.

The Rule of Zero

If your class only owns members that already handle their own copy/move/destruction (smart pointers, standard containers), write none of the five. Let the compiler default everything.

This is the modern way. Reach for explicit Rule-of-Five only when wrapping a C library or hand-managing memory.

Chapter 1 — What MongoDB is

Terminology

- MongoDB — distributed document database; open-source core + commercial Atlas service.- Document — a BSON object: ordered key-value pairs, nested arrays + sub-documents. Conceptually a JSON object with extra types (ObjectId, Date, Binary, Decimal128).- Collection — a group of documents (analogous to a SQL table; no enforced schema by default).- Database — a group of collections.- BSON — Binary JSON, the on-disk + on-wire format. Adds types JSON lacks (ObjectId, Date, Binary, etc.) and length-prefixes for fast traversal.-  — every document has one. Auto-generated  (12 bytes: timestamp + machine + pid + counter) unless you supply your own.- Replica set — a group of  processes that maintain the same data; provides HA + read scaling.- Sharded cluster — multiple replica sets partitioned by a shard key; provides horizontal write scaling.

Chapter 2 — Document vs relational mental model

| Relational | MongoDB ||------------|---------|| Database | Database || Table | Collection || Row | Document || Column | Field || Primary key |  || Foreign key | Reference (manual or ) || Join |  aggregation stage || Schema enforced by DDL | Optional schema validation () || Transactions | Multi-document transactions (since 4.0) || Index | Index (B-tree, hashed, text, geo, vector) |

The shift in thinking:

- Relational: normalise first, denormalise for performance.- Document: denormalise first (embed related data) for read locality; reference only when reuse + size dictate.

Post 07 (Schema Design) covers this decision deeply.

When MongoDB fits

- Document-shaped data (catalogue items, user profiles, content items).- High write throughput with sharding.- Flexible / evolving schema (early product, multi-tenant SaaS with per-tenant variation).- Geographic + full-text + vector queries on the same data.- Real-time change streams.

When MongoDB doesn't fit (consider alternatives)

- Heavy multi-row ACID transactions → Postgres / CockroachDB.- Complex relational reporting + ad-hoc joins → relational + warehouse.- Pure key-value at giant scale → Redis / DynamoDB.- Strict tabular columnar analytics → ClickHouse / BigQuery.

Three-octave scales: every key

By Grade 8 you must own all 12 major and all 12 minor (× 2 = harmonic + melodic) scales — three octaves each.

Practice rotation (4-week cycle)

| Week | Major keys | Minor keys ||------|------------|------------|| 1 | C, G, D, A, E | A, E, B, F♯, C♯ || 2 | B, F♯, C♯, D♭, A♭ | G♯, D♯, A♯, B♭, F || 3 | E♭, B♭, F | C, G, D || 4 | Review weakest 4 keys | Review weakest 4 keys |

15 minutes scales per day, rotating focus across the cycle.

Double stops at Grade 8

| Interval | Difficulty | Key example ||----------|------------|--------------|| 3rds | Moderate (Grade 6+) | G, D, A major || 6ths | Moderate | G, D, A major || Octaves | Hard | G, D major || 10ths | Very hard | Selected keys, single octave || Fingered octaves | Very hard | Heifetz scale system |

10ths require an enormous left-hand stretch (1st + 4th finger on adjacent strings, an octave and a third apart). Most adult learners take 1–2 years to play 10ths reliably.

> Trick: don't force 10ths into pieces if they're not in the syllabus. Practise as a stretch exercise (open-palm yoga for the violin hand). When the syllabus demands them, you'll already have the reach.

Chapter 2 — Virtuoso bowing toolkit

By Grade 8 every technique is in active use. Quick reference:

| Bowing | Description | Typical use ||--------|-------------|--------------|| Détaché | Smooth separate strokes | Most Classical/Romantic passages || Legato / slur | Connected, one bow | Lyrical lines || Staccato | Sharp short, on string | Articulated passages || Slurred staccato | Multiple stops, one direction | Long lines with articulation || Spiccato | Bow lifts between notes | Light, dancing passages || Sautillé | Very fast spiccato | Fast 16th-note passages || Ricochet | Multiple bounces per drop | Showpieces, cadenzas || Martelé | Hammered, percussive | Accents, dramatic openings || Flying staccato | Lifts each note, one direction | Showpieces || Col legno battuto | Tap with the bow stick | Modern repertoire, Mars (Holst) || Col legno tratto | Draw with the wood | Eerie effects, rare || Sul ponticello | Near the bridge | Glassy colour || Sul tasto | Over the fingerboard | Soft, dreamy colour || Pizzicato | Plucked | Common; Bartók pizz snaps string against fingerboard || Jeté | "Thrown" — multiple notes from a single bounce-then-draw | Showpieces || Tremolo | Rapid bow oscillation on one note | Suspense, orchestral effect |

A piece using nearly all of them

Sarasate Zigeunerweisen uses détaché, legato, spiccato, sautillé, ricochet, harmonics, pizzicato, and flying staccato in one 9-minute work. Reference repertoire for technique synthesis.

Chapter 3 — Vibrato as expression

By Grade 8, vibrato is not "on" or "off" — it's a continuous parameter.

The four vibrato variables

1. Width — narrow (subtle warmth) vs wide (passionate Romantic).2. Speed — slow (sustained nobility) vs fast (intense, virtuoso fire).3. Continuous vs delayed — start the vibrato instantly, or let the note begin straight then add vibrato.4. Pulse — strict steady vibrato vs phrased vibrato (slows and speeds with the phrase).

Vibrato style per period

| Period | Vibrato preference ||--------|---------------------|| Baroque | Sparse, narrow, often as ornament (varies by historical performance practice) || Classical | Selective; on long notes mostly || Romantic | Continuous, wide, warm || 20th-c / Modern | Variable; sometimes deliberately senza vibrato || Folk / world | Narrow, fast, intermittent |

> Trick: listen to one violinist play the same piece from different periods (e.g., Hilary Hahn plays both Bach and Tchaikovsky). Notice how her vibrato choice changes. Internalise the period-appropriate sound by daily listening.

Chapter 6 — Performance polish

Grade 8 exams test interpretation, not just technique.

Programme planning (typical Grade 8 recital)

| Slot | Choice | Length ||------|--------|--------|| 1 | Baroque (Bach, Handel) | 5–8 min || 2 | Classical / early Romantic (Mozart, Beethoven) | 8–12 min || 3 | Late Romantic / Modern (Brahms, Ravel, Bartók) | 5–10 min || 4 | Virtuoso showpiece | 4–8 min |

Variety across periods is graded.

Stage presentation

- Tuning ritual: walk onstage, tune visibly, take a breath, begin.- Eye contact with pianist (if accompanied) before nodding to start.- Bow direction visible to audience.- Recovery: if you make a mistake, don't react. Continue. Audience usually misses small errors.

Stage anxiety management

- Daily mock performance for 30 days before exam. Play full programme top-to-bottom every day.- Performance-day routine: same warm-up, same meal timing, same clothing dress rehearsal.- Breathing: 4 seconds in, 6 seconds out, before walking onstage. Lowers heart rate.- Visualisation: mentally walk through the recital from arrival to bow, daily for 2 weeks before exam.

> Where I got stuck: I prepared technically but didn't rehearse the experience of performing. First exam: hands shook on the bow. Fix: 4 weeks of daily mock recitals — in front of family, friends, even an empty room with a recording running. By exam day, the room was less intimidating because I'd "performed" 30 times already.

Chapter 7 — Stylistic understanding

Grade 8 exams ask: Why is this Baroque ornament played this way? You should know:

Baroque (1600–1750)

- Trills start on upper note, on the beat.- Less vibrato; vibrato as occasional ornament.- Strong terraced dynamics (sudden f to p, not gradual).- Rubato sparingly; mostly steady tempo.- Détaché with subtle weight changes for phrase shape.

Classical (1750–1820)

- Balanced phrases, clear structure.- Vibrato on long notes only.- Dynamic gradients (cresc, dim) more frequent.- Détaché with elegance; spiccato light.

Romantic (1820–1900)

- Vibrato continuous.- Wide dynamic range; rubato substantial.- Long lyrical lines.- Full use of register; expressive shifts welcomed.

Modern (1900+)

- Technique-heavy.- May use extended techniques.- Senza vibrato on certain passages.- Irregular metres + atonal pitch language possible.

How to internalise style

Listen to one piece per period weekly, with score in hand. Mark performance choices (vibrato, rubato, bowing). Compare across recordings. Over a year, style sensitivity becomes second nature.

Chapter 1 — Harmonics: the bell-like tones

A harmonic is a high, pure, bell-like tone produced by lightly touching the string at specific nodes (rather than pressing down).

Natural harmonics

Found at division points of the open string:

| Touch point on string | Resulting harmonic | Pitch ||-----------------------|--------------------|-------|| 1/2 (octave node) | 1st overtone | Open string + octave || 1/3 node | 2nd overtone | Octave + 5th || 1/4 node | 3rd overtone | Two octaves above open || 1/5 node | 4th overtone | Two octaves + maj 3rd |

The 1/2 node on the A string is found by lightly touching with your 4th finger at the position where the 4th finger would normally play A5 (one octave above open A). The sound: a soft, ringing high A — an octave higher than expected.

> Trick: harmonics need almost no finger pressure — just a feather touch. If you press, you get a muted scratchy note. If you brush, you get the pure overtone. Practise the touch on open A: bow long stroke, feather-touch where the 3rd finger sits in 1st position. The ringing high A (two octaves up) appears almost magically.

Artificial harmonics

Press one finger firmly (the "stopping finger") and touch with another finger a 4th higher (the "harmonic finger"). The pitch produced is two octaves above the stopped pitch.

Notation: diamond-shape note head for the touched note, plus regular note for the stopped note.

Used famously in: Tchaikovsky Violin Concerto, Paganini Caprices, Ravel Tzigane.

Chapter 2 — All positions: fluency target

By Grade 7, you've learned half, 1st, 2nd, 3rd, 4th, 5th, 6th, 7th positions. Now: 8th position and fluency across all of them.

8th position

On the A string: 1=B5, 2=C♯6, 3=D6, 4=E6 (right at the top of the violin's standard range for most pieces).

The left hand pivots: thumb shifts to a different angle, hand approaches the bridge.

The fluency goal

You should be able to:1. Shift to any position without looking.2. Find the correct first finger pitch within a quarter-tone, on the first try.3. Choose appropriate position for expression (tone colour) — not just to reach a note.

> Trick: practise a single piece entirely in 1st position, then again entirely in 3rd, then entirely in 5th (skipping notes you can't reach). The same melody in different positions sounds different — different string vibrations, different timbre. Pick the position that suits the music.

Position landmarks (physical)

| Position | Hand landmark ||----------|---------------|| 1st | Index touches the neck near the nut || 3rd | Thumb at the curve of the neck || 5th | Hand at the neck-body joint || 7th | Hand over the body curve || 8th+ | Thumb leaves the neck, sits on the shoulder of the violin |

Chapter 3 — Advanced bowings

Martelé ("hammered")

A short, percussive stroke with a strong attack and a dead stop. Bow pressure increased before the stroke begins, released through the stroke, stops abruptly.

Used for: marching feel, accented passages, opening of dramatic phrases.

Ricochet ("rebound, thrown")

Multiple notes from a single thrown bow. The bow is dropped from above, bounces 2–4 times naturally, lifted before it stops.

Used in: Mendelssohn Concerto last movement, Paganini Caprices, Sarasate showpieces.

Sautillé ("springing")

Very fast spiccato — so fast that the bow no longer fully lifts off; the wood "springs" rapidly. Played in the middle of the bow with a loose grip.

Used in: Vivaldi Four Seasons (Summer storm), Beethoven Concerto 1st mvt, Mendelssohn Concerto 1st mvt.

> Where I got stuck: I couldn't transition from spiccato to sautillé. The hand wanted to "control" each bounce. Fix: extreme tempo experiment. Start a tremolo (very fast back-and-forth on one note). Gradually add finger changes. The wrist learns the bouncing speed first, then the fingers add pitches.

Chapter 4 — Octave double stops

Two notes an octave apart, played simultaneously. Fingering: 1st finger on lower string + 4th finger on the next string up (e.g., 1 on G + 4 on D for an octave).

Octaves require:- 1st and 4th fingers to be exactly in tune with each other.- 3rd and 4th fingers stretched apart maximally.

Practice

Slow tuner work. Tune 1st finger first; freeze it. Add 4th finger; adjust until the octave rings (no beats). Then bow the double stop.

Practise on every string pair: G+D, D+A, A+E.

> Trick: octaves are the second-hardest interval to tune (after major 7ths). Beats are very audible; an octave that's even slightly off sounds painful. Practise daily for 5 minutes. Octave fluency takes 6 months minimum.

Chapter 7 — Memorisation strategy

By Grade 7, you should perform from memory. Strategy:

1. Analyse the structure first. Break the piece into sections (A-B-A, exposition-development-recap, theme + variations, etc.). Label each section.2. Memorise section by section — not start-to-finish.3. Memorise the hardest section first. Mental energy is highest at the start of practice; spend it on the toughest bars.4. Practise from any starting point. Open the score randomly; you should be able to start there from memory. This builds resilience for performance anxiety.5. Mental practice. Without the violin, mentally walk through the piece — every shift, every bow direction, every fingering. 10 minutes a day. Increases memory reliability dramatically.6. Slow performance practice. Once memorised, play the whole piece at 60% tempo from memory. Catches weak spots.

> Where I got stuck: I memorised by repetition only — fingers learned the piece, but my brain didn't. Under stress (an audition), my fingers blanked. Fix: 10 minutes of mental practice daily. It feels useless at first, but after a month, memory failure rate dropped 80%.

Newer = more features.

C++ vs Python (one paragraph)

Python is interpreted, dynamically typed, garbage-collected, and slow. C++ is compiled, statically typed, manually memory-managed (with smart-pointer helpers), and fast. Python code reads cleanly with little ceremony; C++ code can be more verbose but exposes what's happening at the machine level. Use C++ when you need raw speed, low memory footprint, hardware access, or you're building infrastructure that other languages will call into.

> Trick: don't pick a language; pick a problem. Most real engineers use both — Python for orchestration and analysis, C++ (or Rust) for the hot inner loop.
