JavaScript Deep Dive — 00 · Engines & Runtime
Created2026-01-26|Programming Web
JavaScript is not "interpreted" and not "compiled" — in a modern engine it is both, several times over, and the engine changes its mind while your code runs. A function starts as bytecode, gets promoted to machine code when it turns hot, gets thrown back to bytecode when one of the guesses behind that machine code turns out wrong, and all the while a garbage collector moves its objects around in memory. Almost every "mysterious" performance cliff in a senior engineer's career — the loop that is fast on Monday and five times slower after a harmless refactor, the service whose p99 latency spikes every few seconds — comes from this machinery. This first post of the series opens up V8, the engine behind Chrome, Edge, Node.js and Deno: its compiler tiers, hidden classes, inline caches, deoptimization, elements kinds and the Orinoco garbage collector, then places the engine inside the runtimes that host it. > Series map: 00 Engines & Runtime (this post) → 01 Event Loop & Concurrency → 02 Objects, Prototypes & Metaprogramming → 03 Async Engineering → 04 Modules, Packaging & TypeScript at Scale → 05 Performance, Memory & Production Debugging. Future: see the extensions table in 05. V8, SpiderMonkey and JavaScriptCore are engines.- Host (embedder) — the program that embeds the engine and gives it a world: the event loop, timers, networking, the DOM, the file system. Chrome's Blink, Node.js, Deno, Bun and Cloudflare's are hosts.- Isolate — one independent V8 heap with its own garbage collector. A browser tab's main thread, each Web Worker and each Node worker run in separate isolates. Isolates share no JavaScript objects.- Realm — one set of global objects and built-ins (, , ). The engine asks the host to schedule promise jobs (); the host decides when they run. That is why microtask timing is defined by HTML and Node, not by ECMAScript alone. The split matters in practice because the specification says nothing about , , , or the DOM. When behaviour differs between Chrome and Node, the engine is usually identical (both V8) and the host is the difference. Each tier trades compile time for code quality: | Tier | Kind | Shipped | Input → output | Why it exists ||---|---|---|---|---|| Ignition | Interpreter | V8 5.9 / Chrome 59 (with TurboFan) | Source → bytecode, then executes it | Fast start, small memory, collects type feedback || Sparkplug | Baseline (non-optimising) compiler | Chrome 91 | Bytecode → machine code in one linear pass, no IR | Removes interpreter dispatch cost almost for free || Maglev | Mid-tier optimising compiler | Chrome 117 | Bytecode + feedback → SSA/CFG IR → machine code | Good code quickly: about 10× slower to compile than Sparkplug, about 10× faster than TurboFan (V8 team's figure) || TurboFan | Top-tier optimising compiler | V8 5.9 | Bytecode + feedback → heavily optimised machine code | Peak speed for truly hot code; its JavaScript backend now runs on the CFG-based Turboshaft IR | Parsing: most functions are parsed twice Full parsing is expensive, and most functions in a large bundle never run. V8 therefore pre-parses inner functions: it checks syntax and records which variables they capture, but builds no AST and no bytecode. The full parse and bytecode generation happen on the first call ("lazy compilation"). A function that is called immediately pays twice, so V8 uses heuristics — for example a function expression wrapped in parentheses () is compiled eagerly. Consequences: - Startup cost is dominated by how much code is parsed, not how much exists. Code splitting and lazy help because unparsed code costs nothing.- Compiled bytecode can be cached. Chrome caches it for scripts it sees repeatedly; Node offers a module compile cache (, added in v22.1.0) that persists it to disk between runs, useful for CLIs. The bracketed numbers after each operation are feedback slots. Every property access, call and arithmetic operation records what it saw — which object shapes, whether the operands were small integers or doubles — into the function's feedback vector. Everything the optimising tiers do is built on this record. Code that never ran has no feedback, and the optimisers cannot specialise it. Tiering up and OSR V8 counts how much a function runs (invocations and loop iterations, weighted by bytecode size) and promotes it when budgets run out. The exact thresholds are internal heuristics that change between releases; do not design around numbers. A long-running loop inside a function that is called only once would never tier up by call count, so V8 performs on-stack replacement (OSR): it compiles an optimised version while the loop is running and jumps into it mid-loop. > Watch out: Node's defaults do not always match Chrome's. Chrome has enabled Maglev since M117, but at least one Node 22 release line ships with as the default. Check your own binary with before assuming a tier exists. Speculation is the whole trick An optimising compiler for a dynamic language cannot know that is a small integer. It speculates from feedback: "every seen so far had shape M1, and was always a Smi". It emits a cheap check (a guard) followed by a fast path — a load at a fixed offset, an integer add. If the guard fails at run time, the optimised code cannot continue; it deoptimizes (Chapter 5). Fast JavaScript is JavaScript whose guards rarely fail. Chapter 3 — Hidden classes (maps) Terminology - Map (V8's term; "hidden class" or shape elsewhere) — a descriptor attached to every heap object that records its property names, their order, their attributes and where each value is stored.- Transition — the edge from one map to another when a property is added. Chapter 6 — Numbers and elements kinds Smis and heap numbers V8 represents small integers as Smis — tagged values stored directly in the pointer, with no allocation. With pointer compression (Chrome on 64-bit) a Smi is 31 bits (−2³⁰ to 2³⁰−1); builds without pointer compression, typical for Node, use 32-bit Smis on 64-bit platforms. Anything else — fractions, , , , integers outside the Smi range — is a HeapNumber (a boxed double), unless the optimiser can keep it unboxed in a register or a double field. Chapter 7 — The Orinoco garbage collector Terminology - Generational hypothesis — most objects die young. A GC that collects young objects often and cheaply wins.- Young generation — where new objects are allocated. In V8 it is split into a nursery and an intermediate generation.- Old generation — objects that survived two young collections.- Scavenge (minor GC) — copying collection of the young generation.- Mark-Compact (major GC) — marking live objects in the whole heap, sweeping dead ones, compacting fragmented pages.- Write barrier — a small piece of code the engine runs on every pointer store into the heap, so concurrent or incremental marking does not miss new references, and old-to-young pointers are remembered.- Stop-the-world pause — time the main thread spends in GC instead of running JavaScript. Young generation: the scavenger New objects go into the nursery with bump-pointer allocation (very cheap). When the young space fills, a scavenge copies live objects out: survivors of their first scavenge become intermediate; survivors of a second are promoted to the old generation. The young generation uses a semi-space design, so half of it is always empty to receive the copies. Cost is proportional to the number of live objects, not the garbage — dying young is nearly free. The scavenger runs in parallel on helper threads; the V8 team measured a 20–50% reduction in main-thread young-generation GC time from parallel scavenging. Node exposes the size knob: (MiB). The Node docs note that the young generation is three times the semi-space size, so +1 MiB of semi-space adds 3 MiB of heap. Raising it can cut scavenges for allocation-heavy servers; benchmark before and after. Old generation: concurrent mark-compact - Marking finds everything reachable from the roots (stack, globals, handles). V8 does most of it concurrently on background threads while JavaScript runs, plus incremental steps on the main thread. Write barriers keep it correct while your code mutates the heap.- Sweeping frees dead objects' memory into free lists, concurrently.- Compaction moves objects out of fragmented pages, in parallel, during a pause.- Large objects (above a size threshold) live in a separate large-object space and are never moved.- Idle-time GC: the browser tells V8 when a frame finished early, and V8 uses the idle slice for GC work. Concurrent marking and sweeping reduced pause times in heavy WebGL games by up to 50%, per the V8 team. In Chrome, Blink's C++ DOM objects are managed by Oilpan () and traced together with the JavaScript heap, so a cycle between a DOM node and a JavaScript closure is still collectable. Abstract Algebra — 05 · Field Extensions and Galois Theory
Created2026-01-14|Mathematics Abstract Algebra
Post 04 ended by building new fields: $\mathbb{C} = \mathbb{R}[x]/(x^2+1)$ and $\mathbb{F}4 = \mathbb{F}2[x]/(x^2+x+1)$. This post studies such constructions systematically. A bigger field $E$ containing $F$ is a vector space over $F$, and its dimension, the degree, turns out to be a very strong invariant: a single divisibility argument proves that no ruler-and-compass construction doubles a cube or trisects a 60° angle. Galois theory then attaches to a polynomial a finite group, the permutations of its roots that respect all algebraic relations, and the Fundamental Theorem matches the subfields of the splitting field with the subgroups of that group. Everything from posts 01–04 comes together here: groups, normal subgroups and quotients, group actions, Sylow-type counting, irreducible polynomials and quotient rings. The chapter ends with the reason there is no quintic formula. > Series map: 00 Integers, Relations & Modular Arithmetic → 01 Groups & Subgroups → 02 Cosets, Lagrange & Quotient Groups → 03 Homomorphisms, Group Actions & Sylow → 04 Rings, Ideals & Fields → 05 Field Extensions & Galois Theory (this post). Learning Outcome - Compute the degree of a field extension, and prove and use the tower law.- Find minimal polynomials, and prove that $F(\alpha) \cong F[x]/(m\alpha)$ with degree $\deg m\alpha$.- Show that $\mathbb{Q}(\sqrt2, \sqrt3)$ has degree 4 and is generated by $\sqrt2 + \sqrt3$.- Prove that doubling the cube and trisecting a 60° angle are impossible with ruler and compass.- Build splitting fields, and prove that there is one finite field of each prime-power order, up to isomorphism.- Define separable, normal and Galois extensions and the Galois group.- State the Fundamental Theorem of Galois Theory and draw the subfield/subgroup lattices for $\mathbb{Q}(\sqrt2, \sqrt3)$ and for the splitting field of $x^3 - 2$.- Define solvable groups and outline why the roots of $x^5 - 4x + 2$ cannot be written with radicals. Chapter 1 — Field extensions and degree Terminology - Extension — a pair of fields $F \subseteq E$, written $E/F$ ("$E$ over $F$"). $F$ is the base field.- Degree — $[E : F] = \dimF E$, the dimension of $E$ as a vector space over $F$. The extension is finite if the degree is finite.- Generated extension — for $\alpha \in E$, $F(\alpha)$ is the smallest subfield of $E$ containing $F$ and $\alpha$. Likewise $F(\alpha1, \dots, \alphan)$. An extension $F(\alpha)/F$ is simple and $\alpha$ is a primitive element.- Intermediate field — a field $K$ with $F \subseteq K \subseteq E$. Examples: $[\mathbb{C} : \mathbb{R}] = 2$ with basis $1, i$. $[\mathbb{Q}(\sqrt2) : \mathbb{Q}] = 2$ with basis $1, \sqrt2$, since $\mathbb{Q}(\sqrt2) = \{a + b\sqrt2 : a, b \in \mathbb{Q}\}$ and $\sqrt2 \notin \mathbb{Q}$. $[\mathbb{R} : \mathbb{Q}]$ is infinite (a countable field cannot span the uncountable $\mathbb{R}$ with finitely many vectors). A field with $q$ elements that contains $\mathbb{F}p$ has $q = p^n$ where $n = [E : \mathbb{F}p]$, because an $n$-dimensional vector space over $\mathbb{F}p$ has $p^n$ elements. The tower law Theorem (tower law). If $F \subseteq K \subseteq E$ are fields, then $$[E : F] = [E : K]\,[K : F],$$ in the sense that the left side is finite exactly when both factors are, and then equality holds. Proof (finite case). Let $\alpha1, \dots, \alpham$ be a basis of $K$ over $F$ and $\beta1, \dots, \betan$ a basis of $E$ over $K$. The claim is that the $mn$ products $\alphai\betaj$ form a basis of $E$ over $F$. - Spanning. Any $e \in E$ is $\sumj kj \betaj$ with $kj \in K$, and each $kj = \sumi f{ij}\alphai$ with $f{ij} \in F$. So $e = \sum{i,j} f{ij}\,\alphai\betaj$.- Independence. If $\sum{i,j} f{ij}\alphai\betaj = 0$, regroup as $\sumj \big(\sumi f{ij}\alphai\big)\betaj = 0$. The inner sums are in $K$ and the $\betaj$ are independent over $K$, so each inner sum is $0$. The $\alphai$ are independent over $F$, so every $f{ij} = 0$. ∎ Corollaries. (1) If $K$ is intermediate in a finite extension $E/F$, then $[K : F]$ divides $[E : F]$. (2) If $[E : F]$ is prime, there is no intermediate field other than $F$ and $E$. (3) If $\alpha \in E$, then $[F(\alpha) : F]$ divides $[E : F]$. > Trick: most degree computations are "bound above by a tower, bound below by divisibility". If $[K : F] = 2$ and $[L : F] = 3$ are both inside $E$, then $6 \mid [E : F]$. Chapter 2 — Algebraic elements and minimal polynomials Terminology - Algebraic — $\alpha \in E$ is algebraic over $F$ if $f(\alpha) = 0$ for some nonzero $f \in F[x]$. Otherwise $\alpha$ is transcendental over $F$.- Algebraic extension — every element of $E$ is algebraic over $F$.- Minimal polynomial — the monic polynomial $m\alpha \in F[x]$ of least degree with $m\alpha(\alpha) = 0$. $\sqrt2$, $i$, $\sqrt[3]{2}$ and $e^{2\pi i/5}$ are algebraic over $\mathbb{Q}$. Hermite proved in 1873 that $e$ is transcendental and Lindemann in 1882 that $\pi$ is transcendental; both proofs are analytic and are not needed below. The minimal polynomial Theorem. Let $\alpha$ be algebraic over $F$. Then: 1. $m\alpha$ exists, is unique, and is irreducible over $F$;2. for $f \in F[x]$: $f(\alpha) = 0$ if and only if $m\alpha \mid f$;3. $F(\alpha) \cong F[x]/(m\alpha)$, so $[F(\alpha) : F] = \deg m\alpha$, with basis $1, \alpha, \dots, \alpha^{n-1}$ where $n = \deg m\alpha$. Proof. Evaluation $\mathrm{ev}\alpha : F[x] \to E$, $f \mapsto f(\alpha)$, is a ring homomorphism. Its kernel $I$ is nonzero because $\alpha$ is algebraic, and $F[x]$ is a PID (post 04), so $I = (m)$ for a unique monic $m$; this $m$ has least degree among nonzero elements of $I$, so $m = m\alpha$, and statement 2 is "$f \in I \iff m\alpha \mid f$". The image of $\mathrm{ev}\alpha$ is a subring of the field $E$, hence a domain, so by the First Isomorphism Theorem $F[x]/(m\alpha)$ is a domain: $(m\alpha)$ is prime, so $m\alpha$ is irreducible. Then $(m\alpha)$ is maximal (post 04, Chapter 6), so the image $F[\alpha]$ is a field containing $F$ and $\alpha$; it is therefore $F(\alpha)$. The basis claim is the division algorithm: every class has a unique representative of degree $< n$. ∎ So to find $[F(\alpha) : F]$: find a polynomial with root $\alpha$ and prove it irreducible with the tests of post 04. > Common pitfall: the minimal polynomial depends on the base field. $m{\sqrt2}$ over $\mathbb{Q}$ is $x^2 - 2$; over $\mathbb{R}$ it is $x - \sqrt2$. Arithmetic in $\mathbb{Q}(\sqrt[3]{2})$. Let $a = \sqrt[3]{2}$, with $ma = x^3 - 2$ (Eisenstein at 2), so $[\mathbb{Q}(a) : \mathbb{Q}] = 3$ with basis $1, a, a^2$. To invert $1 + a$, use $(1 + a)(1 - a + a^2) = 1 + a^3 = 3$: $$\frac{1}{1 + \sqrt[3]{2}} = \frac{1 - \sqrt[3]{2} + \sqrt[3]{4}}{3}.$$ Finite implies algebraic. If $[E : F] = n$ and $\alpha \in E$, the $n + 1$ elements $1, \alpha, \dots, \alpha^n$ are linearly dependent over $F$, and a dependence relation is a nonzero polynomial with root $\alpha$. Consequently, if $\alpha$ and $\beta$ are algebraic then $F(\alpha, \beta)$ is finite (tower law), so $\alpha \pm \beta$, $\alpha\beta$ and $\alpha/\beta$ are algebraic too: the algebraic numbers form a field. Worked example: Q(√2, √3) Degree. $[\mathbb{Q}(\sqrt2) : \mathbb{Q}] = 2$. Next, $\sqrt3 \notin \mathbb{Q}(\sqrt2)$: if $(a + b\sqrt2)^2 = 3$ with $a, b \in \mathbb{Q}$, then $a^2 + 2b^2 = 3$ and $2ab = 0$. $b = 0$ gives $a^2 = 3$ and $a = 0$ gives $b^2 = 3/2$, neither possible in $\mathbb{Q}$. So $x^2 - 3$ stays irreducible over $\mathbb{Q}(\sqrt2)$, and by the tower law $$[\mathbb{Q}(\sqrt2, \sqrt3) : \mathbb{Q}] = [\mathbb{Q}(\sqrt2, \sqrt3) : \mathbb{Q}(\sqrt2)]\,[\mathbb{Q}(\sqrt2) : \mathbb{Q}] = 2 \cdot 2 = 4,$$ with basis $1, \sqrt2, \sqrt3, \sqrt6$ (products of the two bases, as in the proof of the tower law). A primitive element. Let $\theta = \sqrt2 + \sqrt3$. Then $\theta^2 = 5 + 2\sqrt6$, so $(\theta^2 - 5)^2 = 24$, that is $$\theta^4 - 10\theta^2 + 1 = 0.$$ Also $\theta^3 = 11\sqrt2 + 9\sqrt3$, which gives $\sqrt2 = (\theta^3 - 9\theta)/2$ and $\sqrt3 = (11\theta - \theta^3)/2$. So $\mathbb{Q}(\theta)$ contains $\sqrt2$ and $\sqrt3$, hence $\mathbb{Q}(\theta) = \mathbb{Q}(\sqrt2, \sqrt3)$ has degree 4. A degree-4 monic polynomial with root $\theta$ must then be the minimal polynomial: $m\theta = x^4 - 10x^2 + 1$, irreducible over $\mathbb{Q}$ (its four roots are $\pm\sqrt2 \pm \sqrt3$). This is an instance of the primitive element theorem: every finite separable extension (Chapter 5; in particular every finite extension of $\mathbb{Q}$) is simple. Chapter 3 — Ruler and compass Start with the points $0$ and $1$ in the plane $\mathbb{C}$. A ruler draws the line through two constructed points; a compass draws a circle with a constructed centre through a constructed point. New points are intersections of lines and circles. A real number is constructible if it is a coordinate of a constructible point. Key observation. If all points so far have coordinates in a field $K$, then: - the intersection of two lines solves a linear system, so it has coordinates in $K$;- an intersection involving a circle solves a quadratic equation over $K$, so it has coordinates in $K$ or in some $K(\sqrt d)$ with $d \in K$, an extension of degree 2. Theorem. If $\alpha$ is constructible, then $[\mathbb{Q}(\alpha) : \mathbb{Q}]$ is a power of 2. Proof. By the observation, $\alpha$ lies in the top field of a tower $\mathbb{Q} = K0 \subset K1 \subset \cdots \subset Kr$ with each $[K{i+1} : Ki] = 2$. By the tower law $[Kr : \mathbb{Q}] = 2^r$, and $[\mathbb{Q}(\alpha) : \mathbb{Q}]$ divides it. ∎ Doubling the cube. A cube of volume 2 needs side $\sqrt[3]{2}$, whose minimal polynomial $x^3 - 2$ has degree 3. Not a power of 2, so impossible. Trisecting 60°. A 60° angle is constructible (equilateral triangle). Trisecting it means constructing $c = \cos 20^\circ$. From $\cos 3\theta = 4\cos^3\theta - 3\cos\theta$ with $\theta = 20^\circ$ and $\cos 60^\circ = \tfrac12$: $$4c^3 - 3c = \tfrac12 \quad\Longleftrightarrow\quad 8c^3 - 6c - 1 = 0.$$ By the rational root test, a rational root would be one of $\pm1, \pm\tfrac12, \pm\tfrac14, \pm\tfrac18$; substituting gives $1, -3, -3, 1, -\tfrac{19}{8}, \tfrac38, -\tfrac{111}{64}, -\tfrac{17}{64}$, never $0$. A cubic without rational roots is irreducible, so $[\mathbb{Q}(c) : \mathbb{Q}] = 3$ and the trisection is impossible. (Some angles, such as 90°, can be trisected; the theorem is that no method works for every angle.) Squaring the circle. A square of area $\pi$ needs side $\sqrt\pi$. If $\sqrt\pi$ were constructible it would be algebraic, so $\pi$ would be algebraic, contradicting Lindemann. > Watch out: "degree a power of 2" is necessary, not sufficient. The exact criterion is that the splitting field of the minimal polynomial has degree a power of 2. The Gauss–Wantzel theorem answers the polygon question: a regular $n$-gon is constructible if and only if $n$ is a power of 2 times a product of distinct Fermat primes $3, 5, 17, 257, 65537$. Chapter 4 — Splitting fields and finite fields Splitting fields A splitting field of a nonconstant $f \in F[x]$ is an extension $E/F$ in which $f$ factors into linear factors, $f = c(x - \alpha1)\cdots(x - \alphan)$, and which is generated by the roots: $E = F(\alpha1, \dots, \alphan)$. Theorem. Every nonconstant $f \in F[x]$ has a splitting field $E$, with $[E : F] \le n!$ where $n = \deg f$. Any two splitting fields of $f$ over $F$ are isomorphic by an isomorphism that fixes $F$. (Existence: take an irreducible factor $p$ of $f$; in $F[x]/(p)$ it has a root (post 04), so $f$ gains a linear factor over an extension of degree $\le n$; repeat on the quotient, whose degree is $n - 1$. Uniqueness is proved by the same induction, extending an isomorphism one root at a time.) Examples: - $x^2 - 2$ over $\mathbb{Q}$: splitting field $\mathbb{Q}(\sqrt2)$, degree 2.- $x^4 - 10x^2 + 1$: roots $\pm\sqrt2 \pm \sqrt3$, splitting field $\mathbb{Q}(\sqrt2, \sqrt3)$, degree 4.- $x^3 - 2$: roots $\alpha$, $\alpha\omega$, $\alpha\omega^2$ with $\alpha = \sqrt[3]{2}$ and $\omega = e^{2\pi i/3}$, a root of $x^2 + x + 1$. The splitting field is $E = \mathbb{Q}(\alpha, \omega)$ (it contains $\omega = \alpha\omega/\alpha$). $[\mathbb{Q}(\alpha) : \mathbb{Q}] = 3$, and $\omega \notin \mathbb{Q}(\alpha) \subset \mathbb{R}$, so $[E : \mathbb{Q}(\alpha)] = 2$. Hence $[E : \mathbb{Q}] = 6 = 3!$, the maximum. Finite fields Let $E$ be a finite field. Its characteristic is a prime $p$ (post 04), so it contains $\mathbb{F}p$ and has $p^n$ elements, $n = [E : \mathbb{F}p]$. Lemma (freshman's dream). In a commutative ring of characteristic $p$, $(a + b)^p = a^p + b^p$. Proof. Expand with the binomial theorem. For $0 < k < p$, $\binom{p}{k} = \frac{p!}{k!(p-k)!}$ is divisible by $p$: $p$ divides the numerator but not the denominator. So all middle terms vanish. ∎ Hence the Frobenius map $\mathrm{Fr}(a) = a^p$ is a ring homomorphism. On a field it is injective (post 04: homomorphisms out of fields are injective), so on a finite field it is an automorphism, and it fixes exactly the elements of $\mathbb{F}p$ (the roots of $x^p - x$; there are at most $p$ of them, and all of $\mathbb{F}p$ qualifies by Fermat's little theorem from post 00). Theorem (existence and uniqueness of finite fields). For every prime $p$ and $n \ge 1$ there is a field with $q = p^n$ elements, and any two such fields are isomorphic. It is written $\mathbb{F}q$. Proof. Existence. Let $E$ be a splitting field of $g = x^q - x$ over $\mathbb{F}p$, and $S$ the set of roots of $g$ in $E$. The derivative $g' = qx^{q-1} - 1 = -1$ has no common root with $g$, so the roots are distinct and $|S| = q$. $S$ is a subfield: if $a^q = a$ and $b^q = b$, then $(a + b)^q = a^q + b^q = a + b$ (apply the lemma $n$ times), $(ab)^q = ab$, and $(a^{-1})^q = a^{-1}$. A subfield containing all roots is the whole splitting field, so $E = S$ has $q$ elements. Uniqueness. In any field $K$ with $q$ elements, the multiplicative group has order $q - 1$, so $a^{q-1} = 1$ for $a \ne 0$ by Lagrange, and $a^q = a$ for all $a$. So $K$ consists of the $q$ roots of $x^q - x$, and is a splitting field of $x^q - x$ over $\mathbb{F}p$. Splitting fields are unique up to isomorphism. ∎ Two further facts, stated without proof: the multiplicative group $\mathbb{F}q^\times$ is cyclic (post 04's $\mathbb{F}8$ table showed a generator), and $\mathbb{F}{p^d}$ sits inside $\mathbb{F}{p^n}$ exactly when $d \mid n$. Worked example. Over $\mathbb{F}2$: $$\begin{aligned}x^4 - x &= x\,(x + 1)\,(x^2 + x + 1), \\x^8 - x &= x\,(x + 1)\,(x^3 + x + 1)\,(x^3 + x^2 + 1).\end{aligned}$$ The first line lists the minimal polynomials of the 4 elements of $\mathbb{F}4$; the second those of the 8 elements of $\mathbb{F}8$. The two cubics are the two irreducible cubics over $\mathbb{F}2$, each with three roots in $\mathbb{F}8$. No quadratic appears in the second line, matching $2 \nmid 3$: $\mathbb{F}4 \not\subseteq \mathbb{F}8$. Chapter 5 — Galois extensions and the Galois group Terminology - $F$-automorphism of $E$ — a field automorphism $\sigma : E \to E$ with $\sigma(a) = a$ for every $a \in F$. They form a group $\operatorname{Aut}(E/F)$.- Fixed field — for a subgroup $H \le \operatorname{Aut}(E)$, $E^H = \{ e \in E : \sigma(e) = e \text{ for all } \sigma \in H \}$.- Separable polynomial — one with no repeated root in its splitting field. An algebraic extension is separable if every minimal polynomial is separable.- Normal extension — an algebraic $E/F$ such that every irreducible polynomial in $F[x]$ with one root in $E$ splits completely in $E$.- Galois extension — a finite extension that is normal and separable. Its Galois group is $\operatorname{Gal}(E/F) = \operatorname{Aut}(E/F)$.- Galois group of a polynomial — $\operatorname{Gal}(E/F)$ for $E$ a splitting field of the (separable) polynomial. Separability is automatic in the cases you meet most. Over a field of characteristic 0, and over any finite field, every irreducible polynomial is separable. (An irreducible $f$ has a repeated root only if $\gcd(f, f') \ne 1$, which forces $f' = 0$; in characteristic 0 that is impossible for nonconstant $f$.) The standard inseparable example is $x^p - t$ over the field $\mathbb{F}p(t)$ of rational functions: it is irreducible (Eisenstein at the prime $t$), but over its splitting field it equals $(x - t^{1/p})^p$. Automorphisms permute roots Lemma. If $f \in F[x]$, $\alpha \in E$ is a root of $f$, and $\sigma \in \operatorname{Aut}(E/F)$, then $\sigma(\alpha)$ is a root of $f$. Proof. If $f = \sum ck x^k$ with $ck \in F$, then $f(\sigma(\alpha)) = \sum ck \sigma(\alpha)^k = \sigma\big(\sum ck\alpha^k\big) = \sigma(0) = 0$, since $\sigma$ fixes each $ck$. ∎ So if $E = F(\alpha1, \dots, \alphan)$ is a splitting field of $f$, an $F$-automorphism is determined by how it permutes $\alpha1, \dots, \alphan$, and $\operatorname{Aut}(E/F)$ is (isomorphic to) a subgroup of $Sn$, an action on the roots in the sense of post 03. Theorem (characterisations of Galois extensions). For a finite extension $E/F$ the following are equivalent: 1. $E/F$ is Galois (normal and separable);2. $E$ is the splitting field over $F$ of a separable polynomial;3. $\lvert\operatorname{Aut}(E/F)\rvert = [E : F]$;4. the fixed field of $\operatorname{Aut}(E/F)$ is exactly $F$. In general $\lvert\operatorname{Aut}(E/F)\rvert \le [E : F]$ and equality is what "Galois" means in practice. Examples. - $\operatorname{Gal}(\mathbb{C}/\mathbb{R}) = \{\mathrm{id}, \text{complex conjugation}\} \cong \mathbb{Z}/2\mathbb{Z}$.- $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ is not Galois. An automorphism must send $\sqrt[3]{2}$ to a root of $x^3 - 2$ inside $\mathbb{Q}(\sqrt[3]{2}) \subset \mathbb{R}$, and the only real root is $\sqrt[3]{2}$ itself. So $\operatorname{Aut}$ is trivial, of order $1 < 3$. It fails normality: $x^3 - 2$ has one root in the field but does not split there.- $\operatorname{Gal}(\mathbb{F}{p^n}/\mathbb{F}p)$ is cyclic of order $n$, generated by Frobenius. ($\mathrm{Fr}^k$ fixes exactly the roots of $x^{p^k} - x$, so $\mathrm{Fr}$ has order exactly $n$; and the group has order $[\mathbb{F}{p^n} : \mathbb{F}p] = n$ because $\mathbb{F}{p^n}$ is the splitting field of the separable $x^{p^n} - x$.) Chapter 6 — The Fundamental Theorem of Galois Theory Theorem (Fundamental Theorem of Galois Theory). Let $E/F$ be a finite Galois extension with group $G = \operatorname{Gal}(E/F)$. Then the maps $$H \longmapsto E^H \qquad\text{and}\qquad K \longmapsto \operatorname{Gal}(E/K)$$ are mutually inverse bijections between subgroups $H \le G$ and intermediate fields $F \subseteq K \subseteq E$, and: 1. they reverse inclusion: $H1 \le H2$ if and only if $E^{H1} \supseteq E^{H2}$;2. degrees match indices: $[E : E^H] = |H|$ and $[E^H : F] = [G : H]$;3. $K/F$ is Galois if and only if $\operatorname{Gal}(E/K)$ is a normal subgroup of $G$, and then $\operatorname{Gal}(K/F) \cong G / \operatorname{Gal}(E/K)$. So the lattice of intermediate fields is the lattice of subgroups turned upside down: the big field $E$ matches the trivial group, the base $F$ matches all of $G$. Part 3 is where normal subgroups and quotient groups (post 02) acquire their original meaning. Worked example 1: Q(√2, √3) $E = \mathbb{Q}(\sqrt2, \sqrt3)$ is the splitting field of the separable $(x^2 - 2)(x^2 - 3)$, so it is Galois of degree 4 and $G$ has 4 elements. Each automorphism sends $\sqrt2 \mapsto \pm\sqrt2$ and $\sqrt3 \mapsto \pm\sqrt3$, and all four sign choices occur. Let $$\sigma : \sqrt2 \mapsto -\sqrt2,\ \sqrt3 \mapsto \sqrt3, \qquad \tau : \sqrt2 \mapsto \sqrt2,\ \sqrt3 \mapsto -\sqrt3.$$ Each has order 2 and they commute, so $G = \{\mathrm{id}, \sigma, \tau, \sigma\tau\} \cong \mathbb{Z}/2 \times \mathbb{Z}/2$. The subgroups and their fixed fields: | Subgroup | Order | Fixed field | Degree over $\mathbb{Q}$ ||---|---|---|---|| $\{\mathrm{id}\}$ | 1 | $\mathbb{Q}(\sqrt2, \sqrt3)$ | 4 || $\langle\sigma\rangle$ | 2 | $\mathbb{Q}(\sqrt3)$ | 2 || $\langle\tau\rangle$ | 2 | $\mathbb{Q}(\sqrt2)$ | 2 || $\langle\sigma\tau\rangle$ | 2 | $\mathbb{Q}(\sqrt6)$ | 2 || $G$ | 4 | $\mathbb{Q}$ | 1 | ($\sigma\tau(\sqrt6) = (-\sqrt2)(-\sqrt3) = \sqrt6$.) By the theorem these are all the intermediate fields: exactly three quadratic subfields, which is not obvious without Galois theory. $G$ is abelian, so every subgroup is normal and every intermediate field is Galois over $\mathbb{Q}$. Worked example 2: the splitting field of x³ − 2 $E = \mathbb{Q}(\alpha, \omega)$ with $\alpha = \sqrt[3]{2}$, of degree 6 (Chapter 4). It is Galois, so $|G| = 6$, and $G$ acts on the three roots $\alpha, \alpha\omega, \alpha\omega^2$, so $G$ is a subgroup of $S3$ of order 6: $G \cong S3$. Concretely an automorphism is fixed by $\alpha \mapsto \alpha\omega^a$ ($a \in \{0, 1, 2\}$) and $\omega \mapsto \omega$ or $\omega^2$. Let $$\sigma : \alpha \mapsto \alpha\omega,\ \omega \mapsto \omega \quad(\text{order } 3), \qquad \tau : \alpha \mapsto \alpha,\ \omega \mapsto \omega^2 \quad(\text{complex conjugation, order } 2).$$ Composing right to left (apply $\tau$ first in $\sigma\tau$): $\sigma\tau$ sends $\alpha \mapsto \alpha\omega$ and $\omega \mapsto \omega^2$, so $\sigma\tau(\alpha\omega^2) = \alpha\omega \cdot \omega^4 = \alpha\omega^2$. Similarly $\sigma^2\tau$ fixes $\alpha\omega$. The six subgroups of $S3$ and their fixed fields: | Subgroup | Order | Normal? | Fixed field | Degree over $\mathbb{Q}$ ||---|---|---|---|---|| $\{\mathrm{id}\}$ | 1 | yes | $\mathbb{Q}(\alpha, \omega)$ | 6 || $\langle\tau\rangle$ | 2 | no | $\mathbb{Q}(\alpha)$ | 3 || $\langle\sigma\tau\rangle$ | 2 | no | $\mathbb{Q}(\alpha\omega^2)$ | 3 || $\langle\sigma^2\tau\rangle$ | 2 | no | $\mathbb{Q}(\alpha\omega)$ | 3 || $\langle\sigma\rangle = A3$ | 3 | yes | $\mathbb{Q}(\omega)$ | 2 || $S3$ | 6 | yes | $\mathbb{Q}$ | 1 | Each order-2 subgroup fixes one real or complex cube root, so its fixed field contains that root; the degree count $[G : H] = 3 = [\mathbb{Q}(\alpha\omega^k) : \mathbb{Q}]$ makes it equal to $\mathbb{Q}(\alpha\omega^k)$. $\sigma$ fixes $\omega$, and $[G : \langle\sigma\rangle] = 2 = [\mathbb{Q}(\omega) : \mathbb{Q}]$. Part 3 of the theorem, checked on this example: $A3 = \langle\sigma\rangle$ is normal, and $\mathbb{Q}(\omega)$ is Galois over $\mathbb{Q}$ (it is the splitting field of $x^2 + x + 1$), with $\operatorname{Gal}(\mathbb{Q}(\omega)/\mathbb{Q}) \cong S3/A3 \cong \mathbb{Z}/2$. The three subgroups of order 2 are not normal (they are conjugate, like the three Sylow 2-subgroups of $S3$ in post 03), and correspondingly $\mathbb{Q}(\sqrt[3]{2})$ and its two conjugate fields are not Galois over $\mathbb{Q}$. > Common pitfall: the correspondence reverses order. A bigger subgroup fixes more conditions and so has a smaller fixed field. Draw the two lattices with $E$ at the top and $\{\mathrm{id}\}$ at the top. Chapter 7 — Solvable groups and the quintic Solvable groups A group $G$ is solvable if there is a chain of subgroups $$\{e\} = G0 \trianglelefteq G1 \trianglelefteq \cdots \trianglelefteq Gk = G$$ with each $Gi$ normal in $G{i+1}$ and each quotient $G{i+1}/Gi$ abelian. - Abelian groups are solvable ($k = 1$).- $S3$: $\{e\} \trianglelefteq A3 \trianglelefteq S3$ with quotients $\mathbb{Z}/3$ and $\mathbb{Z}/2$.- $S4$: $\{e\} \trianglelefteq V4 \trianglelefteq A4 \trianglelefteq S4$ with quotients $\mathbb{Z}/2 \times \mathbb{Z}/2$, $\mathbb{Z}/3$, $\mathbb{Z}/2$. So every subgroup of $S4$ is solvable too (subgroups and quotients of solvable groups are solvable).- $S5$ is not solvable. Its only normal subgroups are $\{e\}$, $A5$, $S5$, and $A5$ is simple and non-abelian (post 02). A chain would have to pass through $A5$, and the step below $A5$ would need a normal subgroup of $A5$ with abelian quotient; the only candidates are $A5$ itself (quotient trivial, no progress) and $\{e\}$ (quotient $A5$, not abelian). Equivalently, the commutator subgroup of $A5$ is $A5$, so the derived series $S5 \supset A5 \supset A5 \supset \cdots$ never reaches $\{e\}$. Radicals A polynomial $f \in \mathbb{Q}[x]$ is solvable by radicals if its roots can be written starting from rational numbers using $+, -, \times, \div$ and $k$-th roots. The quadratic formula shows this for degree 2; Cardano's and Ferrari's formulas do it for degrees 3 and 4. Theorem (Galois, characteristic 0). $f$ is solvable by radicals if and only if its Galois group is solvable. (Idea of "only if": adjoining a $k$-th root to a field that already contains the $k$-th roots of unity gives a Galois extension with cyclic group; adjoining roots of unity gives an abelian group. A tower of such steps gives, through part 3 of the Fundamental Theorem, a chain of normal subgroups with abelian quotients.) Since $S4$ is solvable and the Galois group of a degree-$n$ polynomial embeds in $Sn$, every polynomial of degree $\le 4$ is solvable by radicals. The Abel–Ruffini theorem says the general quintic is not: the generic polynomial $x^5 + a4x^4 + \cdots + a0$ with independent indeterminate coefficients has Galois group $S5$ over $\mathbb{Q}(a0, \dots, a4)$, which is not solvable, so there is no formula in radicals valid for all quintics. Galois theory gives more: specific quintics with rational coefficients have unsolvable roots. A concrete unsolvable quintic Lemma. Let $p$ be prime and $f \in \mathbb{Q}[x]$ irreducible of degree $p$ with exactly two non-real roots. Then $\operatorname{Gal}(f) \cong Sp$. Proof. View $G = \operatorname{Gal}(f)$ as a subgroup of $Sp$ acting on the $p$ roots. For a root $\alpha$, $[\mathbb{Q}(\alpha) : \mathbb{Q}] = p$ divides $[E : \mathbb{Q}] = |G|$, so by Cauchy's theorem (post 03) $G$ has an element of order $p$; in $Sp$ the elements of order $p$ are the $p$-cycles. Complex conjugation restricts to an element of $G$ that swaps the two non-real roots and fixes the $p - 2$ real ones: a transposition. For prime $p$, a $p$-cycle and a transposition generate all of $Sp$. ∎ Theorem. $f(x) = x^5 - 4x + 2$ is not solvable by radicals over $\mathbb{Q}$. Proof. Irreducible: Eisenstein at $p = 2$ ($2 \mid -4$, $2 \mid 2$, $4 \nmid 2$, leading coefficient 1). Exactly three real roots: $f'(x) = 5x^4 - 4$ vanishes only at $x = \pm c$ with $c = (4/5)^{1/4} \approx 0.9457$. So $f$ increases, then decreases on $[-c, c]$, then increases. The local maximum $f(-c) \approx 5.03 > 0$ and the local minimum $f(c) \approx -1.03 < 0$, while $f \to -\infty$ as $x \to -\infty$ and $f \to +\infty$ as $x \to +\infty$. So $f$ crosses zero once on each of the three monotone pieces: three real roots, approximately $-1.5185$, $0.5085$ and $1.2436$, and the other two roots are a complex-conjugate pair. By the lemma with $p = 5$, $\operatorname{Gal}(f) \cong S5$, which is not solvable. By Galois's theorem, $f$ is not solvable by radicals. ∎ > Watch out: "not solvable by radicals" does not mean the roots are hard to compute. Numerically they are easy (the values above). It means there is no finite expression in $+, -, \times, \div, \sqrt[k]{\ }$ for them. Practice Exercises 1. Chapter 2 — Forcing a rollout when configuration changes Because -injected values do not hot-reload, and because most applications cannot reload files anyway, the honest default is: treat a configuration change as a deployment. Chapter 3 — Storage Terminology - Volume — a directory available to the containers in a Pod, with a lifetime tied to the Pod. is scratch space that vanishes with the Pod; , , and are read-only data sources.- PersistentVolume (PV) — a cluster-scoped object representing a real piece of storage (an EBS volume, a Ceph RBD image, an NFS export).- PersistentVolumeClaim (PVC) — a namespaced request for storage: size, access mode, class. Pods reference PVCs, never PVs.- StorageClass — a named recipe describing how to provision a PV on demand: which provisioner, which parameters, which reclaim and binding policy.- CSI (Container Storage Interface) — the standard gRPC contract between Kubernetes and a storage vendor's driver. The indirection exists so that a workload author can ask for "20 GiB, fast, exclusive" without knowing whether the cluster runs on AWS, on-prem Ceph, or a laptop. It usually is not. Block storage — EBS, GCE PD, Azure Disk, most on-prem SANs — is RWO only, because a block device cannot safely be mounted read-write on two machines at once. RWX requires a file protocol: NFS, EFS, Azure Files, CephFS, Filestore. Every one of those is "keep reality matching a description", which is exactly the loop Kubernetes implements once and reuses for everything. When you do not need Kubernetes This deserves to be said plainly, because the cost of Kubernetes is real: a control plane to run or pay for, a YAML surface area to learn, an upgrade treadmill roughly every four months, and an on-call rotation that now has to understand a distributed system underneath the application. Do not reach for Kubernetes when: - You run one or two services on one or two machines and a few minutes of downtime is acceptable. Compose plus a systemd unit and a restart policy is genuinely simpler and genuinely reliable.- Your workload is bursty and stateless — a managed serverless or PaaS runtime (Cloud Run, Fargate, App Runner, Fly, Render) removes the entire operational tier.- You have no platform owner. Kubernetes without someone responsible for it degrades into an unpatched cluster running a version nobody dares upgrade.- The team is three engineers shipping a product. The orchestration you save is smaller than the orchestration you acquire. Reach for Kubernetes when you have many services, more than one team deploying, an existing cluster to piggyback on, an on-prem or sovereign requirement, or a genuine need for the ecosystem (operators, service mesh, policy engines) built on its API. > Watch out: "we might need to scale later" is not a reason to adopt Kubernetes today. Migrating a containerised app onto Kubernetes later is a bounded, well-trodden project. Running a cluster you do not need for two years is not. Chapter 5 — Pods, ReplicaSets and Deployments Why the Pod, not the container A Pod is one or more containers that are scheduled together, share a network namespace and an IP address, can share volumes, and live and die as a unit. It is the smallest thing Kubernetes schedules. The reason for the extra layer is that some containers are genuinely useless alone. A log shipper that tails must be on the same filesystem as the app. A proxy that terminates mTLS for the app must be on the same network stack as the app. Making the group the schedulable unit means those helpers can be separate images with separate lifecycles and still be guaranteed co-location. What is shared - Network namespace — every container in the Pod sees the same interfaces and the same IP. They reach each other over , and they must not bind the same port. Init containers Init containers run to completion, in order, before any app container starts. If one fails, the kubelet restarts it (subject to the Pod restart policy) and the app containers never start. Use them for schema migrations, waiting on a dependency, fetching config into a shared volume, or setting kernel parameters in a privileged container so the app container needs no privileges. Chapter 5 — Security groups (your everyday firewall) A security group is stateful: if a request matches an outbound rule, the reply is automatically allowed (and vice versa). You only configure one direction, not both. Default behaviour: no inbound, all outbound. As IPs change (autoscaling, recreation), the SG reference stays correct. Chapter 6 — NACLs (the backup layer) A Network ACL is stateless and applied per subnet. Default rules allow all inbound + outbound. Custom NACLs default to deny. NACLs are evaluated in order (rule numbers); the first match wins. In practice most teams don't touch NACLs — security groups do all the real work. Reserve NACLs for blanket per-subnet rules (e.g., "isolated subnets reject any outbound traffic at all") or defence-in-depth against compromised SG state. AWS is the largest public cloud provider, offering over 200 services from raw compute and storage to managed databases, ML training, IoT, and satellite ground stations. For a beginner, that menu is overwhelming. This first post grounds the rest of the series in the core mental model: what the cloud actually is, how AWS organises its physical world (regions and AZs), how you authenticate (IAM), and how you avoid an unwanted bill in week one. The remaining posts go service by service. > Series map: 00 Fundamentals (this post) → 01 EC2 & VPC → 02 Load Balancers & Auto Scaling → 03 Lambda & Serverless → 04 Step Functions → 05 Terraform IaC → (future: S3 deep dive · RDS · DynamoDB · ECS/EKS · CloudWatch · CI/CD · cost optimisation · security best practices). Chapter 1 — What the cloud is Terminology - Cloud computing — renting compute, storage, network, and services from a provider on-demand, billed by usage rather than capital purchase.- Region — a geographic area (e.g., in Northern Virginia, in Hong Kong). Each region is fully independent.- Availability Zone (AZ) — one or more isolated data centres inside a region, connected by low-latency links. Each region has ≥ 3 AZs.- Edge location — smaller PoPs (point of presence) used by CloudFront (CDN) and Route 53 (DNS). Hundreds worldwide.- Service — a single AWS product. EC2, S3, Lambda are services.- API — every AWS service is driven by an HTTPS API. Console, CLI, SDKs, and IaC tools all call the same APIs underneath. Service-model layers | Layer | What the provider runs | What you run | Example AWS ||-------|------------------------|--------------|-------------|| IaaS (Infrastructure) | hardware, virtualisation, network | OS + everything above | EC2, EBS, VPC || PaaS (Platform) | OS + runtime | your app code | Elastic Beanstalk, App Runner || FaaS (Functions) | runtime + scheduling | a single function | Lambda || SaaS (Software) | everything | only data + config | WorkMail, Connect | Trick: when picking a service, ask "how much do I want to manage?". The deeper you go (IaaS → SaaS), the less control and the less ops work. There is no universal best — pick the layer that matches your team's appetite.
