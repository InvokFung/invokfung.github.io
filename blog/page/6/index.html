React Deep Dive — 00 · Rendering Model
Created2026-08-11|Programming Web
Most React bugs that survive code review are not syntax mistakes. They are wrong beliefs about the rendering model: "props changed, so the child re-renders", "setting state updates the variable", "this effect runs once", "the key is only for the warning". Each belief works in the demo and fails in production — as lost input state, a stale value, a double request, or a list that shows the wrong row after a sort. This series is for engineers who already ship React and want the model that sits under it. Post 00 builds that model from the ground: what an element, a component and an instance really are; the render and commit phases; the Fiber tree and its work loop; the reconciliation heuristics; keys and identity; batching; StrictMode; and refs. Examples target React 19.2, with notes where React 18 behaves differently. > Series map: 00 Rendering Model (this post) → 01 Hooks & State Architecture → 02 Concurrent React & React 19 → 03 Performance, Testing & Architecture at Scale. Future topics: see the "Planned future extensions" table in 03. Learning Outcome - Tell apart an element, a component and a component instance, and say where state actually lives.- Describe the three steps of an update — trigger, render, commit — and what is allowed in each.- Explain the Fiber data structure, the two trees ( and ), and why rendering can be paused.- Predict when React keeps state and when it throws it away, from the element type and position alone.- Use keys on purpose: to keep identity across reorders, and to reset a subtree.- List the exact reasons a component renders, and the bailouts that stop a render.- Explain automatic batching (React 18+) and the snapshot behaviour of state.- Read StrictMode's double calls as a test, not a bug, and know what React 19 changed.- Use refs for values that must not trigger a render, including ref cleanup functions and as a prop. Where state lives State does not live "in the function". A function component is called again on every render, and its local variables are new each time. The state lives on the fiber that React created when it first mounted that element at that position in the tree. reads from and writes to that fiber. It keeps the right model in mind: React owns the call, the timing, and how many times it happens. Chapter 2 — Trigger, render, commit Every screen update goes through the same three steps. 1. Trigger. Something schedules an update: the initial , or a / call, or a change in an external store read with .2. Render. React calls the components that may have changed and builds the next tree of elements. It compares that tree with the previous one (reconciliation) and records which host nodes need changes.3. Commit. React applies the recorded changes to the DOM in one go, attaches refs, and runs effects. Render phase: pure and interruptible In the render phase React only calculates. It calls your components and compares results. Because of concurrent rendering (Post 02), the render phase can be paused to let the browser handle input, restarted when a more urgent update arrives, or thrown away if the result is no longer needed. That is why components must be pure during render: same props, state and context in, same elements out, and no side effects. An call, a render counter in a module variable, a write to a ref — any of these can run twice, or run for a render that never commits. Commit phase: synchronous and never partial The commit phase is not interruptible. Once React starts committing, the whole tree is applied in one synchronous pass, so the user never sees half an update. Inside the commit, the order is: | Step | What happens ||---|---|| Before mutation | for classes || Mutation | DOM nodes inserted, updated, removed; old ref detached; layout-effect cleanups of changed components || Layout | refs attached; setups; / || (browser paints) | || Passive | cleanups then setups | runs after the DOM is changed but before the browser paints, so it can measure layout and set state without a visible flicker. normally runs after paint. The React docs add one detail: when the update came from a discrete interaction such as a click, React may run the effects before paint. Do not depend on either timing for correctness; use when you need "before paint". > Watch out: "render" in React does not mean "paint to the screen". A component can render many times with zero DOM changes, and the DOM only changes in the commit. Profilers (Post 03) show render time and commit time separately for this reason. Real Analysis — 02 · Topology of the Real Line and Continuity
Created2026-08-10|Mathematics Real Analysis
Calculus states that a continuous function on a closed interval has a maximum and takes every value in between. Both facts can fail on an open interval or on the rationals, and the reason is not the function but the set it lives on. This post first studies subsets of $\mathbb{R}$ — open, closed and compact sets — and then functions: the $\varepsilon$–$\delta$ definition of a limit and of continuity, with fully worked $\delta$'s, the Extreme Value Theorem, the Intermediate Value Theorem, and uniform continuity. It builds directly on the Axiom of Completeness (Real Analysis 00) and on Bolzano–Weierstrass and sequences (Real Analysis 01). > Series map: 00 The Real Numbers & Completeness → 01 Sequences & Series → 02 Topology of ℝ & Continuity (this post) → 03 Differentiation & Taylor's Theorem → 04 The Riemann Integral → 05 Uniform Convergence & Power Series. Learning Outcome - Define open sets, limit points, closed sets and closure, and decide which of these a given set is.- Define compactness by sequences and by open covers, and prove one direction of the Heine–Borel Theorem.- State the $\varepsilon$–$\delta$ definition of a functional limit and its sequential criterion, and use the criterion to prove that a limit does not exist.- Prove continuity from the definition, with an explicit $\delta$ for $f(x) = x^2$ at a point, and check it numerically.- Prove that continuous images of compact sets are compact, and deduce the Extreme Value Theorem.- Prove the Intermediate Value Theorem using the supremum.- Define uniform continuity, show that $1/x$ and $x^2$ fail it on suitable domains, and prove that continuous functions on compact sets are uniformly continuous.- Describe the discontinuity sets of the Dirichlet and Thomae functions. Chapter 1 — Open and closed sets Terminology - $\varepsilon$-neighbourhood — $V\varepsilon(a) = (a - \varepsilon, a + \varepsilon)$.- Open set — $O \subseteq \mathbb{R}$ is open if for every $a \in O$ there is $\varepsilon > 0$ with $V\varepsilon(a) \subseteq O$. Every point has some room around it inside the set.- Limit point of $A$ — a point $x$ (in $A$ or not) such that every $V\varepsilon(x)$ contains a point of $A$ other than $x$.- Isolated point of $A$ — a point of $A$ that is not a limit point of $A$.- Closed set — a set that contains all of its limit points.- Closure — $\overline{A} = A \cup L$, where $L$ is the set of limit points of $A$.- Complement — $A^c = \mathbb{R} \setminus A$. Examples of open sets - $\mathbb{R}$ and $\emptyset$ are open (the second vacuously).- Every open interval $(a, b)$ is open: for $x \in (a,b)$ take $\varepsilon = \min(x - a,\ b - x)$; then $V\varepsilon(x) \subseteq (a,b)$.- $[0, 1)$ is not open: no neighbourhood of $0$ fits inside it. Theorem. (i) Any union of open sets is open. (ii) A finite intersection of open sets is open. Proof. (i) A point of the union lies in some $O\lambda$, and a neighbourhood inside $O\lambda$ is inside the union. (ii) If $a \in O1 \cap \cdots \cap ON$, choose $\varepsiloni$ with $V{\varepsiloni}(a) \subseteq Oi$ and take $\varepsilon = \mini \varepsiloni > 0$. $\blacksquare$ The word "finite" in (ii) matters: $\bigcap{n=1}^\infty \left(-\frac1n, \frac1n\right) = \{0\}$, which is not open. With infinitely many $\varepsiloni$ the minimum can be $0$. Limit points and closed sets Theorem. $x$ is a limit point of $A$ if and only if $x = \lim an$ for some sequence $(an)$ in $A$ with $an \ne x$ for all $n$. Proof. ($\Rightarrow$) For each $n$ pick $an \in V{1/n}(x) \cap A$ with $an \ne x$; then $\lvert an - x \rvert < 1/n \to 0$. ($\Leftarrow$) Given $\varepsilon$, the terms $an$ with $n$ large lie in $V\varepsilon(x)$, are in $A$, and differ from $x$. $\blacksquare$ So a set is closed exactly when it contains the limit of every convergent sequence of its points (constant sequences included, for points of $A$ itself). | Set | Limit points | Open? | Closed? ||-----|--------------|-------|---------|| $[a, b]$ | $[a, b]$ | no | yes || $(a, b)$ | $[a, b]$ | yes | no || $\{1/n : n \in \mathbb{N}\}$ | $\{0\}$ | no | no ($0$ missing) || $\{0\} \cup \{1/n : n \in \mathbb{N}\}$ | $\{0\}$ | no | yes || $\mathbb{Z}$ | none | no | yes (vacuously) || $\mathbb{Q}$ | $\mathbb{R}$ (density) | no | no || $\mathbb{R}$, $\emptyset$ | $\mathbb{R}$, none | yes | yes | Theorem. A set is open if and only if its complement is closed. Consequently, finite unions and arbitrary intersections of closed sets are closed (De Morgan's laws). Proof of one direction. Let $O$ be open and let $x$ be a limit point of $O^c$. If $x \in O$, some $V\varepsilon(x) \subseteq O$ contains no point of $O^c$, contradicting that $x$ is a limit point of $O^c$. So $x \in O^c$, and $O^c$ is closed. $\blacksquare$ The closure $\overline{A}$ is the smallest closed set containing $A$; for example $\overline{\mathbb{Q}} = \mathbb{R}$ and $\overline{(a,b)} = [a,b]$. > Watch out: "closed" is not the opposite of "open". A set can be both ($\mathbb{R}$, $\emptyset$ — the only two such subsets of $\mathbb{R}$) or neither ($[0,1)$, $\mathbb{Q}$). Chapter 2 — Compact and connected sets Terminology - Compact (sequential definition) — $K$ is compact if every sequence in $K$ has a subsequence that converges to a limit in $K$.- Open cover of $A$ — a collection of open sets $\{O\lambda\}$ whose union contains $A$. A finite subcover is a finite subcollection that still covers $A$.- Compact (cover definition) — every open cover of $K$ has a finite subcover.- Bounded set — $\lvert x \rvert \le M$ for all $x$ in the set, for some $M$. Heine–Borel Theorem (Heine–Borel). For $K \subseteq \mathbb{R}$ the following are equivalent:(i) $K$ is compact (sequential definition);(ii) $K$ is closed and bounded;(iii) every open cover of $K$ has a finite subcover. Proof of (ii) ⇒ (i). Let $(xn)$ be a sequence in $K$. It is bounded because $K$ is, so by Bolzano–Weierstrass (Real Analysis 01) it has a convergent subsequence $x{nk} \to x$. Either $x$ equals infinitely many of the $x{nk}$, so $x \in K$, or it is a limit point of $K$, and then $x \in K$ because $K$ is closed. $\blacksquare$ Proof of (i) ⇒ (ii). If $K$ were unbounded, choose $xn \in K$ with $\lvert xn \rvert > n$; no subsequence is bounded, so none converges. If $K$ were not closed, some limit point $x \notin K$ is the limit of a sequence in $K$; every subsequence also tends to $x \notin K$. $\blacksquare$ The equivalence with (iii) takes more work; see Abbott Section 3.3 and Rudin Theorems 2.40–2.41. Nested compact sets. If $K1 \supseteq K2 \supseteq K3 \supseteq \cdots$ are nonempty compact sets, then $\bigcapn Kn \ne \emptyset$. (Pick $xn \in Kn$. The sequence lies in $K1$, so a subsequence converges to some $x \in K1$. For each fixed $m$, the terms with $nk \ge m$ lie in the closed set $Km$, so $x \in Km$.) This generalizes the Nested Interval Property of Real Analysis 00 from intervals to any compact sets. Examples. $[0,1]$ and the Cantor set (an intersection of closed sets, inside $[0,1]$) are compact. $(0,1)$ is not: the sequence $1/n$ has every subsequence tending to $0 \notin (0,1)$. Equivalently, the open cover $\{(1/n, 1) : n \ge 2\}$ of $(0,1)$ has no finite subcover, since the union of finitely many of these sets is $(1/N, 1)$ for the largest $N$ used, which misses $(0, 1/N]$. $\mathbb{R}$ is closed but not bounded, so not compact. > Trick: use the sequential definition when you have a sequence in hand (most proofs in this post). Use the cover definition to pass from "local" information at each point to a "global" statement with finitely many pieces. Connected sets Two nonempty sets $A, B$ are separated if $\overline{A} \cap B = \emptyset$ and $A \cap \overline{B} = \emptyset$. A set is connected if it is not a union of two separated sets. Theorem. A set $E \subseteq \mathbb{R}$ is connected if and only if it is an interval: whenever $a < c < b$ with $a, b \in E$, also $c \in E$. $\mathbb{Q}$ is not connected: $\mathbb{Q} = \{r < \sqrt2\} \cup \{r > \sqrt2\}$ splits it into two separated pieces. This gap is exactly why the Intermediate Value Theorem fails for functions on $\mathbb{Q}$. Chapter 3 — Limits of functions Terminology - Functional limit — let $f : A \to \mathbb{R}$ and let $c$ be a limit point of $A$. Then $\lim{x \to c} f(x) = L$ means: for every $\varepsilon > 0$ there is $\delta > 0$ such that for all $x \in A$ with $0 < \lvert x - c \rvert < \delta$, $\lvert f(x) - L \rvert < \varepsilon$.- The condition $0 < \lvert x - c \rvert$ means the value $f(c)$ (if it exists) plays no role in the limit. A first example Claim. $\lim{x \to 2} (3x + 1) = 7$. Proof. $\lvert (3x + 1) - 7 \rvert = 3 \lvert x - 2 \rvert$. Given $\varepsilon > 0$, let $\delta = \varepsilon / 3$. If $0 < \lvert x - 2 \rvert < \delta$ then $\lvert (3x+1) - 7 \rvert < 3\delta = \varepsilon$. $\blacksquare$ For a linear function, $\delta$ is simply $\varepsilon$ divided by the slope. Nonlinear functions need one extra step (Chapter 4). The sequential criterion Theorem. $\lim{x \to c} f(x) = L$ if and only if for every sequence $(xn)$ in $A$ with $xn \ne c$ and $xn \to c$, the sequence $f(xn) \to L$. Proof of (⇒). Let $\varepsilon > 0$ and take the $\delta$ from the definition. Since $xn \to c$, there is $N$ with $\lvert xn - c \rvert < \delta$ for $n \ge N$, and $xn \ne c$. So $\lvert f(xn) - L \rvert < \varepsilon$ for $n \ge N$. $\blacksquare$ Proof of (⇐). Suppose the limit is not $L$. Negating the definition (Real Analysis 00): there is $\varepsilon0 > 0$ such that for every $\delta > 0$ some $x \in A$ has $0 < \lvert x - c \rvert < \delta$ and $\lvert f(x) - L \rvert \ge \varepsilon0$. Apply this with $\delta = 1/n$ for each $n$ to get $xn \ne c$ with $\lvert xn - c \rvert < 1/n$, so $xn \to c$, but $\lvert f(xn) - L \rvert \ge \varepsilon0$ for all $n$, so $f(xn) \not\to L$. $\blacksquare$ The same pattern — negate the $\varepsilon$–$\delta$ statement, then use $\delta = 1/n$ to build a sequence — proves the sequential criteria for continuity and for uniform continuity below. Corollary (divergence criterion). If two sequences $xn \to c$ and $yn \to c$ (terms $\ne c$) have $f(xn)$ and $f(yn)$ tending to different limits, then $\lim{x \to c} f(x)$ does not exist. Example. $f(x) = \sin(1/x)$ at $c = 0$. Take $xn = \frac{1}{2n\pi}$ and $yn = \frac{1}{2n\pi + \pi/2}$. Both tend to $0$, but $\sin(1/xn) = \sin(2n\pi) = 0$ and $\sin(1/yn) = \sin(2n\pi + \pi/2) = 1$ for every $n$. The limit does not exist: the graph oscillates between $-1$ and $1$ infinitely often near $0$. Chapter 4 — Continuity Terminology - Removable discontinuity at $c$ — $\lim{x \to c} f(x)$ exists but differs from $f(c)$ (or $f(c)$ is undefined).- Jump discontinuity — the one-sided limits $\lim{x \to c^-} f(x)$ and $\lim{x \to c^+} f(x)$ both exist but are different.- Essential discontinuity — at least one one-sided limit does not exist, as for $\sin(1/x)$ at $0$.- Lipschitz function — there is $K \ge 0$ with $\lvert f(x) - f(y) \rvert \le K \lvert x - y \rvert$ for all $x, y$ in the domain. Definition $f : A \to \mathbb{R}$ is continuous at $c \in A$ if for every $\varepsilon > 0$ there is $\delta > 0$ such that for all $x \in A$ with $\lvert x - c \rvert < \delta$, $\lvert f(x) - f(c) \rvert < \varepsilon$. It is continuous on $A$ if it is continuous at every point of $A$. Equivalently (sequential criterion): $f$ is continuous at $c$ if and only if $xn \to c$ with $xn \in A$ implies $f(xn) \to f(c)$. If $c$ is a limit point of $A$, this is the same as $\lim{x \to c} f(x) = f(c)$. At an isolated point of $A$ every function is continuous. Worked example: a delta for x squared at c = 3 Claim. $f(x) = x^2$ is continuous at $c = 3$. Scratch work. Factor: $\lvert x^2 - 9 \rvert = \lvert x - 3 \rvert \, \lvert x + 3 \rvert$. The factor $\lvert x - 3 \rvert$ is what $\delta$ controls; the factor $\lvert x + 3 \rvert$ must be bounded. Agree in advance that $\delta \le 1$. Then $\lvert x - 3 \rvert < 1$ gives $2 < x < 4$, so $\lvert x + 3 \rvert < 7$, and $$\lvert x^2 - 9 \rvert < 7 \lvert x - 3 \rvert.$$ This is less than $\varepsilon$ when $\lvert x - 3 \rvert < \varepsilon / 7$. Proof. Let $\varepsilon > 0$ and set $\delta = \min\left(1, \frac{\varepsilon}{7}\right)$. If $\lvert x - 3 \rvert < \delta$, then $\lvert x - 3 \rvert < 1$, so $\lvert x + 3 \rvert < 7$, and $\lvert x^2 - 9 \rvert < 7 \cdot \frac{\varepsilon}{7} = \varepsilon$. $\blacksquare$ Checking with numbers. For $\varepsilon = 1$ the rule gives $\delta = \min(1, 1/7) = 1/7 \approx 0.1429$. The worst case is at the right end, $x = 3 + \tfrac17$: $x^2 - 9 = \tfrac67 + \tfrac{1}{49} = \tfrac{43}{49} \approx 0.878 < 1$. At the left end, $9 - (3 - \tfrac17)^2 = \tfrac{41}{49} \approx 0.837 < 1$. Building continuous functions Algebraic Continuity Theorem. If $f$ and $g$ are continuous at $c$, so are $kf$, $f + g$, $fg$, and $f/g$ (if $g(c) \ne 0$). Proof. Use the sequential criterion: if $xn \to c$ then $f(xn) \to f(c)$ and $g(xn) \to g(c)$, and the Algebraic Limit Theorem (Real Analysis 01) does the rest. $\blacksquare$ Since $f(x) = x$ and constants are continuous, every polynomial is continuous on $\mathbb{R}$, and every rational function is continuous wherever its denominator is not zero. Composition. If $g$ is continuous at $c$ and $f$ is continuous at $g(c)$, then $f \circ g$ is continuous at $c$. Proof. Let $\varepsilon > 0$. Choose $\eta > 0$ with $\lvert y - g(c) \rvert < \eta \Rightarrow \lvert f(y) - f(g(c)) \rvert < \varepsilon$. Then choose $\delta > 0$ with $\lvert x - c \rvert < \delta \Rightarrow \lvert g(x) - g(c) \rvert < \eta$. Chaining, $\lvert x - c \rvert < \delta \Rightarrow \lvert f(g(x)) - f(g(c)) \rvert < \varepsilon$. $\blacksquare$ So $\sqrt{1 + x^2}$, $\sin(x^3)$ and $e^{\cos x}$ are continuous (given that the square root, sine, cosine and exponential functions are continuous on their domains). Chapter 5 — Continuous functions on compact sets and intervals Compactness is preserved Theorem. If $f : K \to \mathbb{R}$ is continuous and $K$ is compact, then $f(K) = \{f(x) : x \in K\}$ is compact. Proof. Let $(yn)$ be a sequence in $f(K)$; write $yn = f(xn)$ with $xn \in K$. By compactness a subsequence $x{nk} \to x \in K$. By continuity $y{nk} = f(x{nk}) \to f(x) \in f(K)$. So every sequence in $f(K)$ has a subsequence converging in $f(K)$. $\blacksquare$ The Extreme Value Theorem Theorem (EVT). If $f : K \to \mathbb{R}$ is continuous and $K$ is compact and nonempty, then $f$ attains a maximum and a minimum: there are $x0, x1 \in K$ with $f(x0) \le f(x) \le f(x1)$ for all $x \in K$. Proof. $f(K)$ is compact, hence bounded, so $s = \sup f(K)$ exists (Axiom of Completeness). By the $\varepsilon$-characterization, for each $n$ there is $yn \in f(K)$ with $s - 1/n < yn \le s$, so $yn \to s$. Since $f(K)$ is closed, $s \in f(K)$: $s = f(x1)$ for some $x1 \in K$. The minimum is the same argument with $\inf$. $\blacksquare$ Every hypothesis is needed: | Function and domain | What fails | Max attained? ||---------------------|------------|---------------|| $f(x) = x$ on $(0, 1)$ | domain not closed | no ($\sup = 1$ not reached) || $f(x) = x$ on $[0, \infty)$ | domain not bounded | no (unbounded) || $f(x) = 1/x$ on $(0, 1]$ | domain not closed | no (unbounded) || $f(0) = 0$, $f(x) = 1 - x$ on $(0, 1]$ | $f$ not continuous at $0$ | no ($\sup = 1$ not reached) | The Intermediate Value Theorem Theorem (IVT). Let $f : [a, b] \to \mathbb{R}$ be continuous, and let $L$ be a number strictly between $f(a)$ and $f(b)$. Then there is $c \in (a, b)$ with $f(c) = L$. Proof (via the supremum). Replacing $f$ by $f - L$ (and by $-f$ if needed), assume $f(a) < 0 < f(b)$ and find $c$ with $f(c) = 0$. Let $$S = \{x \in [a, b] : f(x) < 0\}.$$ $S$ contains $a$ and is bounded above by $b$, so $c = \sup S$ exists, and $a \le c \le b$. $f(c) > 0$ is impossible. By continuity there is $\delta > 0$ with $f(x) > 0$ for $x \in (c - \delta, c]$ (take $\varepsilon = f(c)$). Then no point of $S$ lies in $(c - \delta, c]$, and none lies above $c$, so $c - \delta$ is an upper bound of $S$ smaller than $c$. Contradiction. $f(c) < 0$ is impossible. Then $c \ne b$ since $f(b) > 0$, and by continuity $f(x) < 0$ on $[c, c + \delta)$ for some $\delta > 0$ (small enough that $c + \delta \le b$). So $c + \delta/2 \in S$, contradicting that $c$ is an upper bound. Hence $f(c) = 0$, and $c \ne a, b$ since $f(a) < 0 < f(b)$. $\blacksquare$ A second proof: $f([a,b])$ is connected (continuous images of connected sets are connected), hence an interval by the theorem in Chapter 2, so it contains every value between $f(a)$ and $f(b)$. A third uses bisection and the Nested Interval Property — which is also an algorithm. Worked example. $p(x) = x^3 + x - 1$ has a root in $(0,1)$, since $p(0) = -1 < 0 < 1 = p(1)$. On $\mathbb{Q} \cap [0, 2]$, the continuous function $g(x) = x^2 - 2$ is negative at $0$ and positive at $2$ but has no rational zero. Chapter 6 — Uniform continuity Definition $f : A \to \mathbb{R}$ is uniformly continuous on $A$ if for every $\varepsilon > 0$ there is $\delta > 0$ such that for all $x, y \in A$ with $\lvert x - y \rvert < \delta$, $\lvert f(x) - f(y) \rvert < \varepsilon$. Compare the quantifiers: - continuous on $A$: $\forall c\ \ \forall \varepsilon\ \ \exists \delta\ \ \forall x$ — $\delta$ may depend on $\varepsilon$ and on $c$;- uniformly continuous: $\forall \varepsilon\ \ \exists \delta\ \ \forall c\ \ \forall x$ — one $\delta$ works at every point. The example of 1/x Take $f(x) = 1/x$ on $(0, 1]$ and $\varepsilon = 1$. At a point $c$, the largest $\delta$ that works is decided on the left side, where the graph is steeper: $$\frac{1}{c - \delta} - \frac{1}{c} = \frac{\delta}{c(c - \delta)} = \varepsilon \quad\Longleftrightarrow\quad \delta = \frac{\varepsilon c^2}{1 + \varepsilon c}.$$ | point $c$ | $1$ | $1/2$ | $1/4$ | $1/10$ ||-----------|-----|-------|-------|--------|| largest $\delta$ for $\varepsilon = 1$ | $1/2$ | $1/6 \approx 0.167$ | $1/20 = 0.05$ | $1/110 \approx 0.00909$ | At each point a $\delta$ exists, so $1/x$ is continuous on $(0,1]$. But the best $\delta$ tends to $0$ as $c \to 0$, so no single $\delta$ serves every point: $1/x$ is not uniformly continuous on $(0,1]$. The domain is bounded but not closed, and the missing point $0$ is exactly where things go wrong. Proving a function is not uniformly continuous Sequential criterion. $f$ is not uniformly continuous on $A$ if and only if there are $\varepsilon0 > 0$ and sequences $(xn), (yn)$ in $A$ with $\lvert xn - yn \rvert \to 0$ but $\lvert f(xn) - f(yn) \rvert \ge \varepsilon0$ for all $n$. - $1/x$ on $(0,1]$: $xn = \frac{1}{n+1}$, $yn = \frac{1}{n+2}$. Then $\lvert xn - yn \rvert = \frac{1}{(n+1)(n+2)} \to 0$ but $\lvert f(xn) - f(yn) \rvert = 1$.- $x^2$ on $\mathbb{R}$: $xn = n$, $yn = n + \frac1n$. Then $\lvert xn - yn \rvert = \frac1n \to 0$ but $\lvert yn^2 - xn^2 \rvert = 2 + \frac{1}{n^2} \ge 2$. The graph gets steeper without bound.- $\sin(1/x)$ on $(0,1)$: $xn = \frac{1}{2n\pi}$, $yn = \frac{1}{2n\pi + \pi/2}$ from Chapter 3. Their distance tends to $0$ and the values differ by $1$. This function is bounded and continuous on $(0,1)$, yet not uniformly continuous. On a bounded interval, $x^2$ is uniformly continuous: on $[-M, M]$, $\lvert x^2 - y^2 \rvert = \lvert x + y \rvert \lvert x - y \rvert \le 2M \lvert x - y \rvert$, so $\delta = \varepsilon / (2M)$ works everywhere. More generally, a Lipschitz function ($\lvert f(x) - f(y) \rvert \le K \lvert x - y \rvert$ for all $x, y$) is uniformly continuous with $\delta = \varepsilon / K$. Compact domains fix everything Theorem. A continuous function on a compact set $K$ is uniformly continuous on $K$. Proof. Suppose not. By the sequential criterion there are $\varepsilon0 > 0$ and $xn, yn \in K$ with $\lvert xn - yn \rvert \to 0$ and $\lvert f(xn) - f(yn) \rvert \ge \varepsilon0$. By compactness a subsequence $x{nk} \to x \in K$. Then $$\lvert y{nk} - x \rvert \le \lvert y{nk} - x{nk} \rvert + \lvert x{nk} - x \rvert \to 0,$$ so $y{nk} \to x$ too. By continuity at $x$, both $f(x{nk})$ and $f(y{nk})$ tend to $f(x)$, so $\lvert f(x{nk}) - f(y{nk}) \rvert \to 0$. This contradicts $\lvert f(x{nk}) - f(y{nk}) \rvert \ge \varepsilon0$. $\blacksquare$ This theorem is the reason the Riemann integral of a continuous function on $[a, b]$ exists (Real Analysis 04): one $\delta$ for the whole interval controls every subinterval of a partition at once. > Watch out: "continuous on $(0,1)$ and bounded" does not give uniform continuity ($\sin(1/x)$), and neither does "continuous on a closed set" ($x^2$ on $\mathbb{R}$). The hypothesis is closed and bounded. Chapter 7 — How discontinuous can a function be? Dirichlet's function $g(x) = 1$ for $x \in \mathbb{Q}$ and $g(x) = 0$ for $x \notin \mathbb{Q}$ is discontinuous at every point. Given $c$, the density of $\mathbb{Q}$ and of the irrationals (Real Analysis 00) gives a sequence of rationals $xn \to c$ and a sequence of irrationals $yn \to c$, with $g(xn) = 1$ and $g(yn) = 0$; they cannot both tend to $g(c)$. A function continuous at exactly one point. $h(x) = x \, g(x)$ (equal to $x$ on $\mathbb{Q}$ and $0$ elsewhere) is continuous at $0$, since $\lvert h(x) \rvert \le \lvert x \rvert$ (take $\delta = \varepsilon$), and discontinuous at every $c \ne 0$ by the same two-sequence argument. Thomae's function. $$t(x) = \begin{cases} 1 & x = 0, \\ 1/q & x = p/q \text{ in lowest terms, } q \ge 1, \\ 0 & x \notin \mathbb{Q}. \end{cases}$$ - Discontinuous at every rational $c = p/q$: $t(c) = 1/q > 0$, but irrationals $yn \to c$ have $t(yn) = 0$.- Continuous at every irrational $c$: given $\varepsilon > 0$, choose $q0$ with $1/q0 < \varepsilon$. In the interval $(c - 1, c + 1)$ only finitely many rationals have denominator $q < q0$, and none equals $c$. Choose $\delta > 0$ so small that $V\delta(c)$ avoids all of them. Every $x \in V\delta(c)$ is then irrational ($t(x) = 0$) or has denominator $\ge q0$ ($t(x) \le 1/q0 < \varepsilon$). So $\lvert t(x) - t(c) \rvert < \varepsilon$. So Thomae's function is continuous exactly on the irrationals. The reverse is impossible: no function $f : \mathbb{R} \to \mathbb{R}$ is continuous exactly on $\mathbb{Q}$. Limits drive enforcement. - A request is a reservation. The scheduler subtracts it from the node's allocatable capacity and guarantees the Pod that much. It is also the number that decides whether the Pod fits at all.- A limit is a ceiling enforced at runtime by the kernel through cgroups. Exceed the CPU limit and you are throttled. Exceed the memory limit and you are killed. Everything else in this chapter follows from that distinction. CPU is compressible: exceeding your share means running slower. Memory is incompressible: there is no "slower", only "killed". QoS classes The kubelet assigns each Pod a class based purely on how its requests and limits are written: | Class | Condition | Consequence ||-------|-----------|-------------|| Guaranteed | every container sets both CPU and memory, and request == limit for each | evicted last; eligible for exclusive CPUs under the static CPU manager policy || Burstable | at least one request is set, but not the Guaranteed pattern | evicted after BestEffort, in order of how far usage exceeds requests || BestEffort | no requests or limits anywhere in the Pod | evicted first, always | Under node memory pressure the kubelet evicts in that order: BestEffort first, then Burstable Pods that are using more than they requested (ranked by the excess), then Guaranteed. The kernel's own OOM killer uses a parallel mechanism, , derived from the same classes. > Common pitfall: BestEffort Pods look thrifty and are actually hazardous. They are the first thing evicted when a node fills up, they contribute nothing to autoscaler capacity calculations, and they can starve neighbours. CPU limits and CFS throttling A CPU limit is implemented as a CFS quota: the cgroup is granted quota microseconds of CPU time per period (100 ms by default). A limit of means 50 ms of CPU per 100 ms window. When the quota is exhausted, every thread in the cgroup is stopped until the next period begins. This produces a failure mode that is invisible in average CPU graphs. An application averaging 30 % of its limit can still be throttled hard, because the work is not spread evenly: a request arrives, several threads wake, the quota is consumed in 15 ms, and the container sleeps for the remaining 85 ms. The result is tail latency in whole multiples of 100 ms while the dashboard shows a comfortable average. Multithreaded runtimes make it worse. A JVM or Go program that sees 32 host CPUs will happily run 32 threads, burning the quota 32× faster than a single thread would. Measure it — do not guess: Sustained values above roughly 5-10 % on a latency-sensitive service are worth acting on. Confirm on your own workload rather than trusting any published threshold. The genuine argument for omitting CPU limits Set memory limits always; consider omitting CPU limits on latency-sensitive services. The case for omitting: CPU is compressible and already fairly shared. When several containers on a node contend, the kernel divides CPU time in proportion to their requests (cgroup CPU shares) — so requests alone already provide isolation under contention. A limit adds nothing during contention and actively hurts when the node is idle, because it forbids a container from using spare capacity it could have had for free. Throttling a service that could have run faster, on a machine that is 60 % idle, is pure loss. The case for keeping them: limits make behaviour reproducible and capacity predictable, they stop one runaway process from degrading its neighbours' latency (fair sharing is fair, but a busy neighbour still slows you down), some regulated or multi-tenant environments require hard ceilings, and Guaranteed QoS — which requires a CPU limit — is needed for exclusive CPU pinning. A defensible policy: memory limit always set and equal to a measured peak plus headroom; CPU request set from measured usage; CPU limit omitted for latency-sensitive services, set generously (well above the request) for batch and untrusted workloads. Whatever you choose, also set (Go) or the container-aware JVM flags so the runtime sizes its thread pools to the cgroup, not to the host. A sequence is the simplest infinite process in mathematics, and its limit is the idea on which the rest of analysis is built: derivatives, integrals and continuity are all limits in disguise. Chapter 1 — The limit of a sequence Terminology - Sequence — a function from $\mathbb{N}$ to $\mathbb{R}$, written $(an) = (a1, a2, a3, \dots)$.- $\varepsilon$-neighbourhood of $a$ — the interval $V\varepsilon(a) = (a - \varepsilon, a + \varepsilon)$, the points within distance $\varepsilon$ of $a$.- Converges — $(an)$ converges to $a$, written $an \to a$ or $\lim an = a$, if for every $\varepsilon > 0$ there is $N \in \mathbb{N}$ such that $\lvert an - a \rvert < \varepsilon$ for all $n \ge N$.- Diverges — does not converge to any real number.- Tail — the terms $aN, a{N+1}, \dots$ from some index on.- Bounded — there is $M > 0$ with $\lvert an \rvert \le M$ for all $n$. The definition says: whatever tolerance $\varepsilon$ is demanded, the whole tail from some $N$ on lies inside the band $V\varepsilon(a)$. The $N$ is allowed to depend on $\varepsilon$ (a smaller band usually needs a larger $N$). Finitely many early terms never matter. A worked proof with explicit numbers Claim. $\displaystyle an = \frac{2n+1}{n+3} \to 2$. Scratch work. Compute the distance to the limit: $$\lvert an - 2 \rvert = \left\lvert \frac{2n + 1 - 2(n+3)}{n+3} \right\rvert = \frac{5}{n+3}.$$ This is less than $\varepsilon$ exactly when $n + 3 > 5/\varepsilon$, i.e. $n > 5/\varepsilon - 3$. Proof. Let $\varepsilon > 0$. By the Archimedean property choose $N \in \mathbb{N}$ with $N > 5/\varepsilon - 3$. For $n \ge N$, $$\lvert an - 2 \rvert = \frac{5}{n+3} \le \frac{5}{N+3} < \varepsilon. \qquad \blacksquare$$ Checking with numbers. You do not need the exact solution of $\lvert an - a \rvert < \varepsilon$. For $bn = \frac{n+1}{n^2}$, for example, $\lvert bn - 0 \rvert = \frac{n+1}{n^2} \le \frac{2n}{n^2} = \frac{2}{n}$, so any $N > 2/\varepsilon$ works. More examples $1/\sqrt{n} \to 0$. Given $\varepsilon > 0$ choose $N > 1/\varepsilon^2$. For $n \ge N$, $\sqrt{n} \ge \sqrt{N} > 1/\varepsilon$, so $1/\sqrt{n} < \varepsilon$. $r^n \to 0$ for $0 \le r < 1$. If $r = 0$ it is trivial. Otherwise write $r = \frac{1}{1 + h}$ with $h > 0$. A sequence has at most one limit. Proof. Suppose $an \to a$ and $an \to b$. Let $\varepsilon > 0$. There are $N1, N2$ with $\lvert an - a \rvert < \varepsilon/2$ for $n \ge N1$ and $\lvert an - b \rvert < \varepsilon/2$ for $n \ge N2$. For $n = \max(N1, N2)$, $$\lvert a - b \rvert \le \lvert a - an \rvert + \lvert an - b \rvert < \varepsilon.$$ Since $\varepsilon$ was arbitrary, $a = b$ by the equality lemma of Real Analysis 00. $\blacksquare$ Theorem. Every convergent sequence is bounded. Proof. Let $an \to a$. With $\varepsilon = 1$ there is $N$ such that $\lvert an - a \rvert < 1$, hence $\lvert an \rvert < \lvert a \rvert + 1$, for $n \ge N$. Chapter 2 — Limit theorems The Algebraic Limit Theorem Theorem. Let $an \to a$ and $bn \to b$. Then(i) $c\,an \to c\,a$ for every $c \in \mathbb{R}$;(ii) $an + bn \to a + b$;(iii) $an bn \to ab$;(iv) $an / bn \to a / b$, provided $b \ne 0$ (and $bn \ne 0$ for all $n$). Proof of (ii). Let $\varepsilon > 0$. Choose $N1$ with $\lvert an - a \rvert < \varepsilon/2$ for $n \ge N1$, and $N2$ with $\lvert bn - b \rvert < \varepsilon/2$ for $n \ge N2$. For $n \ge \max(N1, N2)$, $$\lvert (an + bn) - (a + b) \rvert \le \lvert an - a \rvert + \lvert bn - b \rvert < \tfrac{\varepsilon}{2} + \tfrac{\varepsilon}{2} = \varepsilon. \qquad \blacksquare$$ Proof of (iii). Add and subtract $an b$: $$\lvert an bn - ab \rvert = \lvert an (bn - b) + (an - a) b \rvert \le \lvert an \rvert \lvert bn - b \rvert + \lvert b \rvert \lvert an - a \rvert.$$ $(an)$ converges, so it is bounded: $\lvert an \rvert \le M$ for some $M > 0$. Let $\varepsilon > 0$. Choose $N1$ with $\lvert bn - b \rvert < \frac{\varepsilon}{2M}$ for $n \ge N1$, and $N2$ with $\lvert an - a \rvert < \frac{\varepsilon}{2(\lvert b \rvert + 1)}$ for $n \ge N2$. (The $+1$ avoids dividing by zero when $b = 0$.) For $n \ge \max(N1, N2)$, $$\lvert an bn - ab \rvert < M \cdot \frac{\varepsilon}{2M} + \lvert b \rvert \cdot \frac{\varepsilon}{2(\lvert b \rvert + 1)} < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon. \qquad \blacksquare$$ Part (iv) is proved by first showing $1/bn \to 1/b$: the key step is that $\lvert bn \rvert > \lvert b \rvert / 2$ for all large $n$ (reverse triangle inequality), which keeps $1/\lvert bn \rvert$ bounded. Example. Rewriting $an = \frac{2n+1}{n+3} = \frac{2 + 1/n}{1 + 3/n}$, the theorem gives $\lim an = \frac{2 + 0}{1 + 0} = 2$ at once, since $1/n \to 0$. The explicit $\varepsilon$–$N$ proof of Chapter 1 is what the theorem packages. Order and squeezing Order Limit Theorem. Let $an \to a$ and $bn \to b$.(i) If $an \ge 0$ for all $n$, then $a \ge 0$.(ii) If $an \le bn$ for all $n$, then $a \le b$.(iii) If $c \le bn$ for all $n$, then $c \le b$; if $an \le c$ for all $n$, then $a \le c$. Proof of (i). Suppose $a < 0$. Take $\varepsilon = \lvert a \rvert$. For large $n$, $\lvert an - a \rvert < \lvert a \rvert$, which gives $an < a + \lvert a \rvert = 0$, a contradiction. Part (ii) is (i) applied to $bn - an$, and (iii) is (ii) with a constant sequence. $\blacksquare$ > Watch out: strict inequalities are not preserved. $1/n > 0$ for every $n$, but $\lim 1/n = 0$. Limits turn $<$ into $\le$. Squeeze theorem. If $xn \le yn \le zn$ for all $n$ and $xn \to \ell$, $zn \to \ell$, then $yn \to \ell$. Example: $0 \le \frac{\lvert\sin n\rvert}{n} \le \frac1n$, so $\frac{\sin n}{n} \to 0$. Chapter 3 — Monotone sequences Terminology - Increasing — $an \le a{n+1}$ for all $n$. Decreasing — $an \ge a{n+1}$ for all $n$.- Monotone — increasing or decreasing. The Monotone Convergence Theorem Theorem. A monotone sequence converges if and only if it is bounded. An increasing bounded sequence converges to $\sup\{an : n \in \mathbb{N}\}$. Proof. Convergent implies bounded (Chapter 1). Conversely, let $(an)$ be increasing and bounded. The set $\{an\}$ is nonempty and bounded above, so by the Axiom of Completeness $s = \sup\{an\}$ exists. Let $\varepsilon > 0$. Since $s - \varepsilon$ is not an upper bound, some $aN > s - \varepsilon$. For $n \ge N$, monotonicity and $s$ being an upper bound give $$s - \varepsilon < aN \le an \le s,$$ so $\lvert an - s \rvert < \varepsilon$. The decreasing case is the same with the infimum. $\blacksquare$ The theorem proves that a limit exists without knowing its value in advance — the essential use of completeness. In $\mathbb{Q}$ it fails: the increasing bounded sequence $1, 1.4, 1.41, 1.414, \dots$ of decimal truncations of $\sqrt{2}$ has no rational limit. Worked example: a recursive sequence for the square root of 2 Define $x1 = 1$ and $$x{n+1} = \frac12 \left( xn + \frac{2}{xn} \right).$$ (This is Newton's method for $x^2 - 2 = 0$.) The first terms are | $n$ | $xn$ | decimal | $xn^2 - 2$ ||-----|-------|---------|-------------|| 1 | $1$ | $1$ | $-1$ || 2 | $3/2$ | $1.5$ | $0.25$ || 3 | $17/12$ | $1.416667$ | $\approx 6.94 \times 10^{-3}$ || 4 | $577/408$ | $1.414216$ | $\approx 6.01 \times 10^{-6}$ || 5 | $665857/470832$ | $1.414214$ | $\approx 4.51 \times 10^{-12}$ | Step 1 — bounded below by $\sqrt{2}$ from $n = 2$ on. All $xn > 0$ by induction. For any $x > 0$, $$\frac12\left(x + \frac2x\right) - \sqrt{2} = \frac{x^2 - 2\sqrt{2}\,x + 2}{2x} = \frac{(x - \sqrt{2})^2}{2x} \ge 0,$$ so $x{n+1} \ge \sqrt{2}$ for every $n \ge 1$. Step 2 — decreasing from $n = 2$ on. For $n \ge 2$, $xn^2 \ge 2$, so $$xn - x{n+1} = \frac{xn}{2} - \frac{1}{xn} = \frac{xn^2 - 2}{2xn} \ge 0.$$ Step 3 — find the limit. The tail $(xn){n \ge 2}$ is decreasing and bounded below, so by the Monotone Convergence Theorem $xn \to L$ for some $L \ge \sqrt{2} > 0$. The shifted sequence $x{n+1}$ has the same limit, and the Algebraic Limit Theorem applied to the recursion gives $L = \frac12 (L + 2/L)$, i.e. $L^2 = 2$. Since $L > 0$, $L = \sqrt{2}$. $\blacksquare$ > Common pitfall: solving $L = \frac12(L + 2/L)$ before proving the limit exists. For $x{n+1} = 2xn$ with $x1 = 1$ the same trick "gives" $L = 2L$, so $L = 0$ — but $xn = 2^{n-1}$ diverges. Existence first (monotone and bounded), then the equation. The number $e$ arises the same way: $\left(1 + \frac1n\right)^n$ is increasing and bounded above by $3$, so it converges, and its limit is defined to be $e$ (Bartle and Sherbert, Section 3.3). Chapter 4 — Subsequences, Bolzano–Weierstrass and Cauchy sequences Terminology - Subsequence of $(an)$ — a sequence $(a{nk}) = (a{n1}, a{n2}, \dots)$ with $n1 < n2 < n3 < \cdots$. It keeps infinitely many terms, in order.- Cauchy sequence — for every $\varepsilon > 0$ there is $N$ such that $\lvert an - am \rvert < \varepsilon$ for all $m, n \ge N$. The terms get close to each other, with no limit mentioned.- Limit superior — $\limsup an = \lim{n \to \infty} yn$ where $yn = \sup\{ak : k \ge n\}$. Limit inferior — the same with $\inf$. Theorem. If $an \to a$, every subsequence also converges to $a$. (Given $\varepsilon$ and $N$ for $(an)$, use the same $N$: $nk \ge k$, so $k \ge N$ implies $nk \ge N$.) This gives the quickest divergence proofs: find two subsequences with different limits. For $(-1)^n$, the even terms tend to $1$ and the odd terms to $-1$. Bolzano–Weierstrass Theorem (Bolzano–Weierstrass). Every bounded sequence has a convergent subsequence. Proof (bisection). Let $\lvert an \rvert \le M$ and $I1 = [-M, M]$. Choose $n1 = 1$. Split $I1$ into two closed halves; at least one contains $an$ for infinitely many $n$. Call it $I2$ and choose $n2 > n1$ with $a{n2} \in I2$. Continue: $I{k+1}$ is a half of $Ik$ containing infinitely many terms, and $n{k+1} > nk$ has $a{n{k+1}} \in I{k+1}$. The intervals are closed, bounded and nested, with length $2M / 2^{k-1}$ for $Ik$. By the Nested Interval Property there is $x$ in every $Ik$. Both $x$ and $a{nk}$ lie in $Ik$, so $$\lvert a{nk} - x \rvert \le \frac{2M}{2^{k-1}} \to 0.$$ Hence $a{nk} \to x$. $\blacksquare$ The Cauchy criterion Theorem (Cauchy criterion). A sequence of real numbers converges if and only if it is a Cauchy sequence. Proof. ($\Rightarrow$) If $an \to a$, choose $N$ with $\lvert an - a \rvert < \varepsilon/2$ for $n \ge N$. For $m, n \ge N$, $\lvert an - am \rvert \le \lvert an - a \rvert + \lvert a - am \rvert < \varepsilon$. ($\Leftarrow$) Let $(an)$ be Cauchy.Bounded: with $\varepsilon = 1$ there is $N$ with $\lvert an - aN \rvert < 1$ for $n \ge N$, so $\lvert an \rvert < \lvert aN \rvert + 1$ for $n \ge N$; take the maximum with the first $N - 1$ terms.A subsequence converges: by Bolzano–Weierstrass, $a{nk} \to a$ for some $a$.The whole sequence follows: given $\varepsilon > 0$, choose $N$ with $\lvert an - am \rvert < \varepsilon/2$ for $m, n \ge N$, and choose $k$ with $nk \ge N$ and $\lvert a{nk} - a \rvert < \varepsilon/2$. For $n \ge N$, $$\lvert an - a \rvert \le \lvert an - a{nk} \rvert + \lvert a{nk} - a \rvert < \varepsilon. \qquad \blacksquare$$ The Cauchy criterion lets you prove convergence using only the terms themselves. In $\mathbb{Q}$ it fails: the Newton sequence of Chapter 3 is a Cauchy sequence of rationals with no rational limit. Completeness of $\mathbb{R}$ can be defined by "every Cauchy sequence converges" together with the Archimedean property; it is equivalent to the Axiom of Completeness. > Watch out: "consecutive terms get close" is not the Cauchy condition. For $an = \sqrt{n}$, $a{n+1} - an = \frac{1}{\sqrt{n+1} + \sqrt{n}} \to 0$, yet $an \to \infty$. Cauchy requires $\lvert an - am \rvert$ small for all pairs $m, n \ge N$. Limit superior and inferior For a bounded sequence, $yn = \sup\{ak : k \ge n\}$ is decreasing (a supremum over a smaller set) and bounded, so $\limsup an = \lim yn$ always exists by the Monotone Convergence Theorem; likewise $\liminf$. Always $\liminf an \le \limsup an$. Example. $an = (-1)^n\left(1 + \frac1n\right)$: the terms are $-2, \tfrac32, -\tfrac43, \tfrac54, \dots$. The even terms decrease to $1$ and the odd terms increase to $-1$, so $\limsup an = 1$ and $\liminf an = -1$, although no term equals $1$ or $-1$. Theorem. A bounded sequence converges if and only if $\liminf an = \limsup an$, and then the limit is this common value. $\limsup$ is the largest limit of any subsequence and $\liminf$ the smallest. These notions give the sharp form of the root test in Chapter 6. Chapter 5 — Infinite series Terminology - Series — an expression $\sum{k=1}^\infty ak$. Its partial sums are $sn = a1 + a2 + \cdots + an$.- Converges — the sequence $(sn)$ converges; its limit $S$ is the sum, written $\sum{k=1}^\infty ak = S$.- Diverges — $(sn)$ does not converge. A series is a sequence in disguise: every question about $\sum ak$ is a question about $(sn)$. Geometric and telescoping series Geometric series. For $r \ne 1$, $sn = \sum{k=0}^{n-1} r^k = \frac{1 - r^n}{1 - r}$ (multiply by $1 - r$ and cancel). If $\lvert r \rvert < 1$, then $r^n \to 0$ and $$\sum{k=0}^\infty r^k = \frac{1}{1 - r}.$$ If $\lvert r \rvert \ge 1$ the series diverges (its terms do not tend to $0$). Example: $\sum{k=1}^\infty \left(\tfrac12\right)^k = \frac{1}{1 - 1/2} - 1 = 1$. Telescoping series. $\frac{1}{k(k+1)} = \frac1k - \frac{1}{k+1}$, so the partial sums collapse: $sn = 1 - \frac{1}{n+1} \to 1$. Hence $\sum{k=1}^\infty \frac{1}{k(k+1)} = 1$. The divergence test Theorem. If $\sum ak$ converges, then $ak \to 0$. Proof. $ak = sk - s{k-1}$, and both $sk$ and $s{k-1}$ tend to the same limit $S$. $\blacksquare$ So $\sum \frac{k}{k+1}$ diverges, since its terms tend to $1$. The converse is false, and the harmonic series is the standard counterexample. The harmonic series diverges Theorem. $\sum{k=1}^\infty \frac1k$ diverges, although $\frac1k \to 0$. Proof. Group the terms in blocks that end at powers of $2$: $$s{2^m} = 1 + \tfrac12 + \left(\tfrac13 + \tfrac14\right) + \left(\tfrac15 + \cdots + \tfrac18\right) + \cdots + \left(\tfrac{1}{2^{m-1}+1} + \cdots + \tfrac{1}{2^m}\right).$$ Each bracket has $2^{j-1}$ terms, each at least $\frac{1}{2^j}$, so each bracket is at least $\frac12$. Hence $s{2^m} \ge 1 + \frac{m}{2}$. The partial sums are increasing and unbounded, so the series diverges. $\blacksquare$ The actual values confirm the bound: $s2 = 1.5$, $s4 \approx 2.083$, $s8 \approx 2.718$, $s{16} \approx 3.381$, $s{32} \approx 4.058$, each at least $1 + m/2$. The growth is very slow — $sn$ grows like $\ln n$. The Cauchy criterion for series Applying the Cauchy criterion to $(sn)$: $\sum ak$ converges if and only if for every $\varepsilon > 0$ there is $N$ such that for all $n > m \ge N$, $$\lvert a{m+1} + a{m+2} + \cdots + an \rvert < \varepsilon.$$ "The blocks far out add up to almost nothing." The harmonic series fails this: the block from $m+1$ to $2m$ is always at least $m \cdot \frac{1}{2m} = \frac12$. Chapter 6 — Convergence tests Comparison Comparison test. Suppose $0 \le ak \le bk$ for all $k$.(i) If $\sum bk$ converges, so does $\sum ak$.(ii) If $\sum ak$ diverges, so does $\sum bk$. Proof. The partial sums of $\sum ak$ are increasing and bounded by $\sum bk$; apply the Monotone Convergence Theorem. Part (ii) is the contrapositive of (i). $\blacksquare$ Example: $\sum 1/k^2$ converges. For $k \ge 2$, $\frac{1}{k^2} < \frac{1}{k(k-1)} = \frac{1}{k-1} - \frac1k$, a telescoping series with sum $1$. So $\sum{k=1}^\infty \frac{1}{k^2} < 1 + 1 = 2$ converges. (Its exact value, $\pi^2/6 \approx 1.645$, is Euler's solution of the Basel problem.) $p$-series. $\sum \frac{1}{k^p}$ converges if and only if $p > 1$. (Cauchy condensation or the integral test, Abbott Section 2.4.) Ratio and root tests Ratio test. Suppose $ak \ne 0$ and $\lim \left\lvert \frac{a{k+1}}{ak} \right\rvert = r$. If $r < 1$, $\sum ak$ converges absolutely; if $r > 1$, it diverges; if $r = 1$, the test says nothing. Root test. Let $r = \limsup \lvert ak \rvert^{1/k}$. If $r < 1$, $\sum ak$ converges absolutely; if $r > 1$, it diverges; if $r = 1$, no conclusion. Both tests compare with a geometric series: if $r < 1$, pick $q$ with $r < q < 1$; eventually $\lvert ak \rvert \le C q^k$. Example. $\sum{k=1}^\infty \frac{k}{2^k}$: $\frac{a{k+1}}{ak} = \frac{k+1}{2k} \to \frac12 < 1$, so it converges. (Its sum is $2$.) > Watch out: $r = 1$ is genuinely inconclusive. Both $\sum 1/k$ (divergent) and $\sum 1/k^2$ (convergent) have ratio limit $1$. Alternating series Alternating Series Test. If $(ak)$ is decreasing and $ak \to 0$, then $\sum{k=1}^\infty (-1)^{k+1} ak = a1 - a2 + a3 - \cdots$ converges. Proof sketch. The even partial sums $s{2n} = (a1 - a2) + \cdots + (a{2n-1} - a{2n})$ increase; the odd ones $s{2n+1} = a1 - (a2 - a3) - \cdots$ decrease; and $s{2n} \le s{2n+1}$ with $s{2n+1} - s{2n} = a{2n+1} \to 0$. So the intervals $[s{2n}, s{2n+1}]$ are nested with lengths going to $0$, and all partial sums converge to the single common point. $\blacksquare$ The proof also gives the error bound: the sum lies between any two consecutive partial sums, so $\lvert S - sn \rvert \le a{n+1}$. Example. The alternating harmonic series converges: $$1 - \frac12 + \frac13 - \frac14 + \cdots = \ln 2 \approx 0.6931.$$ (The value $\ln 2$ comes from the Taylor series of $\ln(1 + x)$ evaluated at $x = 1$; the test itself gives only convergence.) Absolute and conditional convergence - $\sum ak$ converges absolutely if $\sum \lvert ak \rvert$ converges.- It converges conditionally if it converges but $\sum \lvert ak \rvert$ diverges. Theorem. Absolute convergence implies convergence. Proof. By the triangle inequality $\lvert a{m+1} + \cdots + an \rvert \le \lvert a{m+1} \rvert + \cdots + \lvert an \rvert$. If $\sum \lvert ak \rvert$ satisfies the Cauchy criterion, so does $\sum ak$. $\blacksquare$ The alternating harmonic series converges conditionally: it converges, but $\sum \frac1k$ diverges. Rearrangements A rearrangement of $\sum ak$ is $\sum a{f(k)}$ for a bijection $f : \mathbb{N} \to \mathbb{N}$ — the same terms in a different order. Theorem. If $\sum ak$ converges absolutely, every rearrangement converges to the same sum. Riemann rearrangement theorem. If $\sum ak$ converges conditionally, then for every $L \in \mathbb{R}$ there is a rearrangement that converges to $L$ (and there are rearrangements that diverge). The idea: the positive terms alone and the negative terms alone both diverge. Add positive terms until you pass $L$, then negative terms until you drop below $L$, and repeat; since $ak \to 0$, the overshoots shrink to $0$. Example. Rearrange the alternating harmonic series as "one positive term, then two negative terms": $$1 - \frac12 - \frac14 + \frac13 - \frac16 - \frac18 + \frac15 - \frac{1}{10} - \frac{1}{12} + \cdots$$ Group each block of three. Since $\frac{1}{2k-1} - \frac{1}{4k-2} = \frac{1}{4k-2}$, the $k$-th block is $$\frac{1}{4k-2} - \frac{1}{4k} = \frac12 \left( \frac{1}{2k-1} - \frac{1}{2k} \right).$$ So the block sums add up to half of the alternating harmonic series: the rearranged series converges to $\tfrac12 \ln 2$, not $\ln 2$. (The partial sums that stop inside a block differ from the block sums by terms tending to $0$, so they have the same limit.) > Common pitfall: treating an infinite sum like a finite one. Regrouping, reordering and term-by-term manipulations are safe for absolutely convergent series, and can fail for conditionally convergent ones. Practice Exercises 1.
