<h1 id="Chapter-10-—-Sort-limit-skip-—-and-what-doesnt-scale"><a href="#Chapter-10-—-Sort-limit-skip-—-and-what-doesnt-scale" class="headerlink" title="Chapter 10 — Sort, limit, skip — and what doesn't scale"></a>Chapter 10 — Sort, limit, skip — and what doesn't scale</h1>
<pre><code class="language-js"><figure class="highlight js"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span></pre></td><td class="code"><pre><code class="js"><span class="line">db.<span class="hljs-property">orders</span>.<span class="hljs-title function_">find</span>({ <span class="hljs-attr">status</span>: <span class="hljs-string">&quot;paid&quot;</span> })</span><br><span class="line">  .<span class="hljs-title function_">sort</span>({ <span class="hljs-attr">at</span>: -<span class="hljs-number">1</span> })</span><br><span class="line">  .<span class="hljs-title function_">limit</span>(<span class="hljs-number">20</span>)</span><br><span class="line">  .<span class="hljs-title function_">skip</span>(<span class="hljs-number">40</span>)</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>For small offsets this is fine. <strong>Cost of <code>.skip(N)</code></strong>: server scans N + limit documents in sort order, then discards the N. For N = 10,000 on a million-row collection that's painful even with an index.</p>
<h2 id="Range-pagination-—-the-production-pattern"><a href="#Range-pagination-—-the-production-pattern" class="headerlink" title="Range pagination — the production pattern"></a>Range pagination — the production pattern</h2>
<p>Sort by a unique-enough field (often <code>_id</code> or a timestamp). Use the last seen value as a cursor for the next page.</p>
<pre><code class="language-js"><figure class="highlight js"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span><br><span class="line">11</span><br><span class="line">12</span><br><span class="line">13</span><br><span class="line">14</span><br><span class="line">15</span><br><span class="line">16</span><br><span class="line">17</span></pre></td><td class="code"><pre><code class="js"><span class="line"><span class="hljs-comment">// page 1</span></span><br><span class="line"><span class="hljs-keyword">const</span> first = <span class="hljs-keyword">await</span> db.<span class="hljs-title function_">collection</span>(<span class="hljs-string">&#x27;orders&#x27;</span>).<span class="hljs-title function_">find</span>({ <span class="hljs-attr">status</span>: <span class="hljs-string">&quot;paid&quot;</span> })</span><br><span class="line">  .<span class="hljs-title function_">sort</span>({ <span class="hljs-attr">at</span>: -<span class="hljs-number">1</span> })</span><br><span class="line">  .<span class="hljs-title function_">limit</span>(<span class="hljs-number">20</span>)</span><br><span class="line">  .<span class="hljs-title function_">toArray</span>();</span><br><span class="line"> </span><br><span class="line"><span class="hljs-keyword">const</span> last = first[first.<span class="hljs-property">length</span> - <span class="hljs-number">1</span>];</span><br><span class="line"> </span><br><span class="line"><span class="hljs-comment">// page 2</span></span><br><span class="line"><span class="hljs-keyword">const</span> next = <span class="hljs-keyword">await</span> db.<span class="hljs-title function_">collection</span>(<span class="hljs-string">&#x27;orders&#x27;</span>).<span class="hljs-title function_">find</span>({</span><br><span class="line">  <span class="hljs-attr">status</span>: <span class="hljs-string">&quot;paid&quot;</span>,</span><br><span class="line">  <span class="hljs-attr">at</span>: { <span class="hljs-attr">$lt</span>: last.<span class="hljs-property">at</span> }     <span class="hljs-comment">// strictly less than last seen</span></span><br><span class="line">})</span><br><span class="line">  .<span class="hljs-title function_">sort</span>({ <span class="hljs-attr">at</span>: -<span class="hljs-number">1</span> })</span><br><span class="line">  .<span class="hljs-title function_">limit</span>(<span class="hljs-number">20</span>)</span><br><span class="line">  .<span class="hljs-title function_">toArray</span>();</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Always O(<code>limit</code>) per page — independent of how deep into the list you've gone.</p>
<p>For non-unique sort keys (multiple rows with the same <code>at</code>), tiebreak on <code>_id</code>:</p>
<pre><code class="language-js"><figure class="highlight js"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span></pre></td><td class="code"><pre><code class="js"><span class="line">{</span><br><span class="line">  <span class="hljs-attr">$or</span>: [</span><br><span class="line">    { <span class="hljs-attr">at</span>: { <span class="hljs-attr">$lt</span>: last.<span class="hljs-property">at</span> } },</span><br><span class="line">    { <span class="hljs-attr">at</span>: last.<span class="hljs-property">at</span>, <span class="hljs-attr">_id</span>: { <span class="hljs-attr">$lt</span>: last.<span class="hljs-property">_id</span> } }</span><br><span class="line">  ]</span><br><span class="line">}</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>With a compound index on <code>{ at: -1, _id: -1 }</code>, this stays O(limit).</p>
<blockquote>
<p><strong>Trick:</strong> any &quot;Load more&quot; / infinite-scroll UI must use range pagination. Server-side render-time pagination (offset for SEO) tolerates <code>.skip()</code> only up to a few hundred items.</p>
</blockquote>
