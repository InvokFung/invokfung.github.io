<h1 id="Chapter-12-—-Migrations"><a href="#Chapter-12-—-Migrations" class="headerlink" title="Chapter 12 — Migrations"></a>Chapter 12 — Migrations</h1>
<p>Beanie has <code>beanie migrate</code> CLI:</p>
<pre><code class="language-bash"><figure class="highlight bash"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span></pre></td><td class="code"><pre><code class="bash"><span class="line">beanie new-migration --name add_email_index</span><br><span class="line"><span class="hljs-comment"># edit the generated python file with up() / down()</span></span><br><span class="line">beanie migrate -uri <span class="hljs-string">&quot;mongodb://...&quot;</span> -db shop</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>

<h1 id="Chapter-13-—-Common-pitfalls"><a href="#Chapter-13-—-Common-pitfalls" class="headerlink" title="Chapter 13 — Common pitfalls"></a>Chapter 13 — Common pitfalls</h1>
<table>
<thead>
<tr>
<th>Pitfall</th>
<th>Cause</th>
<th>Fix</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>init_beanie</code> called per request</td>
<td>overhead, leak risk</td>
<td>call once in lifespan</td>
</tr>
<tr>
<td>Links populate causing N+1</td>
<td>many docs each <code>fetch_links</code></td>
<td>aggregation <code>$lookup</code></td>
</tr>
<tr>
<td>Projection model field name mismatch</td>
<td>aliases needed</td>
<td>use <code>Field(alias=&quot;_id&quot;)</code></td>
</tr>
<tr>
<td><code>EmailStr</code> install error</td>
<td>missing optional dep</td>
<td><code>pip install pydantic[email]</code></td>
</tr>
<tr>
<td>Auto-index blocks on production startup</td>
<td>huge collection</td>
<td>disable + migrate manually</td>
</tr>
<tr>
<td>Mixed sync + async code</td>
<td>accidental blocking call</td>
<td>wrap with <code>asyncio.to_thread</code></td>
</tr>
<tr>
<td>Old Pydantic v1 examples</td>
<td>breaking changes</td>
<td>always use Pydantic v2</td>
</tr>
<tr>
<td><code>id</code> vs <code>_id</code> confusion</td>
<td>Beanie exposes <code>.id</code> (the str-friendly view)</td>
<td>match docs</td>
</tr>
</tbody>
</table>

<h1 id="Practice-Exercises"><a href="#Practice-Exercises" class="headerlink" title="Practice Exercises"></a>Practice Exercises</h1>
<h2 id="Exercise-1-—-Hello-Beanie-FastAPI"><a href="#Exercise-1-—-Hello-Beanie-FastAPI" class="headerlink" title="Exercise 1 — Hello Beanie + FastAPI"></a>Exercise 1 — Hello Beanie + FastAPI</h2>

<h2 id="Exercise-2-—-Aggregation"><a href="#Exercise-2-—-Aggregation" class="headerlink" title="Exercise 2 — Aggregation"></a>Exercise 2 — Aggregation</h2>

<h2 id="Exercise-3-—-Links"><a href="#Exercise-3-—-Links" class="headerlink" title="Exercise 3 — Links"></a>Exercise 3 — Links</h2>

<h1 id="Cheat-sheet"><a href="#Cheat-sheet" class="headerlink" title="Cheat-sheet"></a>Cheat-sheet</h1>
<table>
<thead>
<tr>
<th>What</th>
<th>How</th>
</tr>
</thead>
<tbody>
<tr>
<td>Install</td>
<td><code>pip install beanie motor fastapi</code></td>
</tr>
<tr>
<td>Init</td>
<td><code>await init_beanie(db, document_models=[...])</code></td>
</tr>
<tr>
<td>Model</td>
<td><code>class X(Document): ...</code></td>
</tr>
<tr>
<td>Index</td>
<td><code>Annotated[T, Indexed(unique=True)]</code> or <code>Settings.indexes</code></td>
</tr>
<tr>
<td>Query</td>
<td><code>Model.find(Model.field == v)</code> (type-safe)</td>
</tr>
<tr>
<td>Insert</td>
<td><code>await m.insert()</code> or <code>Model.insert_one(m)</code></td>
</tr>
<tr>
<td>Update</td>
<td><code>await m.save()</code> (state-managed) or <code>find(...).update({$set: ...})</code></td>
</tr>
<tr>
<td>Delete</td>
<td><code>await m.delete()</code></td>
</tr>
<tr>
<td>Project</td>
<td><code>find().project(SlimModel)</code></td>
</tr>
<tr>
<td>Aggregate</td>
<td><code>Model.aggregate([...], projection_model=Out)</code></td>
</tr>
<tr>
<td>Link</td>
<td><code>Link[User]</code> field; <code>fetch_links=True</code></td>
</tr>
<tr>
<td>Hook</td>
<td><code>@before_event(Insert)</code> / <code>@after_event(...)</code></td>
</tr>
<tr>
<td>Transaction</td>
<td><code>session.start_transaction()</code></td>
</tr>
<tr>
<td>Bulk</td>
<td><code>async with BulkWriter() as bulk: m.insert(bulk_writer=bulk)</code></td>
</tr>
<tr>
<td>FastAPI</td>
<td>lifespan to init/close; Pydantic models for request/response</td>
</tr>
<tr>
<td>Migration</td>
<td><code>beanie new-migration</code> / <code>beanie migrate</code></td>
</tr>
<tr>
<td>Async only</td>
<td>use Motor under the hood</td>
</tr>
