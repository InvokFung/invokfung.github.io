11:Tfa3f,<p>In 2026, most React shops doing 3D use <strong>React Three Fiber (R3F)</strong> instead of vanilla Three.js. R3F is a thin renderer that maps Three.js objects to JSX — every <code>&lt;mesh&gt;</code>, <code>&lt;group&gt;</code>, <code>&lt;perspectiveCamera&gt;</code> you'd write imperatively becomes a React component. Around it has grown the <strong>pmndrs ecosystem</strong>: <strong>drei</strong> (a giant helper library), <strong>@react-three/postprocessing</strong>, <strong>@react-three/rapier</strong>, <strong>@react-three/xr</strong>, plus utilities for state (zustand), animation (framer-motion-3d), and more. This post covers all the essentials so you can port the previous 11 posts' patterns into React.</p>

<p>Series map: 00 Foundations → 01 Geometry &amp; Materials → 02 Cameras &amp; Controls → 03 Lighting &amp; Shadows → 04 Textures &amp; PBR → 05 Asset Pipeline → 06 Animation → 07 Instancing &amp; Batching → 08 Low-End Perf → 09 Shaders → 10 Post-Processing → 11 Physics → <strong>12 R3F + Drei</strong> (this post) → 13 AI 3D.</p>

<h2 id="JSX-naming-convention"><a href="#JSX-naming-convention" class="headerlink" title="JSX naming convention"></a>JSX naming convention</h2>
<p>Lowercase tag = a Three.js class. <code>&lt;mesh&gt;</code> → <code>THREE.Mesh</code>, <code>&lt;boxGeometry&gt;</code> → <code>THREE.BoxGeometry</code>, <code>&lt;directionalLight&gt;</code> → <code>THREE.DirectionalLight</code>.</p>
<p>Property style:</p>
<ul>
<li>Constructor args → <code>args={[...]}</code>.</li>
<li>Object properties (vectors, colours) → flat strings/arrays: <code>position={[0, 1, 0]}</code>.</li>
<li>Sub-properties via dash notation: <code>rotation-x={Math.PI / 2}</code>, <code>material-color=&quot;red&quot;</code>.</li>
</ul>

<h1 id="Chapter-4-—-Drei-the-helper-library"><a href="#Chapter-4-—-Drei-the-helper-library" class="headerlink" title="Chapter 4 — Drei (the helper library)"></a>Chapter 4 — Drei (the helper library)</h1>
<p><code>@react-three/drei</code> ships dozens of components that bundle common patterns. The headline ones:</p>
<h3 id="Controls"><a href="#Controls" class="headerlink" title="Controls"></a>Controls</h3>
<p><code>&lt;OrbitControls /&gt;</code>, <code>&lt;MapControls /&gt;</code>, <code>&lt;TrackballControls /&gt;</code>, <code>&lt;PointerLockControls /&gt;</code>, <code>&lt;FirstPersonControls /&gt;</code>, <code>&lt;FlyControls /&gt;</code>, <code>&lt;TransformControls object={ref} /&gt;</code>, <code>&lt;DragControls items={...} /&gt;</code>.</p>
<h3 id="Cameras-staging"><a href="#Cameras-staging" class="headerlink" title="Cameras / staging"></a>Cameras / staging</h3>
<p><code>&lt;PerspectiveCamera makeDefault /&gt;</code>, <code>&lt;OrthographicCamera makeDefault /&gt;</code>, <code>&lt;Stage /&gt;</code> (auto-light + ground + camera framing for product viewers), <code>&lt;CameraShake /&gt;</code>, <code>&lt;CameraControls /&gt;</code> (better OrbitControls).</p>
<h3 id="Environment-lighting"><a href="#Environment-lighting" class="headerlink" title="Environment / lighting"></a>Environment / lighting</h3>
<p><code>&lt;Environment preset=&quot;sunset&quot; /&gt;</code> — one-line IBL with a built-in HDR.<br>
<code>&lt;Sky distance={450000} sunPosition={[0, 1, 0]} /&gt;</code> — procedural sky.<br>
<code>&lt;Stars /&gt;</code>, <code>&lt;Cloud /&gt;</code>, <code>&lt;Sparkles /&gt;</code>.</p>
<h3 id="Shadows"><a href="#Shadows" class="headerlink" title="Shadows"></a>Shadows</h3>
<p><code>&lt;ContactShadows position={[0, 0, 0]} opacity={0.4} blur={2.5} far={4} /&gt;</code> — soft fake shadow under an object.<br>
<code>&lt;AccumulativeShadows&gt;</code> + <code>&lt;RandomizedLight&gt;</code> — high-quality baked-look shadows.</p>
<h3 id="Loaders"><a href="#Loaders" class="headerlink" title="Loaders"></a>Loaders</h3>
<p><code>useGLTF('/model.glb')</code>, <code>useTexture('/diffuse.jpg')</code>, <code>useFBX</code>, <code>useKTX2</code>, <code>useVideoTexture</code>.</p>
<h3 id="Geometry-Mesh-helpers"><a href="#Geometry-Mesh-helpers" class="headerlink" title="Geometry / Mesh helpers"></a>Geometry / Mesh helpers</h3>
<p><code>&lt;Box /&gt;</code>, <code>&lt;Sphere /&gt;</code>, <code>&lt;Plane /&gt;</code>, <code>&lt;Torus /&gt;</code> (lighter syntax than <code>&lt;mesh&gt;&lt;boxGeometry/&gt;&lt;/mesh&gt;</code>).<br>
<code>&lt;Instances&gt;</code> + <code>&lt;Instance /&gt;</code> — declarative InstancedMesh.<br>
<code>&lt;Merged&gt;</code> — declarative geometry merge.</p>
<h3 id="Text-HTML"><a href="#Text-HTML" class="headerlink" title="Text / HTML"></a>Text / HTML</h3>
<p><code>&lt;Text&gt;Hello&lt;/Text&gt;</code> — high-quality SDF text.<br>
<code>&lt;Html&gt;</code> — DOM nodes attached to a 3D position.<br>
<code>&lt;Center&gt;</code> — centre child object on origin.</p>
<h3 id="Performance"><a href="#Performance" class="headerlink" title="Performance"></a>Performance</h3>
<p><code>&lt;Preload all /&gt;</code> — preload textures + models before fade-in.<br>
<code>&lt;AdaptiveDpr pixelated /&gt;</code> — auto-downgrade pixel ratio under load.<br>
<code>&lt;AdaptiveEvents /&gt;</code> — pause pointer events under load.<br>
<code>&lt;BakeShadows /&gt;</code> — bake shadows on first render then freeze.</p>
<h3 id="Misc"><a href="#Misc" class="headerlink" title="Misc"></a>Misc</h3>
<p><code>&lt;Bounds&gt;</code> + <code>&lt;useBounds()&gt;</code> — zoom to fit children.<br>
<code>&lt;Outlines /&gt;</code> — toon-style outline.<br>
<code>&lt;MeshReflectorMaterial&gt;</code> — reflective floor.<br>
<code>&lt;MeshDistortMaterial&gt;</code> — distorted blob material.</p>

<h1 id="Chapter-8-—-Performance-traps"><a href="#Chapter-8-—-Performance-traps" class="headerlink" title="Chapter 8 — Performance traps"></a>Chapter 8 — Performance traps</h1>
<p>R3F is fast when used correctly; slow when used like React. Key rules:</p>
<ol>
<li><strong>Never call <code>setState</code> in <code>useFrame</code></strong> — causes a React re-render every frame. Mutate refs instead.</li>
<li><strong>Don't create objects inline in render</strong> — <code>&lt;mesh material={new MeshStandardMaterial({...})} /&gt;</code> allocates per render. Memoize with <code>useMemo</code>:<pre><code class="language-jsx"><figure class="highlight jsx"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span></pre></td><td class="code"><pre><code class="jsx"><span class="line"><span class="hljs-keyword">const</span> mat = <span class="hljs-title function_">useMemo</span>(<span class="hljs-function">() =&gt;</span> <span class="hljs-keyword">new</span> <span class="hljs-variable constant_">THREE</span>.<span class="hljs-title class_">MeshStandardMaterial</span>({ <span class="hljs-attr">color</span>: <span class="hljs-string">&#x27;red&#x27;</span> }), []);</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
</li>
<li><strong>Use Drei's <code>&lt;Instances&gt;</code></strong> for many similar objects:<pre><code class="language-jsx"><figure class="highlight jsx"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span></pre></td><td class="code"><pre><code class="jsx"><span class="line">&lt;<span class="hljs-title class_">Instances</span> limit={<span class="hljs-number">1000</span>} range={<span class="hljs-number">1000</span>}&gt;</span><br><span class="line">  <span class="language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">boxGeometry</span> /&gt;</span></span></span><br><span class="line">  <span class="language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">meshStandardMaterial</span> /&gt;</span></span></span><br><span class="line">  {data.<span class="hljs-title function_">map</span>(<span class="hljs-function">(<span class="hljs-params">d, i</span>) =&gt;</span> <span class="language-xml"><span class="hljs-tag">&lt;<span class="hljs-name">Instance</span> <span class="hljs-attr">key</span>=<span class="hljs-string">{i}</span> <span class="hljs-attr">position</span>=<span class="hljs-string">{d.pos}</span> <span class="hljs-attr">color</span>=<span class="hljs-string">{d.color}</span> /&gt;</span></span>)}</span><br><span class="line">&lt;/<span class="hljs-title class_">Instances</span>&gt;</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>

<h1 id="Practice-Exercises"><a href="#Practice-Exercises" class="headerlink" title="Practice Exercises"></a>Practice Exercises</h1>
<h2 id="Exercise-1-—-Rebuild-Post-00-cube-in-R3F"><a href="#Exercise-1-—-Rebuild-Post-00-cube-in-R3F" class="headerlink" title="Exercise 1 — Rebuild Post 00 cube in R3F"></a>Exercise 1 — Rebuild Post 00 cube in R3F</h2>
<p>A spinning cube in <code>&lt;Canvas&gt;</code> with OrbitControls + Environment.</p>
<h2 id="Exercise-2-—-Drei-tour"><a href="#Exercise-2-—-Drei-tour" class="headerlink" title="Exercise 2 — Drei tour"></a>Exercise 2 — Drei tour</h2>

<h2 id="Exercise-3-—-Drei"><a href="#Exercise-3-—-Drei" class="headerlink" title="Exercise 3 — Drei &lt;Instances>"></a>Exercise 3 — Drei <code>&lt;Instances&gt;</code></h2>
<p>10,000 small cubes scattered randomly using <code>&lt;Instances&gt;</code> + <code>&lt;Instance&gt;</code>. Confirm draw calls stay low via <code>&lt;Perf&gt;</code>.</p>
<h2 id="Exercise-4-—-Physics"><a href="#Exercise-4-—-Physics" class="headerlink" title="Exercise 4 — Physics"></a>Exercise 4 — Physics</h2>
<p>Wrap a stack of 20 cubes in <code>&lt;RigidBody&gt;</code> over a fixed floor with <code>&lt;Physics&gt;</code>. Click a cube → apply an upward impulse (via the body ref).</p>
<h2 id="Exercise-5-—-Post-processing"><a href="#Exercise-5-—-Post-processing" class="headerlink" title="Exercise 5 — Post-processing"></a>Exercise 5 — Post-processing</h2>
<p>Add <code>&lt;EffectComposer&gt;</code> with Bloom + Vignette + SMAA. Compare visually with/without.</p>
<h2 id="Exercise-6-—-Optimise-with-the-traps"><a href="#Exercise-6-—-Optimise-with-the-traps" class="headerlink" title="Exercise 6 — Optimise with the traps"></a>Exercise 6 — Optimise with the traps</h2>
<p>Build a scene that <strong>violates</strong> trap 1-3 (setState in useFrame, inline materials, no instancing). Measure FPS in Perf. Refactor to fix all three. Measure again.</p>
