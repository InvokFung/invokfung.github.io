Three.js Course — 06 · Animation — Mixer, Clips, Morph Targets, Skinned Meshes

Created2026-05-18|Updated2026-05-18|Programming > 3D
|Post View:

Three.js animates in three main ways: per-frame property updates inside the render loop, AnimationMixer playing back authored clips (from glTF, FBX, etc.), and morph targets / skinned meshes for character rigs. This post covers all three plus the tween libraries (@tweenjs/tween.js, GSAP) that make property animation pleasant, frame timing rules (always use delta time, never frame count), and the standard mixer recipes — cross-fade, additive blends, time-scale, weights.

Learning Outcome

  • Animate properties safely with requestAnimationFrame + delta time.
  • Play glTF animation clips using AnimationMixer.
  • Cross-fade, blend, weight multiple clips.
  • Use morph targets (blend shapes) for facial / shape interpolation.
  • Use skinned meshes with bones (SkeletonHelper).
  • Use @tweenjs/tween.js or GSAP for declarative property animation.

Chapter 1 — Delta-time fundamentals

The animation loop runs at the browser's frame rate — usually 60 Hz, sometimes 120 Hz on modern displays, sometimes 30 Hz on a struggling phone. Animation logic must be frame-rate independent.

Never write cube.rotation.y += 0.01 — that's "0.01 radians per frame", which means twice as fast at 120 Hz and half as fast at 30 Hz. Always multiply by dt.

Chapter 3 — Tween libraries

For declarative "go from A to B over T seconds with easing", a tween library is cleaner:

GSAP is the heavyweight alternative — more features (timelines, scroll triggers, plugins) but a paid Club license for some features. For Three.js scenes, @tweenjs/tween.js is usually enough.

Common easings

Linear, Quadratic.In/Out/InOut, Cubic.*, Quartic.*, Quintic.*, Sinusoidal.*, Exponential.*, Circular.*, Elastic.*, Back.*, Bounce.*.

Quadratic.InOut (s-curve, slow ends, fast middle) is the safe default for UI motion. Cubic.Out (fast start, slow end) is good for "object arrives at destination".

Chapter 6 — Morph targets (blend shapes)

A morph target is an alternate version of a mesh — same vertex count, different positions. Interpolating between morphs animates facial expressions, mouth shapes, body deformations.

A glTF with morph targets exposes mesh.morphTargetInfluences (array of 0-1 weights) and mesh.morphTargetDictionary (name → index).

Animate manually or via AnimationMixer (glTF animations target morph influences automatically when authored to).

Costs

Morph targets multiply geometry size by (1 + N) where N = number of targets. A 10k-vertex mesh with 20 expressions = 210k vertices' worth of data. Manageable for a single character; not for crowds.

Use cases

  • Lip-sync for talking characters (a basic phoneme set is 8-12 shapes).
  • Body shape sliders ("character creator").
  • Procedural deformation (wave on a flag — though shaders do this better).

Chapter 7 — Skinned meshes (bones / armature)

A skinned mesh deforms based on a skeleton (a hierarchy of bones). Each vertex is weighted against up to 4 bones; transforming bones deforms the surface.

glTF embeds skin + skeleton + animation clips together; GLTFLoader reconstructs them as THREE.SkinnedMesh + THREE.Skeleton.

Skinned animation is what makes characters walk, fight, dance. Authoring happens in Blender / Maya / Houdini; Three.js mostly plays back.

Chapter 9 — Animation libraries beyond the mixer

Library Use
@tweenjs/tween.js declarative tweens; cheap, simple
gsap feature-rich tweens, timelines
motion (formerly Framer Motion 3D) physics-spring animations, declarative
theatre.js timeline-based, in-browser animation editor
popmotion low-level animation primitives

For complex sequenced animation (cutscenes), theatre.js is impressive — a real animation editor that runs inside your page.

Chapter 10 — Performance tips

  • One mixer per character. Many characters = many mixers + one shared scene; cheap.
  • Cache clipAction — calling it repeatedly with the same clip returns the same action but allocates lookups.
  • Pause off-screen characters — mixer.timeScale = 0 while not in frustum.
  • Skip animations far away — at distance, snap to a single pose; the player won't notice.
  • For huge crowds, use InstancedMesh (Post 07) with GPU-driven animation via a vertex shader sampling a baked animation texture. Three.js doesn't ship this but the pattern is common (see BatchedAnimation / GPU skinning libraries).
  • Cull unused bones — characters often ship with bones for hair / cloth that aren't used; remove in the exporter.

Practice Exercises

Exercise 1 — Delta-time sanity

Rotate a cube with 0.5 * dt. Toggle setTimeout(() => fakeSlow(), ...) to make frames slow. Confirm the cube keeps the same wall-clock rotation speed.

Exercise 2 — Tween a position

Tween a cube from (0, 0, 0) to (5, 2, 0) over 2 s with Cubic.Out easing. On complete, tween back.

Exercise 3 — Play a glTF animation

Load a Mixamo character (free, mixamo.com). Play its "Idle" clip via AnimationMixer.

Exercise 4 — Cross-fade

Same character, two clips: Idle + Run. Press W to start crossFadeTo(run), release to fade back. Use warp: true.

Exercise 5 — Morph targets

Load any model with morphs (Khronos RobotExpressive is good). Drive the morph weights from sliders (HTML range inputs). Confirm shapes blend.

Exercise 6 — Skeleton helper

Add SkeletonHelper to your character. Watch bones move while the animation plays.

Cheat-sheet

What How
Clock const clock = new THREE.Clock(); const dt = clock.getDelta()
Frame-rate independent always multiply by dt
Tween library @tweenjs/tween.js — call TWEEN.update() each frame
Common easing Cubic.Out, Quadratic.InOut
Play glTF clip mixer = new THREE.AnimationMixer(scene); mixer.clipAction(clip).play()
Update mixer mixer.update(dt)
Find clip by name THREE.AnimationClip.findByName(clips, 'Walk')
Loop action.setLoop(THREE.LoopOnce/Repeat/PingPong)
Hold last frame action.clampWhenFinished = true
Cross-fade from.crossFadeTo(to, duration, warp)
Blend weights set action.weight on both
Morph target mesh.morphTargetInfluences[i] = weight
Skinned helpers new THREE.SkeletonHelper(mesh) for debug
IK CCDIKSolver from addons
Retarget animation SkeletonUtils.retargetClip
Big crowds GPU-skinned InstancedMesh (Post 07 + custom shader)
