<h1 id="Chapter-1-—-glTF-in-one-paragraph"><a href="#Chapter-1-—-glTF-in-one-paragraph" class="headerlink" title="Chapter 1 — glTF in one paragraph"></a>Chapter 1 — glTF in one paragraph</h1>
<p>glTF 2.0 (Khronos, 2017) is the standard 3D delivery format for the web. It's a JSON file (<code>*.gltf</code>) describing scene graph + materials, plus binary buffers for geometry/textures. A <code>.glb</code> is the same data packed into a single binary file. Materials follow the <strong>metallic-roughness PBR</strong> model. Extensions add advanced features (<code>KHR_draco_mesh_compression</code>, <code>KHR_texture_basisu</code>, <code>EXT_meshopt_compression</code>, <code>KHR_materials_clearcoat</code>, etc.).</p>
<p>Why glTF over alternatives:</p>
<ul>
<li>Designed for web/real-time (compact, GPU-friendly buffers).</li>
<li>Comprehensive material support that maps onto Three.js <code>MeshStandardMaterial</code> / <code>MeshPhysicalMaterial</code> exactly.</li>
<li>Animations, skins, morph targets all standardised.</li>
<li>First-class exporters from every major DCC (Blender, Maya, 3ds Max, Houdini, Cinema 4D, Substance, ZBrush).</li>
</ul>
<p><code>.glb</code> (binary, single file) is the right default unless you have a specific reason to split.</p>

<h1 id="Practice-Exercises"><a href="#Practice-Exercises" class="headerlink" title="Practice Exercises"></a>Practice Exercises</h1>
<h2 id="Exercise-1-—-Load-add"><a href="#Exercise-1-—-Load-add" class="headerlink" title="Exercise 1 — Load + add"></a>Exercise 1 — Load + add</h2>
<p>Download <code>DamagedHelmet.glb</code> from Khronos sample assets. Load with GLTFLoader. Add lighting + an HDR environment. Should look photorealistic.</p>
<h2 id="Exercise-2-—-Wire-shadows-on-a-loaded-model"><a href="#Exercise-2-—-Wire-shadows-on-a-loaded-model" class="headerlink" title="Exercise 2 — Wire shadows on a loaded model"></a>Exercise 2 — Wire shadows on a loaded model</h2>
<p>After load, traverse and <code>castShadow / receiveShadow = true</code> on every mesh. Add a ground plane that receives. Verify shadows render.</p>
<h2 id="Exercise-3-—-Optimise-with-gltf-transform"><a href="#Exercise-3-—-Optimise-with-gltf-transform" class="headerlink" title="Exercise 3 — Optimise with gltf-transform"></a>Exercise 3 — Optimise with gltf-transform</h2>
<p>Take a 5+ MB glTF (search Sketchfab). Run <code>gltf-transform inspect</code>. Apply <code>gltf-transform optimize</code>. Compare sizes + load times. Confirm visually identical.</p>
<h2 id="Exercise-4-—-All-three-compressions"><a href="#Exercise-4-—-All-three-compressions" class="headerlink" title="Exercise 4 — All three compressions"></a>Exercise 4 — All three compressions</h2>
<p>Apply Draco (or Meshopt) + KTX2 (UASTC for normal map, ETC1S for colour). Configure all three loaders in Three.js. Confirm <code>renderer.info.memory.textures</code> is way down.</p>
<h2 id="Exercise-5-—-Lazy-decoders"><a href="#Exercise-5-—-Lazy-decoders" class="headerlink" title="Exercise 5 — Lazy decoders"></a>Exercise 5 — Lazy decoders</h2>
<p>Refactor your loader setup so DRACOLoader and KTX2Loader are dynamically imported. Confirm the initial bundle (<code>npm run build</code>) shrinks substantially.</p>
