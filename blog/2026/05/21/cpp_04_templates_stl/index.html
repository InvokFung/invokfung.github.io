C++ Course — 04 · Templates and the Standard Library (STL)

Created2026-05-21|Updated2026-05-21|Programming
|Post View:

The Standard Template Library — vectors, maps, strings, algorithms — is C++'s killer app. Master it and you can replace 80% of hand-written loops with <algorithm> calls, get tested-by-millions code for free, and gain measurable performance from compiler-optimised templates. This post covers function templates, class templates, and the most-used STL containers + algorithms.

Series map: 00 Setup → 01 Syntax & Types → 02 Pointers & Memory → 03 Classes & OOP → 04 Templates & STL (this post) → 05 Modern C++ → (future).

Learning Outcome

  • Define and call function templates and class templates.
  • Use the main STL containers: vector, array, deque, list, map, unordered_map, set, string.
  • Use iterators to traverse and mutate containers.
  • Use <algorithm>: sort, find, count, transform, for_each, accumulate.
  • Understand iterator categories (forward / bidirectional / random-access).
  • Pick the right container based on access patterns.

Chapter 3 — std::vector (the workhorse)

Internally a dynamic array. Amortised O(1) push_back, O(1) random access, O(n) insert/erase in middle.

Trick: if you know the final size, v.reserve(N) ahead of time to prevent reallocations.

Chapter 4 — Other key containers

Container Underlying Access Insert/erase When to use
vector<T> dynamic array O(1) random O(1) at end, O(n) middle default container
array<T, N> fixed array O(1) n/a size known at compile time
deque<T> segmented array O(1) random O(1) both ends queue-like patterns
list<T> doubly linked O(n) O(1) anywhere if iterator known rarely useful
map<K, V> balanced BST O(log n) O(log n) keys ordered
unordered_map<K, V> hash table O(1) avg O(1) avg keys NOT ordered
set<T> balanced BST O(log n) O(log n) sorted unique values
unordered_set<T> hash table O(1) avg O(1) avg fast membership
string dynamic array of chars O(1) O(n) middle text

std::unordered_map (hash table — usually faster)

Default to unordered_map unless you need keys in sorted order.

Chapter 5 — Iterators

Every STL container has begin() and end(). end() is one past the last element.

Categories (most→least powerful):

  • Random-access: vector, array, deque. Supports it + n, it[i], it1 - it2.
  • Bidirectional: list, map, set. Supports ++it, --it.
  • Forward: forward-only.
  • Input / Output: single-pass only (e.g., reading from a stream).

Range-based for is iterators under the hood

Use range-for. The classic iterator loop is for cases where you need the iterator itself.

Chapter 7 — The <algorithm> header

The single most underused header. Replaces hand-written loops with descriptive, optimised one-liners.

Trick: before writing a loop on a container, search cppreference's algorithm list — there's almost always a standard one.

Lambdas (recap)

[ ] is the capture list. [=] captures everything by value, [&] by reference. Be explicit when possible.

Chapter 8 — C++20 ranges (brief)

C++20 introduced ranges — algorithms that take the container directly + composable views.

Cleaner than iterator-pair style. Worth learning if your compiler supports C++20.

Chapter 9 — Choosing a container

Decision tree:

  1. Default = std::vector. Right answer ~80% of the time.
  2. Need keys → values? std::unordered_map (or map if you need sorted iteration).
  3. Need unique-set membership? std::unordered_set (or set if sorted).
  4. Inserting at both ends? std::deque.
  5. Fixed-size? std::array (zero overhead, size in the type).
  6. Lots of middle insertions and you have iterators? std::list — but profile first; it's often slower than vector due to cache effects.

Rule: benchmark before choosing anything other than vector for performance reasons. The cache wins almost every fight.

Function template template<typename T> T f(T a, T b)
Class template template<typename T> class Box { T v; };

Map (sorted) std::map<K, V>

String std::string
Iterator auto it = v.begin();
End iterator one past last
Algorithm sort std::sort(v.begin(), v.end())

Lambda [capture](args){ body }
