<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span></pre></td><td class="code"><pre><code class="python"><span class="line"><span class="hljs-comment"># WITHOUT with — must remember to close</span></span><br><span class="line">f = <span class="hljs-built_in">open</span>(<span class="hljs-string">&quot;x.txt&quot;</span>)</span><br><span class="line">data = f.read()</span><br><span class="line">f.close()         <span class="hljs-comment"># easy to forget; missed on exceptions</span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-comment"># WITH — auto-closes even on exception</span></span><br><span class="line"><span class="hljs-keyword">with</span> <span class="hljs-built_in">open</span>(<span class="hljs-string">&quot;x.txt&quot;</span>) <span class="hljs-keyword">as</span> f:</span><br><span class="line">    data = f.read()</span><br><span class="line"><span class="hljs-comment"># closed here, no matter what</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>The <code>with</code> block is a <strong>context manager</strong>: the file is guaranteed to be closed when the block exits. Always use it for files.</p>
<blockquote>
<p><em>Where I got stuck:</em> an early script of mine kept thousands of files open until the OS refused new ones. The fix was 5 characters: wrap the <code>open(...)</code> in a <code>with</code>. I never forgot again.</p>
</blockquote>

<h1 id="Chapter-5-—-Exceptions-what-they-are"><a href="#Chapter-5-—-Exceptions-what-they-are" class="headerlink" title="Chapter 5 — Exceptions: what they are"></a>Chapter 5 — Exceptions: what they are</h1>
<p>An <strong>exception</strong> is an error event that interrupts normal flow. Python signals problems by raising exceptions.</p>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span><br><span class="line">11</span><br><span class="line">12</span><br><span class="line">13</span></pre></td><td class="code"><pre><code class="python"><span class="line"><span class="hljs-number">1</span> / <span class="hljs-number">0</span></span><br><span class="line"><span class="hljs-comment"># ZeroDivisionError: division by zero</span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-built_in">int</span>(<span class="hljs-string">&quot;abc&quot;</span>)</span><br><span class="line"><span class="hljs-comment"># ValueError: invalid literal for int() with base 10: &#x27;abc&#x27;</span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-built_in">open</span>(<span class="hljs-string">&quot;missing.txt&quot;</span>)</span><br><span class="line"><span class="hljs-comment"># FileNotFoundError: [Errno 2] No such file or directory: &#x27;missing.txt&#x27;</span></span><br><span class="line"> </span><br><span class="line">d = {<span class="hljs-string">&quot;a&quot;</span>: <span class="hljs-number">1</span>}</span><br><span class="line">d[<span class="hljs-string">&quot;b&quot;</span>]</span><br><span class="line"><span class="hljs-comment"># KeyError: &#x27;b&#x27;</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>If unhandled, the exception propagates up the call stack and (eventually) crashes the program with a traceback.</p>
<hr>

<p>Parts:</p>
<ul>
<li><code>try:</code> — code that might fail.</li>
<li><code>except XError:</code> — handle a specific exception.</li>

<li><code>finally:</code> — always runs (cleanup).</li>
</ul>
<h2 id="Catching-too-much"><a href="#Catching-too-much" class="headerlink" title="Catching too much"></a>Catching too much</h2>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span></pre></td><td class="code"><pre><code class="python"><span class="line"><span class="hljs-keyword">try</span>:</span><br><span class="line">    do_stuff()</span><br><span class="line"><span class="hljs-keyword">except</span>:                <span class="hljs-comment"># NEVER do this</span></span><br><span class="line">    <span class="hljs-keyword">pass</span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-keyword">try</span>:</span><br><span class="line">    do_stuff()</span><br><span class="line"><span class="hljs-keyword">except</span> Exception:      <span class="hljs-comment"># better, but still wide</span></span><br><span class="line">    log_error()</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>A bare <code>except:</code> catches <strong>everything</strong>, including <code>KeyboardInterrupt</code> (Ctrl+C) and <code>SystemExit</code>. You will eventually trap a signal you wanted to receive.</p>

<p><em>Rule of thumb:</em> catch the <strong>narrowest</strong> exception type that addresses the failure. If you don't know the type, run the code, see the traceback, then catch that type.</p>
</blockquote>

start</span><br><span class="line">        <span class="hljs-built_in">print</span>(<span class="hljs-string">f&quot;<span class="hljs-subst">{label}</span>: <span class="hljs-subst">{elapsed:<span class="hljs-number">.3</span>f}</span>s&quot;</span>)</span><br><span class="line"> </span><br><span class="line"><span class="hljs-keyword">with</span> timer(<span class="hljs-string">&quot;load&quot;</span>):</span><br><span class="line">    data = Path(<span class="hljs-string">&quot;big.csv&quot;</span>).read_text()</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
