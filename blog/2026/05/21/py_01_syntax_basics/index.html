Python Course — 01 · Syntax, Types, and Control Flow

Created2026-05-21|Updated2026-05-21|Programming
|Post View:

This post covers the core syntax every Python program uses: variables, primitive types, operators, conditionals, and loops. Python's defining visual feature — meaningful indentation — is introduced and explained. By the end, you can write any control-flow logic you'd expect from a beginner book.

Series map: 00 Setup → 01 Syntax (this post) → 02 Data Structures → 03 Functions & Modules → 04 OOP → 05 Files & Exceptions → (future).

Learning Outcome

  • Declare variables and understand dynamic typing.
  • Use the six core primitive types: int, float, bool, str, None, bytes.
  • Use arithmetic, comparison, logical, and assignment operators.
  • Write if/elif/else, for, and while blocks.
  • Understand indentation as syntax (not decoration).
  • Use break, continue, and else on loops.

Chapter 1 — Variables and dynamic typing

Terminology

  • Variable — a name bound to a value.
  • Dynamic typing — variable types are checked at runtime, not declaration time.
  • Type hint — optional annotation (x: int = 5) — ignored at runtime, used by tools.
  • Mutable / immutable — whether a value can be changed in place.

Type hints (optional but recommended)

These are hints — Python ignores them at runtime. Tools like mypy, pyright, and your IDE use them for static analysis. Use them in real code; skip them in throwaway scripts.

Trick: if you print(type(x)), Python tells you the runtime type. Great for debugging "wait, why is this a string?" surprises.

Chapter 4 — Indentation is syntax

This is the rule that shocks beginners coming from C-family languages. Python uses indentation (not {} or begin/end) to define blocks.

Rules:

  • All lines in the same block must have exactly the same indentation.
  • Standard is 4 spaces per level (PEP 8).
  • Never mix tabs and spaces. Most editors auto-convert.
  • A colon : introduces a new block (after if, for, while, def, class, try, etc.).

Where I got stuck: I once spent 30 minutes debugging a script that "just didn't run the loop". The culprit: a tab character on one line where the rest used spaces. Python silently disagrees about whether they're equal. Modern editors highlight whitespace; turn it on.

Chapter 6 — Loops

for loop

Python's for always iterates over an iterable (sequence, generator, etc.). It is not the C-style for(i=0; i<10; i++).

break, continue, loop-else

  • break — exit the innermost loop.
  • continue — skip to next iteration.
  • else after for/while — runs only if the loop finished without break.

The else runs only when the inner for completes without finding a divisor → the number is prime. This is a Python-unique idiom worth memorising.
