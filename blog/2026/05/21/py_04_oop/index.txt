11:Tb02a,<p>Object-oriented programming organises code around <strong>data + the operations on it</strong>. Python's OOP is lightweight (no <code>private</code> keyword, no compile-time type checking) yet flexible enough for everything from 10-line scripts to massive frameworks. This post covers classes, instances, inheritance, dunder methods, properties, and the modern <code>@dataclass</code> decorator.</p>

<h1 id="Learning-Outcome"><a href="#Learning-Outcome" class="headerlink" title="Learning Outcome"></a>Learning Outcome</h1>
<ul>
<li>Define classes with <code>__init__</code>, methods, and instance attributes.</li>

<h1 id="Chapter-1-—-Class-basics"><a href="#Chapter-1-—-Class-basics" class="headerlink" title="Chapter 1 — Class basics"></a>Chapter 1 — Class basics</h1>
<h2 id="Terminology"><a href="#Terminology" class="headerlink" title="Terminology"></a>Terminology</h2>
<ul>
<li><strong>Class</strong> — a template that defines attributes and methods.</li>
<li><strong>Instance</strong> — an object created from a class.</li>
<li><strong>Attribute</strong> — data stored on an instance (or class).</li>
<li><strong>Method</strong> — a function defined inside a class.</li>
<li><strong><code>self</code></strong> — the conventional first parameter of every instance method, automatically bound to the instance.</li>
</ul>

<p>That's it. No boilerplate.</p>
<h2 id="Options"><a href="#Options" class="headerlink" title="Options"></a>Options</h2>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span></pre></td><td class="code"><pre><code class="python"><span class="line"><span class="hljs-meta">@dataclass(<span class="hljs-params">frozen=<span class="hljs-literal">True</span>, slots=<span class="hljs-literal">True</span></span>)</span></span><br><span class="line"><span class="hljs-keyword">class</span> <span class="hljs-title class_">Coord</span>:</span><br><span class="line">    x: <span class="hljs-built_in">int</span></span><br><span class="line">    y: <span class="hljs-built_in">int</span></span><br><span class="line"> </span><br><span class="line">c = Coord(<span class="hljs-number">1</span>, <span class="hljs-number">2</span>)</span><br><span class="line">c.x = <span class="hljs-number">5</span>   <span class="hljs-comment"># AttributeError — frozen=True makes it immutable</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<ul>
<li><code>frozen=True</code> — immutable (hashable, usable as dict keys).</li>
<li><code>slots=True</code> (3.10+) — faster + uses less memory.</li>
<li><code>order=True</code> — generates <code>&lt;</code>, <code>&lt;=</code>, <code>&gt;</code>, <code>&gt;=</code>.</li>
</ul>
<h2 id="Default-values"><a href="#Default-values" class="headerlink" title="Default values"></a>Default values</h2>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span></pre></td><td class="code"><pre><code class="python"><span class="line"><span class="hljs-keyword">from</span> dataclasses <span class="hljs-keyword">import</span> dataclass, field</span><br><span class="line"> </span><br><span class="line"><span class="hljs-meta">@dataclass</span></span><br><span class="line"><span class="hljs-keyword">class</span> <span class="hljs-title class_">User</span>:</span><br><span class="line">    name: <span class="hljs-built_in">str</span></span><br><span class="line">    tags: <span class="hljs-built_in">list</span> = field(default_factory=<span class="hljs-built_in">list</span>)   <span class="hljs-comment"># mutable default — must use factory</span></span><br><span class="line">    score: <span class="hljs-built_in">int</span> = <span class="hljs-number">0</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<blockquote>
<p><em>Trick:</em> <code>@dataclass</code> should be your <strong>default</strong> class style. Reach for plain <code>class</code> only when you need custom <code>__init__</code> logic.</p>
</blockquote>

<h1 id="Chapter-8-—-Composition-over-inheritance"><a href="#Chapter-8-—-Composition-over-inheritance" class="headerlink" title="Chapter 8 — Composition over inheritance"></a>Chapter 8 — Composition over inheritance</h1>
<p>A common OOP design rule: when you can use <em>containment</em> instead of inheritance, do.</p>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span><br><span class="line">11</span><br><span class="line">12</span><br><span class="line">13</span><br><span class="line">14</span><br><span class="line">15</span></pre></td><td class="code"><pre><code class="python"><span class="line"><span class="hljs-comment"># Inheritance approach (often wrong)</span></span><br><span class="line"><span class="hljs-keyword">class</span> <span class="hljs-title class_">Engine</span>:</span><br><span class="line">    <span class="hljs-keyword">def</span> <span class="hljs-title function_">start</span>(<span class="hljs-params">self</span>): <span class="hljs-built_in">print</span>(<span class="hljs-string">&quot;vroom&quot;</span>)</span><br><span class="line"> </span><br><span class="line"><span class="hljs-keyword">class</span> <span class="hljs-title class_">Car</span>(<span class="hljs-title class_ inherited__">Engine</span>):       <span class="hljs-comment"># &quot;Car is an Engine&quot;? — no, a Car *has* an Engine</span></span><br><span class="line">    <span class="hljs-keyword">pass</span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-comment"># Composition (better)</span></span><br><span class="line"><span class="hljs-keyword">class</span> <span class="hljs-title class_">Car</span>:</span><br><span class="line">    <span class="hljs-keyword">def</span> <span class="hljs-title function_">__init__</span>(<span class="hljs-params">self</span>):</span><br><span class="line">        <span class="hljs-variable language_">self</span>.engine = Engine()</span><br><span class="line"> </span><br><span class="line">    <span class="hljs-keyword">def</span> <span class="hljs-title function_">start</span>(<span class="hljs-params">self</span>):</span><br><span class="line">        <span class="hljs-variable language_">self</span>.engine.start()</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Inheritance creates a tight, often-unwanted coupling. Composition keeps pieces interchangeable.</p>
