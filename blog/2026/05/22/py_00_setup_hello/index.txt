<h2 id="Terminology"><a href="#Terminology" class="headerlink" title="Terminology"></a>Terminology</h2>
<ul>
<li><strong>Interpreter</strong> — the program (<code>python</code> or <code>python3</code>) that reads and executes Python code line by line.</li>
<li><strong>REPL</strong> — Read-Eval-Print Loop: an interactive shell where each line you type is executed immediately.</li>
<li><strong>Script</strong> — a <code>.py</code> file containing Python code, run with <code>python script.py</code>.</li>
<li><strong>Module</strong> — a <code>.py</code> file imported by another file.</li>
<li><strong>Package</strong> — a directory of modules with an <code>__init__.py</code>.</li>
<li><strong>PEP</strong> — Python Enhancement Proposal. The language's design documents. <strong>PEP 8</strong> is the style guide everyone follows.</li>
</ul>
<h2 id="Python-vs-other-languages-one-paragraph"><a href="#Python-vs-other-languages-one-paragraph" class="headerlink" title="Python vs other languages (one paragraph)"></a>Python vs other languages (one paragraph)</h2>
<p>Python is <em>interpreted</em> (no compile step), <em>dynamically typed</em> (you don't declare types, though you can hint them), and <em>garbage-collected</em> (no manual memory management). The trade-off vs C++/Rust: Python is 10–100× slower in raw computation but 5–10× faster to write. For data work, web back-ends, scripts, automation, and ML, the slowness almost never matters.</p>
<blockquote>
<p><em>Trick:</em> don't compare languages by speed in isolation. Compare by <em>time-to-correct-program</em>. Python wins almost every &quot;write something useful by Friday&quot; race.</p>
</blockquote>

<h1 id="Chapter-3-—-The-REPL"><a href="#Chapter-3-—-The-REPL" class="headerlink" title="Chapter 3 — The REPL"></a>Chapter 3 — The REPL</h1>
<p>Open a terminal and type <code>python</code> (or <code>python3</code> on macOS/Linux):</p>
<pre><code class="language-text"><figure class="highlight text"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span></pre></td><td class="code"><pre><code class="text"><span class="line">$ python</span><br><span class="line">Python 3.12.4 (main, ...) on darwin</span><br><span class="line">Type &quot;help&quot;, &quot;copyright&quot;, &quot;credits&quot; or &quot;license&quot; for more information.</span><br><span class="line">&gt;&gt;&gt; 1 + 1</span><br><span class="line">2</span><br><span class="line">&gt;&gt;&gt; name = &quot;Ada&quot;</span><br><span class="line">&gt;&gt;&gt; f&quot;Hello, {name}&quot;</span><br><span class="line">&#x27;Hello, Ada&#x27;</span><br><span class="line">&gt;&gt;&gt; exit()</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>The <code>&gt;&gt;&gt;</code> prompt waits for input; each expression's result is printed automatically. Indented blocks use <code>...</code> as the continuation prompt:</p>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span></pre></td><td class="code"><pre><code class="python"><span class="line"><span class="hljs-meta">&gt;&gt;&gt; </span><span class="hljs-keyword">for</span> i <span class="hljs-keyword">in</span> <span class="hljs-built_in">range</span>(<span class="hljs-number">3</span>):</span><br><span class="line"><span class="hljs-meta">... </span>    <span class="hljs-built_in">print</span>(i)</span><br><span class="line">...</span><br><span class="line"><span class="hljs-number">0</span></span><br><span class="line"><span class="hljs-number">1</span></span><br><span class="line"><span class="hljs-number">2</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>The REPL is your <strong>calculator + sandbox</strong>. Use it to test snippets, explore stdlib, check syntax.</p>
<blockquote>
<p><em>Trick:</em> the underscore <code>_</code> in the REPL holds the last result. <code>2 + 2</code> then <code>_ * 10</code> gives <code>40</code>. Useful for chained quick math.</p>
</blockquote>
<hr>
<h1 id="Chapter-4-—-Your-first-script"><a href="#Chapter-4-—-Your-first-script" class="headerlink" title="Chapter 4 — Your first script"></a>Chapter 4 — Your first script</h1>
<p>Create a file <code>hello.py</code>:</p>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span></pre></td><td class="code"><pre><code class="python"><span class="line"><span class="hljs-comment"># hello.py</span></span><br><span class="line"><span class="hljs-built_in">print</span>(<span class="hljs-string">&quot;Hello, World!&quot;</span>)</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Run it:</p>
<pre><code class="language-bash"><figure class="highlight bash"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span></pre></td><td class="code"><pre><code class="bash"><span class="line">python hello.py</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Output: <code>Hello, World!</code></p>
<h2 id="Interactive-version"><a href="#Interactive-version" class="headerlink" title="Interactive version"></a>Interactive version</h2>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span></pre></td><td class="code"><pre><code class="python"><span class="line"><span class="hljs-comment"># greet.py</span></span><br><span class="line">name = <span class="hljs-built_in">input</span>(<span class="hljs-string">&quot;What is your name? &quot;</span>)</span><br><span class="line"><span class="hljs-built_in">print</span>(<span class="hljs-string">f&quot;Hi, <span class="hljs-subst">{name}</span>!&quot;</span>)</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Run, type your name, get greeted. Two concepts introduced:</p>
<ul>
<li><code>input(prompt)</code> reads a line of text from the user.</li>
<li><code>f&quot;...&quot;</code> is an <strong>f-string</strong>: any <code>{expression}</code> inside is evaluated and substituted.</li>
</ul>
<h2 id="Shebang-Linux-macOS-only"><a href="#Shebang-Linux-macOS-only" class="headerlink" title="Shebang (Linux / macOS only)"></a>Shebang (Linux / macOS only)</h2>
<p>Add <code>#!/usr/bin/env python3</code> as the first line of a script, then <code>chmod +x hello.py</code>, and run with <code>./hello.py</code>. The OS reads the shebang to know which interpreter to use.</p>
<hr>
<h1 id="Chapter-5-—-Virtual-environments-venv"><a href="#Chapter-5-—-Virtual-environments-venv" class="headerlink" title="Chapter 5 — Virtual environments (venv)"></a>Chapter 5 — Virtual environments (venv)</h1>
<p>Each Python project should have its own isolated package list. This prevents &quot;global pip install&quot; chaos.</p>
<pre><code class="language-bash"><figure class="highlight bash"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span><br><span class="line">11</span><br><span class="line">12</span><br><span class="line">13</span><br><span class="line">14</span><br><span class="line">15</span><br><span class="line">16</span><br><span class="line">17</span></pre></td><td class="code"><pre><code class="bash"><span class="line"><span class="hljs-comment"># create a venv in a folder named .venv</span></span><br><span class="line">python -m venv .venv</span><br><span class="line"> </span><br><span class="line"><span class="hljs-comment"># activate it</span></span><br><span class="line"><span class="hljs-comment"># Windows (PowerShell):</span></span><br><span class="line">.venv\Scripts\Activate.ps1</span><br><span class="line"><span class="hljs-comment"># Windows (cmd):</span></span><br><span class="line">.venv\Scripts\activate.bat</span><br><span class="line"><span class="hljs-comment"># macOS / Linux:</span></span><br><span class="line"><span class="hljs-built_in">source</span> .venv/bin/activate</span><br><span class="line"> </span><br><span class="line"><span class="hljs-comment"># install something</span></span><br><span class="line">pip install requests</span><br><span class="line"> </span><br><span class="line"><span class="hljs-comment"># deactivate when done</span></span><br><span class="line">deactivate</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>After activation, your shell prompt usually shows <code>(.venv)</code> as a prefix. Any <code>pip install</code> only affects this venv, not the system Python.</p>
<blockquote>
<p><em>Where I got stuck:</em> I skipped venvs for a year. Then one project needed <code>requests==2.20</code> and another needed <code>requests==2.28</code>. Mass-upgrading broke the older project. The fix took an hour; the fix would have taken 0 hours with venvs. <strong>Always use a venv.</strong></p>
</blockquote>
<h2 id="requirementstxt"><a href="#requirementstxt" class="headerlink" title="requirements.txt"></a>requirements.txt</h2>
<p>Pin your dependencies:</p>
<pre><code class="language-bash"><figure class="highlight bash"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span></pre></td><td class="code"><pre><code class="bash"><span class="line">pip freeze &gt; requirements.txt</span><br><span class="line"><span class="hljs-comment"># later, on another machine:</span></span><br><span class="line">pip install -r requirements.txt</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>

<p>Sample run:</p>
<pre><code class="language-text"><figure class="highlight text"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span></pre></td><td class="code"><pre><code class="text"><span class="line">Celsius: 25</span><br><span class="line">25.0°C = 77.0°F</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Hint: <code>input()</code> returns a string; convert with <code>float(...)</code>.</p>
<details>
<summary>Solution</summary>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span></pre></td><td class="code"><pre><code class="python"><span class="line">c = <span class="hljs-built_in">float</span>(<span class="hljs-built_in">input</span>(<span class="hljs-string">&quot;Celsius: &quot;</span>))</span><br><span class="line">f = c * <span class="hljs-number">9</span> / <span class="hljs-number">5</span> + <span class="hljs-number">32</span></span><br><span class="line"><span class="hljs-built_in">print</span>(<span class="hljs-string">f&quot;<span class="hljs-subst">{c}</span>°C = <span class="hljs-subst">{f}</span>°F&quot;</span>)</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
