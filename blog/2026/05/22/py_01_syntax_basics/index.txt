<h1 id="Chapter-4-—-Indentation-is-syntax"><a href="#Chapter-4-—-Indentation-is-syntax" class="headerlink" title="Chapter 4 — Indentation is syntax"></a>Chapter 4 — Indentation is syntax</h1>
<p>This is the rule that shocks beginners coming from C-family languages. Python uses <strong>indentation</strong> (not <code>{}</code> or <code>begin/end</code>) to define blocks.</p>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span></pre></td><td class="code"><pre><code class="python"><span class="line"><span class="hljs-keyword">if</span> x &gt; <span class="hljs-number">0</span>:</span><br><span class="line">    <span class="hljs-built_in">print</span>(<span class="hljs-string">&quot;positive&quot;</span>)        <span class="hljs-comment"># this line is inside the if</span></span><br><span class="line">    <span class="hljs-built_in">print</span>(<span class="hljs-string">&quot;still inside&quot;</span>)    <span class="hljs-comment"># this too</span></span><br><span class="line"><span class="hljs-built_in">print</span>(<span class="hljs-string">&quot;outside the if&quot;</span>)      <span class="hljs-comment"># this is after</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Rules:</p>
<ul>
<li>All lines in the same block must have <strong>exactly the same indentation</strong>.</li>
<li>Standard is <strong>4 spaces per level</strong> (PEP 8).</li>
<li><strong>Never mix tabs and spaces.</strong> Most editors auto-convert.</li>
<li>A colon <code>:</code> introduces a new block (after <code>if</code>, <code>for</code>, <code>while</code>, <code>def</code>, <code>class</code>, <code>try</code>, etc.).</li>
</ul>
<blockquote>
<p><em>Where I got stuck:</em> I once spent 30 minutes debugging a script that &quot;just didn't run the loop&quot;. The culprit: a tab character on one line where the rest used spaces. Python silently disagrees about whether they're equal. Modern editors highlight whitespace; turn it on.</p>
</blockquote>
