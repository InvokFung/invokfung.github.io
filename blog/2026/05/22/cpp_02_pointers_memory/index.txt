<h1 id="Chapter-1-—-What-a-pointer-is"><a href="#Chapter-1-—-What-a-pointer-is" class="headerlink" title="Chapter 1 — What a pointer is"></a>Chapter 1 — What a pointer is</h1>
<h2 id="Terminology"><a href="#Terminology" class="headerlink" title="Terminology"></a>Terminology</h2>
<ul>
<li><strong>Pointer</strong> — a variable whose value is the <strong>memory address</strong> of another variable.</li>
<li><strong>Dereference</strong> — read the value at the address (<code>*p</code>).</li>
<li><strong>Null pointer</strong> — a pointer that points to &quot;nothing&quot;; comparisons against <code>nullptr</code> test this.</li>
<li><strong>Dangling pointer</strong> — a pointer to memory that's been freed or gone out of scope. Reading it = undefined behaviour.</li>
</ul>
<h2 id="Declaration-and-dereference"><a href="#Declaration-and-dereference" class="headerlink" title="Declaration and dereference"></a>Declaration and dereference</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">int</span> x = <span class="hljs-number">42</span>;</span><br><span class="line"><span class="hljs-type">int</span>* p = &amp;x;        <span class="hljs-comment">// p holds the address of x</span></span><br><span class="line"> </span><br><span class="line">std::cout &lt;&lt; p;     <span class="hljs-comment">// some hex address like 0x7ffe...</span></span><br><span class="line">std::cout &lt;&lt; *p;    <span class="hljs-comment">// 42 — the value AT that address</span></span><br><span class="line"> </span><br><span class="line">*p = <span class="hljs-number">99</span>;            <span class="hljs-comment">// changes x to 99 via the pointer</span></span><br><span class="line">std::cout &lt;&lt; x;     <span class="hljs-comment">// 99</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Read <code>int*</code> as &quot;pointer to int&quot;. The <code>*</code> after the type is part of the type. The <code>*</code> before the variable name is the dereference operator.</p>
<h2 id="Null-pointer"><a href="#Null-pointer" class="headerlink" title="Null pointer"></a>Null pointer</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">int</span>* p = <span class="hljs-literal">nullptr</span>;     <span class="hljs-comment">// explicitly null</span></span><br><span class="line"><span class="hljs-keyword">if</span> (p) {</span><br><span class="line">    *p = <span class="hljs-number">5</span>;           <span class="hljs-comment">// skipped — p is null</span></span><br><span class="line">}</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p><strong>Always initialise pointers</strong>. Either give them a real address or <code>nullptr</code>.</p>
<blockquote>
<p><em>Where I got stuck:</em> my first month of C++ I declared <code>int* p;</code> and immediately did <code>*p = 5;</code>. Garbage address → memory access violation → crash. Always either initialise from a real variable's <code>&amp;</code>, set to <code>nullptr</code>, or use <code>new</code>.</p>
</blockquote>

<h1 id="Chapter-2-—-Pointer-vs-reference"><a href="#Chapter-2-—-Pointer-vs-reference" class="headerlink" title="Chapter 2 — Pointer vs reference"></a>Chapter 2 — Pointer vs reference</h1>
<table>
<thead>
<tr>
<th></th>
<th>Pointer (<code>int*</code>)</th>
<th>Reference (<code>int&amp;</code>)</th>
</tr>

<h1 id="Chapter-3-—-C-style-arrays"><a href="#Chapter-3-—-C-style-arrays" class="headerlink" title="Chapter 3 — C-style arrays"></a>Chapter 3 — C-style arrays</h1>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">int</span> arr[<span class="hljs-number">5</span>] = {<span class="hljs-number">10</span>, <span class="hljs-number">20</span>, <span class="hljs-number">30</span>, <span class="hljs-number">40</span>, <span class="hljs-number">50</span>};</span><br><span class="line">arr[<span class="hljs-number">0</span>];                 <span class="hljs-comment">// 10</span></span><br><span class="line">arr[<span class="hljs-number">4</span>];                 <span class="hljs-comment">// 50</span></span><br><span class="line">arr[<span class="hljs-number">5</span>];                 <span class="hljs-comment">// OUT OF BOUNDS — undefined behaviour!</span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-comment">// size</span></span><br><span class="line"><span class="hljs-keyword">constexpr</span> <span class="hljs-type">int</span> N = <span class="hljs-built_in">sizeof</span>(arr) / <span class="hljs-built_in">sizeof</span>(arr[<span class="hljs-number">0</span>]);   <span class="hljs-comment">// 5</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>C-style arrays decay to pointers when passed to functions:</p>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">print</span><span class="hljs-params">(<span class="hljs-type">int</span>* a, <span class="hljs-type">int</span> n)</span> </span>{     <span class="hljs-comment">// received as pointer; size info LOST</span></span><br><span class="line">    <span class="hljs-keyword">for</span> (<span class="hljs-type">int</span> i = <span class="hljs-number">0</span>; i &lt; n; ++i) std::cout &lt;&lt; a[i] &lt;&lt; <span class="hljs-string">&quot; &quot;</span>;</span><br><span class="line">}</span><br><span class="line"> </span><br><span class="line"><span class="hljs-built_in">print</span>(arr, <span class="hljs-number">5</span>);</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p><strong>This is the classic C foot-gun.</strong> The array's size is lost; you must pass it separately. Forget once → buffer overrun → security CVE.</p>
<h2 id="Modern-fix-use-stdarray-or-stdvector"><a href="#Modern-fix-use-stdarray-or-stdvector" class="headerlink" title="Modern fix: use std::array or std::vector"></a>Modern fix: use <code>std::array</code> or <code>std::vector</code></h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-meta">#<span class="hljs-keyword">include</span> <span class="hljs-string">&lt;array&gt;</span></span></span><br><span class="line"><span class="hljs-meta">#<span class="hljs-keyword">include</span> <span class="hljs-string">&lt;vector&gt;</span></span></span><br><span class="line"> </span><br><span class="line">std::array&lt;<span class="hljs-type">int</span>, 5&gt; fixed = {<span class="hljs-number">10</span>, <span class="hljs-number">20</span>, <span class="hljs-number">30</span>, <span class="hljs-number">40</span>, <span class="hljs-number">50</span>};   <span class="hljs-comment">// size at compile time</span></span><br><span class="line">fixed.<span class="hljs-built_in">size</span>();                                       <span class="hljs-comment">// 5 — known!</span></span><br><span class="line"> </span><br><span class="line">std::vector&lt;<span class="hljs-type">int</span>&gt; dynamic = {<span class="hljs-number">1</span>, <span class="hljs-number">2</span>, <span class="hljs-number">3</span>};               <span class="hljs-comment">// size at runtime</span></span><br><span class="line">dynamic.<span class="hljs-built_in">push_back</span>(<span class="hljs-number">4</span>);</span><br><span class="line">dynamic.<span class="hljs-built_in">size</span>();                                     <span class="hljs-comment">// 4</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Both know their size, support range-for, and refuse to decay. Use these in 100% of new code. Save C arrays for embedded / no-std contexts.</p>

<h1 id="Chapter-4-—-new-and-delete"><a href="#Chapter-4-—-new-and-delete" class="headerlink" title="Chapter 4 — new and delete"></a>Chapter 4 — new and delete</h1>
<p><code>new</code> allocates memory on the <strong>heap</strong> (large, freely-sized, manually freed). <code>delete</code> releases it.</p>
<h2 id="Single-object"><a href="#Single-object" class="headerlink" title="Single object"></a>Single object</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">int</span>* p = <span class="hljs-keyword">new</span> <span class="hljs-built_in">int</span>(<span class="hljs-number">42</span>);    <span class="hljs-comment">// allocate one int, init to 42</span></span><br><span class="line">std::cout &lt;&lt; *p &lt;&lt; <span class="hljs-string">&quot;\n&quot;</span>;</span><br><span class="line"><span class="hljs-keyword">delete</span> p;                <span class="hljs-comment">// FREE the memory</span></span><br><span class="line">p = <span class="hljs-literal">nullptr</span>;             <span class="hljs-comment">// (good habit) prevent later misuse</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<h2 id="Array"><a href="#Array" class="headerlink" title="Array"></a>Array</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">int</span>* arr = <span class="hljs-keyword">new</span> <span class="hljs-type">int</span>[<span class="hljs-number">100</span>]{};      <span class="hljs-comment">// 100 ints, zero-initialised</span></span><br><span class="line">arr[<span class="hljs-number">0</span>] = <span class="hljs-number">7</span>;</span><br><span class="line"><span class="hljs-keyword">delete</span>[] arr;                   <span class="hljs-comment">// <span class="hljs-doctag">NOTE:</span> use delete[] for arrays!</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>

<h2 id="What-goes-wrong"><a href="#What-goes-wrong" class="headerlink" title="What goes wrong"></a>What goes wrong</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span><br><span class="line">11</span><br><span class="line">12</span><br><span class="line">13</span><br><span class="line">14</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">int</span>* p = <span class="hljs-keyword">new</span> <span class="hljs-built_in">int</span>(<span class="hljs-number">5</span>);</span><br><span class="line"><span class="hljs-keyword">delete</span> p;</span><br><span class="line"><span class="hljs-keyword">delete</span> p;                <span class="hljs-comment">// DOUBLE FREE — undefined behaviour, often crash</span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-type">int</span>* q = <span class="hljs-keyword">new</span> <span class="hljs-built_in">int</span>(<span class="hljs-number">7</span>);</span><br><span class="line"><span class="hljs-comment">// ... forget to delete q ...   // MEMORY LEAK — process holds memory forever</span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-type">int</span>* r;</span><br><span class="line">{</span><br><span class="line">    <span class="hljs-type">int</span> local = <span class="hljs-number">5</span>;</span><br><span class="line">    r = &amp;local;</span><br><span class="line">}</span><br><span class="line">*r;                      <span class="hljs-comment">// DANGLING — local is gone</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>These three bugs — double-free, leak, dangling — define why <strong>manual memory management is the hardest part of C++</strong>.</p>
<blockquote>
<p><em>Trick:</em> in modern C++ you rarely write <code>new</code> and <code>delete</code> directly. You use <strong>smart pointers</strong> (<code>std::unique_ptr</code>, <code>std::shared_ptr</code> — Post 05) and let the type system free things automatically. This chapter is here so you understand what the smart pointers are doing for you.</p>
</blockquote>

<h1 id="Chapter-7-—-RAII-the-C-idiom"><a href="#Chapter-7-—-RAII-the-C-idiom" class="headerlink" title="Chapter 7 — RAII (the C++ idiom)"></a>Chapter 7 — RAII (the C++ idiom)</h1>
<p><strong>Resource Acquisition Is Initialisation</strong> = tie a resource's lifetime to an object. The constructor acquires, the destructor releases. When the object goes out of scope, cleanup is automatic.</p>
<h2 id="Why-it-matters"><a href="#Why-it-matters" class="headerlink" title="Why it matters"></a>Why it matters</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span><br><span class="line">11</span><br><span class="line">12</span><br><span class="line">13</span><br><span class="line">14</span><br><span class="line">15</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">bad</span><span class="hljs-params">()</span> </span>{</span><br><span class="line">    FILE* f = <span class="hljs-built_in">fopen</span>(<span class="hljs-string">&quot;data.txt&quot;</span>, <span class="hljs-string">&quot;r&quot;</span>);</span><br><span class="line">    <span class="hljs-keyword">if</span> (!<span class="hljs-built_in">do_stuff</span>(f)) {</span><br><span class="line">        <span class="hljs-keyword">return</span>;                  <span class="hljs-comment">// LEAK — never closed</span></span><br><span class="line">    }</span><br><span class="line">    <span class="hljs-built_in">fclose</span>(f);</span><br><span class="line">}</span><br><span class="line"> </span><br><span class="line"><span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">good</span><span class="hljs-params">()</span> </span>{</span><br><span class="line">    <span class="hljs-function">std::ifstream <span class="hljs-title">f</span><span class="hljs-params">(<span class="hljs-string">&quot;data.txt&quot;</span>)</span></span>; <span class="hljs-comment">// file opened</span></span><br><span class="line">    <span class="hljs-keyword">if</span> (!<span class="hljs-built_in">do_stuff</span>(f)) {</span><br><span class="line">        <span class="hljs-keyword">return</span>;                  <span class="hljs-comment">// SAFE — ifstream destructor closes it</span></span><br><span class="line">    }</span><br><span class="line">}                                <span class="hljs-comment">// closed here too if we reach the end</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p><code>std::ifstream</code> is an RAII wrapper around a file handle. The destructor closes the file no matter how the function returns (normal, early return, exception thrown).</p>
<h2 id="The-pattern-in-your-own-classes"><a href="#The-pattern-in-your-own-classes" class="headerlink" title="The pattern in your own classes"></a>The pattern in your own classes</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span><br><span class="line">11</span><br><span class="line">12</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-keyword">class</span> <span class="hljs-title class_">Resource</span> {</span><br><span class="line">    <span class="hljs-type">int</span>* data;</span><br><span class="line"><span class="hljs-keyword">public</span>:</span><br><span class="line">    <span class="hljs-built_in">Resource</span>(<span class="hljs-type">int</span> n) : <span class="hljs-built_in">data</span>(<span class="hljs-keyword">new</span> <span class="hljs-type">int</span>[n]{}) {}    <span class="hljs-comment">// acquire</span></span><br><span class="line">    ~<span class="hljs-built_in">Resource</span>() { <span class="hljs-keyword">delete</span>[] data; }             <span class="hljs-comment">// release</span></span><br><span class="line">};</span><br><span class="line"> </span><br><span class="line"><span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">use</span><span class="hljs-params">()</span> </span>{</span><br><span class="line">    <span class="hljs-function">Resource <span class="hljs-title">r</span><span class="hljs-params">(<span class="hljs-number">100</span>)</span></span>;</span><br><span class="line">    <span class="hljs-comment">// ...</span></span><br><span class="line">}   <span class="hljs-comment">// r.~Resource() called — data freed</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<blockquote>
<p><em>Trick:</em> every C++ class that owns a raw resource (memory, file, lock, socket) should follow <strong>the Rule of Three / Five / Zero</strong>:</p>
<ul>
<li>If you write a custom destructor, you probably also need copy constructor + copy assignment.</li>
<li>C++11 adds move constructor + move assignment (Five total).</li>
<li>If you can avoid all five by using smart pointers and containers (the Rule of Zero) — do.</li>
</ul>
</blockquote>

<p>Modern C++ provides smart pointers that own heap memory and free it automatically. We cover them fully in Post 05; here's a preview:</p>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span><br><span class="line">11</span><br><span class="line">12</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-meta">#<span class="hljs-keyword">include</span> <span class="hljs-string">&lt;memory&gt;</span></span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-comment">// unique ownership — auto-freed when the unique_ptr goes out of scope</span></span><br><span class="line"><span class="hljs-keyword">auto</span> p = std::<span class="hljs-built_in">make_unique</span>&lt;<span class="hljs-type">int</span>&gt;(<span class="hljs-number">42</span>);</span><br><span class="line">std::cout &lt;&lt; *p &lt;&lt; <span class="hljs-string">&quot;\n&quot;</span>;        <span class="hljs-comment">// 42</span></span><br><span class="line"><span class="hljs-comment">// no delete needed</span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-comment">// shared ownership — last owner frees</span></span><br><span class="line"><span class="hljs-keyword">auto</span> sp1 = std::<span class="hljs-built_in">make_shared</span>&lt;<span class="hljs-type">int</span>&gt;(<span class="hljs-number">100</span>);</span><br><span class="line"><span class="hljs-keyword">auto</span> sp2 = sp1;                 <span class="hljs-comment">// both own; reference count = 2</span></span><br><span class="line"><span class="hljs-comment">// when both go out of scope, memory freed</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>

<p>The code below leaks. Identify where, and fix it (a) with explicit <code>delete</code>, then (b) with <code>std::unique_ptr</code>.</p>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">process</span><span class="hljs-params">()</span> </span>{</span><br><span class="line">    <span class="hljs-type">int</span>* buf = <span class="hljs-keyword">new</span> <span class="hljs-type">int</span>[<span class="hljs-number">1024</span>];</span><br><span class="line">    <span class="hljs-keyword">if</span> (<span class="hljs-built_in">something_failed</span>()) {</span><br><span class="line">        <span class="hljs-keyword">return</span>;                   <span class="hljs-comment">// LEAK</span></span><br><span class="line">    }</span><br><span class="line">    <span class="hljs-built_in">use</span>(buf);</span><br><span class="line">    <span class="hljs-keyword">delete</span>[] buf;</span><br><span class="line">}</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>

<p>(b) Use <code>std::unique_ptr</code>:</p>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-meta">#<span class="hljs-keyword">include</span> <span class="hljs-string">&lt;memory&gt;</span></span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">process</span><span class="hljs-params">()</span> </span>{</span><br><span class="line">    <span class="hljs-keyword">auto</span> buf = std::<span class="hljs-built_in">make_unique</span>&lt;<span class="hljs-type">int</span>[]&gt;(<span class="hljs-number">1024</span>);</span><br><span class="line">    <span class="hljs-keyword">if</span> (<span class="hljs-built_in">something_failed</span>()) {</span><br><span class="line">        <span class="hljs-keyword">return</span>;     <span class="hljs-comment">// buf destructor frees automatically</span></span><br><span class="line">    }</span><br><span class="line">    <span class="hljs-built_in">use</span>(buf.<span class="hljs-built_in">get</span>());</span><br><span class="line">}</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>

<h1 id="Cheat-sheet"><a href="#Cheat-sheet" class="headerlink" title="Cheat-sheet"></a>Cheat-sheet</h1>
<table>
<thead>
<tr>
<th>What</th>
<th>How</th>
</tr>
</thead>
<tbody>
<tr>
<td>Declare pointer</td>
<td><code>int* p</code></td>
</tr>
<tr>
<td>Address of</td>
<td><code>&amp;x</code></td>
</tr>
<tr>
<td>Dereference</td>
<td><code>*p</code></td>
</tr>
<tr>
<td>Null</td>
<td><code>nullptr</code></td>
</tr>
<tr>
<td>Allocate one</td>
<td><code>int* p = new int(5);</code></td>
</tr>
<tr>
<td>Free one</td>
<td><code>delete p;</code></td>
</tr>
<tr>
<td>Allocate array</td>
<td><code>int* a = new int[N];</code></td>
</tr>
<tr>
<td>Free array</td>
<td><code>delete[] a;</code></td>
</tr>
<tr>
<td>Member via pointer</td>
<td><code>p-&gt;member</code></td>
</tr>
<tr>
<td>Member via reference</td>
<td><code>r.member</code></td>
</tr>
<tr>
<td>Modern array</td>
<td><code>std::array&lt;int, 5&gt;</code> or <code>std::vector&lt;int&gt;</code></td>
</tr>
<tr>
<td>Modern owning ptr</td>
<td><code>std::make_unique&lt;T&gt;(...)</code></td>
</tr>
<tr>
<td>Pointer to const</td>
<td><code>const int* p;</code></td>
</tr>
<tr>
<td>Const pointer</td>
<td><code>int* const p = &amp;x;</code></td>
</tr>
<tr>
<td>RAII rule</td>
<td>Constructor acquires, destructor releases</td>
</tr>
<tr>
<td>Rule of Zero</td>
<td>Use smart pointers + containers, write no copy/move/dtor</td>
</tr>
