<h2 id="Combining-everything"><a href="#Combining-everything" class="headerlink" title="Combining everything"></a>Combining everything</h2>

<p>Order: positional → <code>*args</code> → keyword-only → <code>**kwargs</code>.</p>
<h2 id="Keyword-only-and-positional-only"><a href="#Keyword-only-and-positional-only" class="headerlink" title="Keyword-only and positional-only"></a>Keyword-only and positional-only</h2>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span></pre></td><td class="code"><pre><code class="python"><span class="line"><span class="hljs-keyword">def</span> <span class="hljs-title function_">func</span>(<span class="hljs-params">pos_only, /, normal, *, kw_only</span>):</span><br><span class="line">    ...</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<ul>
<li>Before <code>/</code> — must be positional.</li>
<li>After <code>*</code> — must be keyword.</li>
</ul>
<blockquote>
<p><em>Trick:</em> using <code>*</code> to force keyword-only args (<code>def f(*, debug=False)</code>) prevents callers from passing <code>True</code> mysteriously without context. Great for boolean flags.</p>
</blockquote>

<h1 id="Chapter-3-—-Scope-LEGB-rule"><a href="#Chapter-3-—-Scope-LEGB-rule" class="headerlink" title="Chapter 3 — Scope (LEGB rule)"></a>Chapter 3 — Scope (LEGB rule)</h1>
<p>When Python looks up a name, it checks in this order:</p>
<ol>
<li><strong>L</strong>ocal — inside the current function.</li>
<li><strong>E</strong>nclosing — outer functions (if nested).</li>
<li><strong>G</strong>lobal — at the module's top level.</li>
<li><strong>B</strong>uilt-in — <code>print</code>, <code>len</code>, etc.</li>
</ol>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span><br><span class="line">11</span><br><span class="line">12</span><br><span class="line">13</span></pre></td><td class="code"><pre><code class="python"><span class="line">x = <span class="hljs-string">&quot;global&quot;</span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-keyword">def</span> <span class="hljs-title function_">outer</span>():</span><br><span class="line">    x = <span class="hljs-string">&quot;enclosing&quot;</span></span><br><span class="line">    <span class="hljs-keyword">def</span> <span class="hljs-title function_">inner</span>():</span><br><span class="line">        x = <span class="hljs-string">&quot;local&quot;</span></span><br><span class="line">        <span class="hljs-built_in">print</span>(x)   <span class="hljs-comment"># &quot;local&quot;</span></span><br><span class="line">    inner()</span><br><span class="line">    <span class="hljs-built_in">print</span>(x)       <span class="hljs-comment"># &quot;enclosing&quot;</span></span><br><span class="line"> </span><br><span class="line">outer()</span><br><span class="line"><span class="hljs-built_in">print</span>(x)           <span class="hljs-comment"># &quot;global&quot;</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<h2 id="Modifying-outer-scope"><a href="#Modifying-outer-scope" class="headerlink" title="Modifying outer scope"></a>Modifying outer scope</h2>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span></pre></td><td class="code"><pre><code class="python"><span class="line">counter = <span class="hljs-number">0</span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-keyword">def</span> <span class="hljs-title function_">increment</span>():</span><br><span class="line">    <span class="hljs-keyword">global</span> counter</span><br><span class="line">    counter += <span class="hljs-number">1</span>   <span class="hljs-comment"># without `global`, raises UnboundLocalError</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span></pre></td><td class="code"><pre><code class="python"><span class="line"><span class="hljs-keyword">def</span> <span class="hljs-title function_">outer</span>():</span><br><span class="line">    x = <span class="hljs-number">1</span></span><br><span class="line">    <span class="hljs-keyword">def</span> <span class="hljs-title function_">inner</span>():</span><br><span class="line">        <span class="hljs-keyword">nonlocal</span> x</span><br><span class="line">        x += <span class="hljs-number">1</span>     <span class="hljs-comment"># modifies outer function&#x27;s x</span></span><br><span class="line">    inner()</span><br><span class="line">    <span class="hljs-built_in">print</span>(x)       <span class="hljs-comment"># 2</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p><code>global</code> and <code>nonlocal</code> are escape hatches. <strong>Prefer returning values</strong> to mutating outer state.</p>

<h1 id="Chapter-6-—-The-if-__name__-__main__-block"><a href="#Chapter-6-—-The-if-__name__-__main__-block" class="headerlink" title="Chapter 6 — The if __name__ == &quot;__main__&quot; block"></a>Chapter 6 — The <code>if __name__ == &quot;__main__&quot;</code> block</h1>
<p>When you run <code>python script.py</code>, Python sets <code>__name__ == &quot;__main__&quot;</code> inside that file. When you <code>import script</code> from elsewhere, <code>__name__ == &quot;script&quot;</code>.</p>
<pre><code class="language-python"><figure class="highlight python"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span></pre></td><td class="code"><pre><code class="python"><span class="line"><span class="hljs-comment"># script.py</span></span><br><span class="line"><span class="hljs-keyword">def</span> <span class="hljs-title function_">main</span>():</span><br><span class="line">    <span class="hljs-built_in">print</span>(<span class="hljs-string">&quot;doing work&quot;</span>)</span><br><span class="line"> </span><br><span class="line"><span class="hljs-keyword">if</span> __name__ == <span class="hljs-string">&quot;__main__&quot;</span>:</span><br><span class="line">    main()</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>This lets the file be both <strong>importable</strong> (no side effects on import) and <strong>runnable</strong> (executes when run directly).</p>
<blockquote>
<p><em>Trick:</em> every executable script should have this block. Tests and other modules can then import its functions without triggering the whole script.</p>
</blockquote>

<h1 id="Chapter-9-—-Function-design-tips"><a href="#Chapter-9-—-Function-design-tips" class="headerlink" title="Chapter 9 — Function design tips"></a>Chapter 9 — Function design tips</h1>
<ol>
<li><strong>One purpose per function.</strong> If you can't name it cleanly, it does too much.</li>
<li><strong>Return values, don't print</strong> (except for genuinely user-facing functions). Lets the caller decide what to do.</li>
<li><strong>Keep parameter count low.</strong> 5+ args = it's time to wrap them in a dataclass or dict.</li>
<li><strong>Document with a docstring.</strong> Even one line beats nothing.</li>
<li><strong>Avoid hidden side effects.</strong> A function called <code>calculate_total</code> shouldn't write to the DB.</li>
</ol>
<blockquote>
