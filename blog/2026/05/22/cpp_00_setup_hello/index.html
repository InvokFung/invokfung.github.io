C++ Course — 00 · Setup, Compiler, and Hello World

Created2026-05-22|Updated2026-05-21|Programming
|Post View:

C++ is the language that trades safety for control. You manage memory directly. You touch hardware closer. You pay for speed by accepting that one wrong pointer can crash everything. In exchange, your code can outrun every garbage-collected language by 10–100×, run on the smallest microcontroller, and live inside browsers, game engines, databases, operating systems, and trading systems. This post is the first step of a step-by-step C++ course. Future posts extend into templates, concurrency, modules, and modern (C++17/20/23) features.

Series map: 00 Setup (this post) → 01 Syntax & Types → 02 Pointers & Memory → 03 Classes & OOP → 04 Templates & STL → 05 Modern C++ → (future) concurrency · modules · ranges · coroutines.

Learning Outcome

  • Install a modern C++ compiler on Windows / macOS / Linux.
  • Understand the compile + link model and the role of headers.
  • Write, compile, and run "Hello, World" using g++, clang++, or MSVC.
  • Use a basic build flow (single file → multi-file → CMake glimpse).
  • Pick a sensible editor / IDE.

Chapter 1 — What C++ is (and isn't)

Terminology

  • Compiler — translates .cpp source into machine code (object files).
  • Linker — combines object files + libraries into a runnable executable.
  • Standard library (STL/std::) — the language's built-in collections, algorithms, I/O.
  • Header file (.h / .hpp) — declarations imported by other files via #include.
  • Source file (.cpp) — implementations + the main() function.
  • Standard — the language version: C++11, C++14, C++17, C++20, C++23. Newer = more features.

C++ vs Python (one paragraph)

Python is interpreted, dynamically typed, garbage-collected, and slow. C++ is compiled, statically typed, manually memory-managed (with smart-pointer helpers), and fast. Python code reads cleanly with little ceremony; C++ code can be more verbose but exposes what's happening at the machine level. Use C++ when you need raw speed, low memory footprint, hardware access, or you're building infrastructure that other languages will call into.

Trick: don't pick a language; pick a problem. Most real engineers use both — Python for orchestration and analysis, C++ (or Rust) for the hot inner loop.

Chapter 2 — Compiler installation

You need one of: g++ (GCC), clang++ (LLVM), or MSVC (Microsoft Visual C++). Each can compile standards-conforming code.

Windows

Option A — MSYS2 / MinGW (gives you g++):

  1. Install MSYS2 from msys2.org.
  2. In the MSYS2 terminal: pacman -S mingw-w64-ucrt-x86_64-gcc.
  3. Add C:\msys64\ucrt64\bin to PATH.
  4. New terminal: g++ --version should show GCC 13+.

Option B — Visual Studio (gives you MSVC):

  1. Download Visual Studio Community (free) from visualstudio.microsoft.com.
  2. During install, tick "Desktop development with C++".
  3. Open x64 Native Tools Command Prompt for VS; cl is the compiler.

Option C — clang-cl + LLVM: similar to MSVC but using clang.

macOS

That's it. macOS ships with a recent clang.

Linux (Debian/Ubuntu)

Fedora: sudo dnf install gcc-c++ clang make cmake.
Arch: sudo pacman -S gcc clang make cmake.

Chapter 4 — A slightly bigger program

New pieces:

  • #include <string> — pulls in std::string.
  • std::getline(std::cin, name) — reads a whole line from standard input.
  • Stream operator << chains naturally.

Compile flags worth knowing

Flag Meaning
-std=c++20 Use C++20 standard (use c++23 if your compiler supports it).
-Wall Most warnings on.
-Wextra Extra warnings (off by default but recommended).
-O2 Optimisation level 2 (release builds). For debugging use -O0 -g.
-g Embed debug info for gdb / lldb.

Trick: always compile with -Wall -Wextra from day 1. Warnings catch 80% of beginner bugs before they crash at runtime.

Chapter 7 — Editor / IDE choice

Tool Notes
VS Code + C/C++ extension + CMake Tools Free, fast, works everywhere. Recommended starting point.
CLion JetBrains. Best refactoring; paid but free for students.
Visual Studio (Windows) The MSVC-native IDE. Best Windows integration.
Qt Creator Slick if you're doing Qt UI work.
Neovim + clangd + LSP Terminal-native; powerful once configured.
Sublime Text + LSP Fast, light.

Use VS Code if undecided. The C/C++ extension (Microsoft) gives you completion, jump-to-definition, and integrated debugging.

Cheat-sheet

What How
Compile single file g++ -std=c++20 -Wall x.cpp -o x
Compile multi-file g++ a.cpp b.cpp -o app
MSVC compile cl x.cpp
Print std::cout << x << "\n";
Read line std::getline(std::cin, s);
Read whitespace-separated std::cin >> x;
Include standard header #include <iostream>
Include local header #include "file.h"
