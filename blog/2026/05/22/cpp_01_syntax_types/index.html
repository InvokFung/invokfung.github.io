C++ Course — 01 · Syntax, Types, References, and Control Flow

Created2026-05-22|Updated2026-05-21|Programming
|Post View:

This post covers the syntactic spine of C++: primitive types, variable declaration, const, references, operators, control flow, and the first taste of functions. C++ is statically typed — every variable's type is fixed at compile time — which forces you to think about representation up front. The payoff: huge classes of bugs caught before your program runs.

Series map: 00 Setup → 01 Syntax & Types (this post) → 02 Pointers & Memory → 03 Classes & OOP → 04 Templates & STL → 05 Modern C++ → (future).

Learning Outcome

  • Declare and initialise variables of every primitive type.
  • Use const, auto, and references correctly.
  • Use arithmetic, comparison, logical, and bitwise operators.
  • Write if/else, for, while, do-while, switch, and range-based for.
  • Understand integer overflow, type promotion, and narrowing.
  • Define and call simple functions; understand pass-by-value vs pass-by-reference.

Chapter 1 — Primitive types

Terminology

  • Type — describes the size + interpretation of a value (e.g., 32-bit signed integer).
  • Variable — a typed, named memory location.
  • Declaration — introduces a name + type (int x;).
  • Initialisation — gives it a value at the point of declaration (int x = 5;).
  • Definition — a declaration that allocates storage.

Common types

bool 1 byte true / false
char 1 byte signed -128..127 (impl-defined)

Chapter 2 — Variable declaration and initialisation

Why prefer {}?

Braced initialisation rejects narrowing conversions at compile time:

This catches the kind of bugs that ruin nights. Use {} everywhere modern compilers allow it.

auto — let the compiler deduce

auto is great when:

  • The type is obvious from the right side.
  • The type is long (iterators, lambdas, template instantiations).

Don't use auto for everything — sometimes spelling out the type makes intent clearer.

Chapter 3 — const and constexpr

const

Once declared const, the variable cannot be reassigned. Use const aggressively — it documents intent and lets the compiler optimise.

constexpr (compile-time constant)

constexpr is evaluated during compilation. Use for sizes, mathematical constants, lookup tables.

Trick: default to const for any variable you don't actively change after initialisation. It costs nothing and prevents accidental mutation.

Chapter 4 — References (first taste)

A reference is an alias for another variable.

Key facts about references:

  • Must be initialised at declaration — no "uninitialised reference".
  • Cannot be re-seated to another variable.
  • Always refer to a valid object (unlike pointers, which can be null).

const reference

This is the way to pass large objects to functions in C++: by const &. It avoids copies but guarantees the function can't modify the argument.

We'll cover pointers (int*) in detail in Post 02. References are usually the cleaner choice.

Chapter 5 — Operators

Arithmetic

+, -, *, /, % (modulo, integers only). Watch out: 5 / 2 is 2, not 2.5, because both operands are int. Use 5.0 / 2 or 5 / 2.0 to force floating-point.

Comparison

==, !=, <, >, <=, >= — return bool.

Logical

&& (and), || (or), ! (not). They short-circuit.

Bitwise

&, |, ^ (xor), ~ (not), << (left shift), >> (right shift). These operate on individual bits — useful for low-level manipulation and flags:

Assignment shorthand

+=, -=, *=, /=, %=, &=, |=, ^=, <<=, >>=.

Increment / decrement

Prefer ++i when the result isn't used — slightly more efficient for non-trivial types.

Chapter 8 — Functions (intro)

Pass by value vs reference

Default rule:

  • Small types (int, double, pointers) → pass by value.
  • Large types (std::string, containers, your own classes) → pass by const & unless you need to mutate.

Default arguments

Defaults must be on trailing parameters.
