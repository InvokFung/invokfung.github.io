<ul>

<h2 id="Terminology"><a href="#Terminology" class="headerlink" title="Terminology"></a>Terminology</h2>
<ul>
<li><strong>Type</strong> — describes the size + interpretation of a value (e.g., 32-bit signed integer).</li>
<li><strong>Variable</strong> — a typed, named memory location.</li>
<li><strong>Declaration</strong> — introduces a name + type (<code>int x;</code>).</li>
<li><strong>Initialisation</strong> — gives it a value at the point of declaration (<code>int x = 5;</code>).</li>
<li><strong>Definition</strong> — a declaration that allocates storage.</li>
</ul>

<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span><br><span class="line">11</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">int</span> x;              <span class="hljs-comment">// declared, uninitialised — value is GARBAGE</span></span><br><span class="line"><span class="hljs-type">int</span> y = <span class="hljs-number">5</span>;          <span class="hljs-comment">// copy-initialisation</span></span><br><span class="line"><span class="hljs-function"><span class="hljs-type">int</span> <span class="hljs-title">z</span><span class="hljs-params">(<span class="hljs-number">7</span>)</span></span>;           <span class="hljs-comment">// direct initialisation (constructor-style)</span></span><br><span class="line"><span class="hljs-type">int</span> w{<span class="hljs-number">9</span>};           <span class="hljs-comment">// braced (uniform / list) initialisation — RECOMMENDED</span></span><br><span class="line"> </span><br><span class="line"><span class="hljs-type">double</span> pi = <span class="hljs-number">3.14159</span>;</span><br><span class="line"><span class="hljs-type">char</span> letter = <span class="hljs-string">&#x27;A&#x27;</span>;</span><br><span class="line"><span class="hljs-type">bool</span> active = <span class="hljs-literal">true</span>;</span><br><span class="line"> </span><br><span class="line">std::string name = <span class="hljs-string">&quot;Ada&quot;</span>;   <span class="hljs-comment">// requires #include &lt;string&gt;</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<h2 id="Why-prefer"><a href="#Why-prefer" class="headerlink" title="Why prefer {}?"></a>Why prefer <code>{}</code>?</h2>
<p>Braced initialisation rejects <strong>narrowing conversions</strong> at compile time:</p>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">int</span> x = <span class="hljs-number">3.7</span>;        <span class="hljs-comment">// compiles — silently truncates to 3</span></span><br><span class="line"><span class="hljs-type">int</span> y{<span class="hljs-number">3.7</span>};         <span class="hljs-comment">// ERROR — narrowing forbidden</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>This catches the kind of bugs that ruin nights. Use <code>{}</code> everywhere modern compilers allow it.</p>
<h2 id="auto-—-let-the-compiler-deduce"><a href="#auto-—-let-the-compiler-deduce" class="headerlink" title="auto — let the compiler deduce"></a><code>auto</code> — let the compiler deduce</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-keyword">auto</span> x = <span class="hljs-number">5</span>;             <span class="hljs-comment">// int</span></span><br><span class="line"><span class="hljs-keyword">auto</span> y = <span class="hljs-number">3.14</span>;          <span class="hljs-comment">// double</span></span><br><span class="line"><span class="hljs-keyword">auto</span> name = <span class="hljs-string">&quot;Ada&quot;</span>;      <span class="hljs-comment">// const char*  (NOT std::string!)</span></span><br><span class="line"><span class="hljs-keyword">auto</span> s = std::string{<span class="hljs-string">&quot;Ada&quot;</span>};   <span class="hljs-comment">// explicit</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p><code>auto</code> is great when:</p>
<ul>
<li>The type is obvious from the right side.</li>
<li>The type is long (iterators, lambdas, template instantiations).</li>
</ul>
<p>Don't use <code>auto</code> for everything — sometimes spelling out the type makes intent clearer.</p>

<h1 id="Chapter-3-—-const-and-constexpr"><a href="#Chapter-3-—-const-and-constexpr" class="headerlink" title="Chapter 3 — const and constexpr"></a>Chapter 3 — <code>const</code> and <code>constexpr</code></h1>
<h2 id="const"><a href="#const" class="headerlink" title="const"></a><code>const</code></h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">const</span> <span class="hljs-type">int</span> MAX = <span class="hljs-number">100</span>;</span><br><span class="line">MAX = <span class="hljs-number">200</span>;          <span class="hljs-comment">// ERROR — cannot modify const</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Once declared <code>const</code>, the variable cannot be reassigned. Use <code>const</code> aggressively — it documents intent and lets the compiler optimise.</p>
<h2 id="constexpr-compile-time-constant"><a href="#constexpr-compile-time-constant" class="headerlink" title="constexpr (compile-time constant)"></a><code>constexpr</code> (compile-time constant)</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-keyword">constexpr</span> <span class="hljs-type">int</span> BUFFER = <span class="hljs-number">1024</span>;     <span class="hljs-comment">// value known at compile time</span></span><br><span class="line"><span class="hljs-keyword">constexpr</span> <span class="hljs-type">double</span> PI = <span class="hljs-number">3.14159265358979</span>;</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p><code>constexpr</code> is evaluated during compilation. Use for sizes, mathematical constants, lookup tables.</p>
<blockquote>
<p><em>Trick:</em> default to <code>const</code> for any variable you don't actively change after initialisation. It costs nothing and prevents accidental mutation.</p>
</blockquote>
<hr>
<h1 id="Chapter-4-—-References-first-taste"><a href="#Chapter-4-—-References-first-taste" class="headerlink" title="Chapter 4 — References (first taste)"></a>Chapter 4 — References (first taste)</h1>
<p>A <strong>reference</strong> is an alias for another variable.</p>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">int</span> x = <span class="hljs-number">5</span>;</span><br><span class="line"><span class="hljs-type">int</span>&amp; ref = x;       <span class="hljs-comment">// ref is another name for x</span></span><br><span class="line"> </span><br><span class="line">ref = <span class="hljs-number">10</span>;           <span class="hljs-comment">// changes x too</span></span><br><span class="line">std::cout &lt;&lt; x;     <span class="hljs-comment">// 10</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Key facts about references:</p>
<ul>
<li>Must be <strong>initialised at declaration</strong> — no &quot;uninitialised reference&quot;.</li>
<li>Cannot be re-seated to another variable.</li>
<li>Always refer to a valid object (unlike pointers, which can be null).</li>
</ul>
<h2 id="const-reference"><a href="#const-reference" class="headerlink" title="const reference"></a>const reference</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">print</span><span class="hljs-params">(<span class="hljs-type">const</span> std::string&amp; s)</span> </span>{     <span class="hljs-comment">// pass by const ref — no copy, can&#x27;t modify</span></span><br><span class="line">    std::cout &lt;&lt; s &lt;&lt; <span class="hljs-string">&quot;\n&quot;</span>;</span><br><span class="line">}</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>This is <strong>the</strong> way to pass large objects to functions in C++: by <code>const &amp;</code>. It avoids copies but guarantees the function can't modify the argument.</p>
<p>We'll cover pointers (<code>int*</code>) in detail in Post 02. References are usually the cleaner choice.</p>

<h1 id="Chapter-5-—-Operators"><a href="#Chapter-5-—-Operators" class="headerlink" title="Chapter 5 — Operators"></a>Chapter 5 — Operators</h1>
<h2 id="Arithmetic"><a href="#Arithmetic" class="headerlink" title="Arithmetic"></a>Arithmetic</h2>
<p><code>+</code>, <code>-</code>, <code>*</code>, <code>/</code>, <code>%</code> (modulo, integers only). Watch out: <code>5 / 2</code> is <code>2</code>, not <code>2.5</code>, because both operands are <code>int</code>. Use <code>5.0 / 2</code> or <code>5 / 2.0</code> to force floating-point.</p>
<h2 id="Comparison"><a href="#Comparison" class="headerlink" title="Comparison"></a>Comparison</h2>
<p><code>==</code>, <code>!=</code>, <code>&lt;</code>, <code>&gt;</code>, <code>&lt;=</code>, <code>&gt;=</code> — return <code>bool</code>.</p>
<h2 id="Logical"><a href="#Logical" class="headerlink" title="Logical"></a>Logical</h2>
<p><code>&amp;&amp;</code> (and), <code>||</code> (or), <code>!</code> (not). They short-circuit.</p>
<h2 id="Bitwise"><a href="#Bitwise" class="headerlink" title="Bitwise"></a>Bitwise</h2>
<p><code>&amp;</code>, <code>|</code>, <code>^</code> (xor), <code>~</code> (not), <code>&lt;&lt;</code> (left shift), <code>&gt;&gt;</code> (right shift). These operate on individual bits — useful for low-level manipulation and flags:</p>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">int</span> flags = <span class="hljs-number">0</span>;</span><br><span class="line">flags |= (<span class="hljs-number">1</span> &lt;&lt; <span class="hljs-number">0</span>);     <span class="hljs-comment">// set bit 0</span></span><br><span class="line">flags |= (<span class="hljs-number">1</span> &lt;&lt; <span class="hljs-number">2</span>);     <span class="hljs-comment">// set bit 2</span></span><br><span class="line"><span class="hljs-keyword">if</span> (flags &amp; (<span class="hljs-number">1</span> &lt;&lt; <span class="hljs-number">2</span>)) { ... }   <span class="hljs-comment">// test bit 2</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<h2 id="Assignment-shorthand"><a href="#Assignment-shorthand" class="headerlink" title="Assignment shorthand"></a>Assignment shorthand</h2>
<p><code>+=</code>, <code>-=</code>, <code>*=</code>, <code>/=</code>, <code>%=</code>, <code>&amp;=</code>, <code>|=</code>, <code>^=</code>, <code>&lt;&lt;=</code>, <code>&gt;&gt;=</code>.</p>
<h2 id="Increment-decrement"><a href="#Increment-decrement" class="headerlink" title="Increment / decrement"></a>Increment / decrement</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">int</span> i = <span class="hljs-number">5</span>;</span><br><span class="line">i++;        <span class="hljs-comment">// post-increment (returns old value, then increments)</span></span><br><span class="line">++i;        <span class="hljs-comment">// pre-increment (increments, then returns)</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Prefer <code>++i</code> when the result isn't used — slightly more efficient for non-trivial types.</p>
<hr>
<h1 id="Chapter-6-—-Integer-overflow-promotion"><a href="#Chapter-6-—-Integer-overflow-promotion" class="headerlink" title="Chapter 6 — Integer overflow + promotion"></a>Chapter 6 — Integer overflow + promotion</h1>
<p>Signed integer overflow is <strong>undefined behaviour</strong> in C++:</p>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">int</span> x = INT_MAX;</span><br><span class="line"><span class="hljs-type">int</span> y = x + <span class="hljs-number">1</span>;     <span class="hljs-comment">// UB — compiler is allowed to do anything</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Use <code>int64_t</code> or be sure your arithmetic stays in range.</p>
<p>Unsigned overflow wraps (well-defined):</p>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">uint32_t</span> u = <span class="hljs-number">0</span>;</span><br><span class="line">u--;     <span class="hljs-comment">// becomes 4,294,967,295</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<h2 id="Type-promotion"><a href="#Type-promotion" class="headerlink" title="Type promotion"></a>Type promotion</h2>
<p>When mixing types, the compiler promotes the smaller/narrower to the wider:</p>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">int</span>    i = <span class="hljs-number">5</span>;</span><br><span class="line"><span class="hljs-type">double</span> d = <span class="hljs-number">2.0</span>;</span><br><span class="line"><span class="hljs-keyword">auto</span>   r = i + d;     <span class="hljs-comment">// r is double, value 7.0</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Signed + unsigned of the same size → unsigned. <strong>Mixing signed and unsigned is a notorious bug source</strong>:</p>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-type">unsigned</span> <span class="hljs-type">int</span> u = <span class="hljs-number">1</span>;</span><br><span class="line"><span class="hljs-type">int</span>          s = <span class="hljs-number">-1</span>;</span><br><span class="line"><span class="hljs-keyword">if</span> (s &lt; u) { ... }    <span class="hljs-comment">// SURPRISE: s is converted to unsigned (huge), so condition is FALSE</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Use signed types unless you have a specific reason for unsigned.</p>

<h1 id="Chapter-7-—-Control-flow"><a href="#Chapter-7-—-Control-flow" class="headerlink" title="Chapter 7 — Control flow"></a>Chapter 7 — Control flow</h1>
<h2 id="if-else"><a href="#if-else" class="headerlink" title="if / else"></a>if / else</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-keyword">if</span> (x &gt; <span class="hljs-number">0</span>) {</span><br><span class="line">    std::cout &lt;&lt; <span class="hljs-string">&quot;positive&quot;</span>;</span><br><span class="line">} <span class="hljs-keyword">else</span> <span class="hljs-keyword">if</span> (x == <span class="hljs-number">0</span>) {</span><br><span class="line">    std::cout &lt;&lt; <span class="hljs-string">&quot;zero&quot;</span>;</span><br><span class="line">} <span class="hljs-keyword">else</span> {</span><br><span class="line">    std::cout &lt;&lt; <span class="hljs-string">&quot;negative&quot;</span>;</span><br><span class="line">}</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Braces are optional for single-statement bodies, but <strong>always use them</strong> — prevents the dangling-statement bug.</p>
<h2 id="C17-if-with-init"><a href="#C17-if-with-init" class="headerlink" title="C++17 if with init"></a>C++17 if with init</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-keyword">if</span> (<span class="hljs-keyword">auto</span> it = m.<span class="hljs-built_in">find</span>(key); it != m.<span class="hljs-built_in">end</span>()) {</span><br><span class="line">    <span class="hljs-comment">// use it-&gt;second</span></span><br><span class="line">}</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>The variable <code>it</code> is scoped to the <code>if</code>/<code>else</code>. Keeps tiny helpers out of the surrounding scope.</p>
<h2 id="while-do-while"><a href="#while-do-while" class="headerlink" title="while / do-while"></a>while / do-while</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-keyword">while</span> (n &gt; <span class="hljs-number">0</span>) {</span><br><span class="line">    <span class="hljs-built_in">process</span>(n);</span><br><span class="line">    --n;</span><br><span class="line">}</span><br><span class="line"> </span><br><span class="line"><span class="hljs-keyword">do</span> {</span><br><span class="line">    <span class="hljs-comment">/* runs at least once */</span></span><br><span class="line">} <span class="hljs-keyword">while</span> (<span class="hljs-built_in">still_running</span>());</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<h2 id="Classic-for"><a href="#Classic-for" class="headerlink" title="Classic for"></a>Classic <code>for</code></h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-keyword">for</span> (<span class="hljs-type">int</span> i = <span class="hljs-number">0</span>; i &lt; <span class="hljs-number">10</span>; ++i) {</span><br><span class="line">    std::cout &lt;&lt; i &lt;&lt; <span class="hljs-string">&quot; &quot;</span>;</span><br><span class="line">}</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Three parts: init, condition, increment.</p>
<h2 id="Range-based-for-C11"><a href="#Range-based-for-C11" class="headerlink" title="Range-based for (C++11+)"></a>Range-based <code>for</code> (C++11+)</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span><br><span class="line">11</span><br><span class="line">12</span><br><span class="line">13</span></pre></td><td class="code"><pre><code class="cpp"><span class="line">std::vector&lt;<span class="hljs-type">int</span>&gt; v{<span class="hljs-number">1</span>, <span class="hljs-number">2</span>, <span class="hljs-number">3</span>, <span class="hljs-number">4</span>, <span class="hljs-number">5</span>};</span><br><span class="line"><span class="hljs-keyword">for</span> (<span class="hljs-type">int</span> x : v) {              <span class="hljs-comment">// copy each element</span></span><br><span class="line">    std::cout &lt;&lt; x &lt;&lt; <span class="hljs-string">&quot; &quot;</span>;</span><br><span class="line">}</span><br><span class="line"> </span><br><span class="line"><span class="hljs-keyword">for</span> (<span class="hljs-type">const</span> <span class="hljs-keyword">auto</span>&amp; x : v) {      <span class="hljs-comment">// const reference — no copy, no mutation</span></span><br><span class="line">    std::cout &lt;&lt; x &lt;&lt; <span class="hljs-string">&quot; &quot;</span>;</span><br><span class="line">}</span><br><span class="line"> </span><br><span class="line"><span class="hljs-keyword">for</span> (<span class="hljs-keyword">auto</span>&amp; x : v) {            <span class="hljs-comment">// mutable reference — can modify</span></span><br><span class="line">    x *= <span class="hljs-number">2</span>;</span><br><span class="line">}</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p><code>const auto&amp;</code> is the idiomatic default. Use plain <code>auto</code> only for small types like <code>int</code>/<code>double</code>.</p>
<h2 id="switch"><a href="#switch" class="headerlink" title="switch"></a>switch</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span><br><span class="line">9</span><br><span class="line">10</span><br><span class="line">11</span><br><span class="line">12</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-keyword">switch</span> (cmd) {</span><br><span class="line">    <span class="hljs-keyword">case</span> <span class="hljs-number">1</span>:</span><br><span class="line">        <span class="hljs-built_in">do_one</span>();</span><br><span class="line">        <span class="hljs-keyword">break</span>;</span><br><span class="line">    <span class="hljs-keyword">case</span> <span class="hljs-number">2</span>:</span><br><span class="line">    <span class="hljs-keyword">case</span> <span class="hljs-number">3</span>:</span><br><span class="line">        <span class="hljs-built_in">do_two_or_three</span>();</span><br><span class="line">        <span class="hljs-keyword">break</span>;</span><br><span class="line">    <span class="hljs-keyword">default</span>:</span><br><span class="line">        <span class="hljs-built_in">do_other</span>();</span><br><span class="line">}</span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>

<h2 id="Pass-by-value-vs-reference"><a href="#Pass-by-value-vs-reference" class="headerlink" title="Pass by value vs reference"></a>Pass by value vs reference</h2>
<pre><code class="language-cpp"><figure class="highlight cpp"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br><span class="line">3</span><br><span class="line">4</span><br><span class="line">5</span><br><span class="line">6</span><br><span class="line">7</span><br><span class="line">8</span></pre></td><td class="code"><pre><code class="cpp"><span class="line"><span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">by_value</span><span class="hljs-params">(<span class="hljs-type">int</span> x)</span>          </span>{ x = <span class="hljs-number">999</span>; }</span><br><span class="line"><span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">by_reference</span><span class="hljs-params">(<span class="hljs-type">int</span>&amp; x)</span>     </span>{ x = <span class="hljs-number">999</span>; }</span><br><span class="line"><span class="hljs-function"><span class="hljs-type">void</span> <span class="hljs-title">by_const_ref</span><span class="hljs-params">(<span class="hljs-type">const</span> <span class="hljs-type">int</span>&amp; x)</span> </span>{ <span class="hljs-comment">/* x = 999;  // ERROR */</span> }</span><br><span class="line"> </span><br><span class="line"><span class="hljs-type">int</span> n = <span class="hljs-number">5</span>;</span><br><span class="line"><span class="hljs-built_in">by_value</span>(n);        <span class="hljs-comment">// n is still 5</span></span><br><span class="line"><span class="hljs-built_in">by_reference</span>(n);    <span class="hljs-comment">// n is now 999</span></span><br><span class="line"> </span></code></pre></td></tr></table></figure></code></pre>
<p>Default rule:</p>
<ul>
<li>Small types (<code>int</code>, <code>double</code>, pointers) → pass by value.</li>
<li>Large types (<code>std::string</code>, containers, your own classes) → pass by <code>const &amp;</code> unless you need to mutate.</li>
</ul>
