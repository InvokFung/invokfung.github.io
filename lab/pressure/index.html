Pressure

My name, set wall to wall in a variable font. Letters near the cursor swell wide and heavy, the rest pull in thin. Leave the mouse still and a slow wave runs through them.

Where it came from

TextPressure and VariableProximity from React Bits, widely cloned onto shadcn and Framer component sites. This one is plain JS on Google's Roboto Flex, which has width, weight and optical size axes.

How it works

  • Each letter is a span. Every frame its distance to the pointer sets three font axes at once: width 25 to 151, weight 140 to 1000, optical size 8 to 144.
  • Rows are justified wall to wall, so the line keeps its edges while letters trade width.
